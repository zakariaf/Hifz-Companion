## Goal

The optional source URL on a science row becomes a real, honest affordance — and nothing more. This task plugs the link behaviour into the E19-T04 row's citation link slot: when a register row carries a URL, the citation shows a **non-color "opens externally" glyph at the logical end** plus the localized **"opens in your browser" hint**, and a tap hands the URL to the **system browser** via the injected `SourceLinkLauncher` boundary (tech-decision log #15: `url_launcher`, `LaunchMode.externalApplication`, `app` shell only). The app makes **no in-app fetch** — the link is an optional convenience, never the citation itself (`ui-science-source-row` point 6): the full reference is always on-device text (T04/T05), so **offline the tap simply does nothing** — a calm no-op, no error wall, and the citation carries full trust with zero network (C-047, C-048). The row (T04), the `[TRAD]` variant (T05), the screen (T07), and the transcreated hint value (T09) are siblings; this task owns only the link behaviour, its leaves-the-app affordance, its offline degradation, and the guard test proving a tap opens no socket.

## Implementation notes

This task is behaviour-only: no register data (T01), no row anatomy (T04), no screen (T07), no engine, no clock, no `review_log`. It is **test-first on the offline guard**: the throwing-`HttpOverrides` test and the fake-launcher test are written before the launcher is wired.

1. **Files.** In the `features` package, `lib/src/science/` (per the T04/T07 module anatomy): `source_link_launcher.dart` — the abstract `SourceLinkLauncher` interface (one method, e.g. `Future<void> openExternal(Uri url)`), pure Dart, **no** `url_launcher` import; register a `sourceLinkLauncherProvider` in the scoped `science_providers.dart` whose unoverridden read is a startup defect (eng-define-service-boundary). In the `app` shell only: the concrete implementation that imports `package:url_launcher` and calls `launchUrl(url, mode: LaunchMode.externalApplication)`, overridden into the provider in `main` — the **only** file in the repo that names the plugin (decision #15).
2. **Plug the slot, don't rebuild the row.** Wire `onOpenExternal` on T04's `SourceCitation` to `sourceLinkLauncherProvider` for rows whose register entry carries a URL. A row **without** a URL renders no glyph, no hint, no dead affordance — the link is optional per row, never a placeholder.
3. **Visibly external, never disguised.** The affordance is the citation's trailing run: a non-color "opens externally" glyph at the **logical end** (`EdgeInsetsDirectional`; mirror decision from the ds-12 §2 table via eng-rtl-and-bidi-layout — never intuition) plus the localized hint in `type.caption` / `color.text.secondary`. Externality is carried by glyph **words + shape**, never by color or underline alone (WCAG 1.4.1). The hit area clears `touch.min` (≥48×48dp) even though the visible glyph is small.
4. **Offline degrades to a calm no-op.** If the launcher reports failure (a `false` return or a platform exception — including airplane mode, no browser, a malformed URL), swallow it: **no error dialog, no snackbar, no retry nag, no connectivity probe before the tap**. The on-device citation is the trust carrier; the link failing is information-free by design (11 §2). Do not disable the link behind a connectivity check — checking is itself a network-ish behaviour and adds a false state; just hand to the OS.
5. **No in-app fetch, provably.** Nothing in this task imports `package:http`, `package:dio`, or `dart:io`'s `HttpClient` — the banned-import lint over `features/**` (01 §6) must stay green with zero exemptions added. `url_launcher` crosses a platform channel and opens no Dart socket, which is why the throwing-`HttpOverrides` guard passes with the link tapped.
6. **Bidi + semantics.** The Latin URL/venue run is FSI/PDI-isolated so it never reorders the RTL citation line (10-privacy §7). The link contributes its words to T04's single `MergeSemantics` phrase — the screen reader hears citation + "opens in your browser" as one localized node with the link flag set (`Semantics(link: true)`); the glyph itself is decoration (`ExcludeSemantics`).
7. **The URL is register-owned data — never constructed here.** The `Uri` comes from the T01 typed row (an optional field the parser already validated); this task neither builds, rewrites, normalizes, nor appends to it — a query-string added in the feature layer is exactly the exfiltration shape 01 §6 warns about. A URL the OS rejects degrades like offline: calm no-op, never a crash or an error state.
8. **Quiet feedback, keyboard-reachable.** The tap gives the standard quiet ink response only — no celebratory motion, no haptic beyond the platform default, nothing that rewards "reading the science" (11 §6). The affordance is focusable in the RTL traversal order with a visible focus ring (07-components §6 discipline); reduce-motion changes nothing because nothing animates.
9. **Strings via the ARB pipeline** (eng-add-localized-string): add the hint key (e.g. `scienceExternalLinkHint`) to `app_ar.arb` (base) so the build compiles; T09 owns the transcreated fa/ckb/ar values and their scholarly/native review. No hardcoded user-facing string, no raw URL shown as the attribution.
10. **Pitfalls to avoid:** an in-app WebView / in-app browser tab presentation (must be the *system* browser, `LaunchMode.externalApplication`); reusing this launcher for the E16 About **repository** link (01 §6 deliberately keeps that URL as selectable, copyable text — decision #15 does not cover it); making the URL the citation or hiding the reference behind it; any prefetch, favicon, or link-preview unfurl (that is an in-app fetch); an offline error wall or "you are offline" banner; importing `url_launcher` anywhere in `features/`; a color-only or underline-only externality cue; the glyph at a physical `right`; a second launcher package or a hand-rolled intent (the approved dependency set is closed — decision #15 / #17-style amendments only).

## Acceptance criteria

- [ ] `features/.../science/source_link_launcher.dart` defines the `SourceLinkLauncher` interface + provider with no plugin import; the only file importing `package:url_launcher` is the `app`-shell implementation, wired via `Provider` override in `main` (grep-verifiable), launching with `LaunchMode.externalApplication`.
- [ ] A row whose register entry carries a URL shows the non-color "opens externally" glyph at the logical end + the localized `scienceExternalLinkHint`; a row without a URL shows neither glyph nor hint nor any tappable dead zone.
- [ ] Tapping the link requests the system browser with exactly the register row's URL through the injected boundary; the app performs **zero** in-app network calls before, during, or after the tap.
- [ ] A failed launch (offline / no browser / platform error) resolves to a calm no-op: no error dialog, snackbar, retry affordance, or connectivity check appears, and the full on-device citation remains rendered and readable.
- [ ] The link affordance is ≥48×48dp (`touch.min`), carries the link semantics flag, and its hint words join T04's single merged screen-reader phrase in the active locale; the externality cue survives grayscale (non-color glyph + words).
- [ ] The Latin URL/venue run is FSI/PDI bidi-isolated; the glyph position and insets are logical start/end only (no `left`/`right`); the glyph's mirror behaviour traces to the ds-12 §2 table.
- [ ] The hint is an ARB key present in the pipeline (base `app_ar.arb`; fa/ckb/ar values owned by T09, ckb flagged pending native review); no hardcoded user-facing string.
- [ ] The tap gives only the standard quiet ink response (no celebratory motion or haptic); the affordance is keyboard/switch-focusable in the RTL traversal order with a visible focus ring; the launched `Uri` is byte-identical to the register row's URL (nothing appended or rewritten).
- [ ] The banned-import lint and dependency allow-list gates pass unchanged: no `http`/`dio`/`HttpClient` import in this task's files, no new dependency beyond decision #15's `url_launcher`.

## Tests

All deterministic, offline by construction: the global throwing `HttpOverrides` stays installed (11-testing §7), the launcher is a recording fake, no real platform channel, no clock.

- `features/test/science/external_source_link_offline_guard_test.dart` — **written first**; the epic's named offline guard: with `useOfflineTestPolicy()` (the throwing `HttpOverrides`) active, pump a seeded row with a URL, tap the link, and complete the test with zero socket opens (any fetch would throw loudly); then drive the fake launcher's failure path (`openExternal` resolving as failed) and assert no error widget, no snackbar, and the full citation text still present — the row renders identically to the untapped state.
- `features/test/science/external_source_link_test.dart` (widget) — a `FakeSourceLinkLauncher` injected via provider override records that one tap produces exactly one `openExternal` with the expected `Uri`; the affordance's hit area is ≥48×48dp; semantics carry the link flag + the localized hint inside T04's merged phrase (asserted across fa/ckb/ar); a no-URL row renders no glyph, no hint, and no launcher call on tap; the glyph run sits at the logical end under `Directionality.rtl` and the Latin URL run is isolate-wrapped (FSI/PDI present in the built string); directional-focus traversal reaches the link and the recorded `Uri` is byte-identical to the seeded register row's URL.
- `app/test/source_link_launcher_impl_test.dart` (unit) — the concrete implementation, with the `url_launcher` platform interface replaced by a test double, requests `LaunchMode.externalApplication` with the given URL, and maps a `false` return or a thrown platform exception to a completed calm no-op (no rethrow).
- `features/test/science/science_import_boundary_test.dart` (unit) — pins the boundary: no file under `features/.../science/` imports `package:url_launcher`, `package:http`, `package:dio`, or `dart:io` (string-scan over the source, mirroring the CI banned-import rule so the failure is local and named).
- Per-locale goldens of the glyph + hint on the row, and the whole-screen offline sweep, live in **E19-T10** — not duplicated here.
