## Goal

The religious/methodology rows of "The science we follow" render with the reverence and restraint this audience will scrutinise. This task extends the E19-T04 `ScienceSourceRow` — reusing its two-layer face/"the evidence" scaffolding, `MergeSemantics`, and RTL geometry — with the **`[TRAD]` variant** selected by `EvidenceGrade.trad` on the register row: the source shown as **collection + number + grading** as readable on-device text (the decay ḥadīth *Ṣaḥīḥ al-Bukhārī 5032* / *Ṣaḥīḥ Muslim 791*, C-035; the seven manāzil, C-036; talaqqī/sanad, C-038; the ʿarḍa *Bukhārī 4998*, C-039; traditional overlearning, C-040; actions-by-intentions, C-045; servant-not-fatwa, C-046), framed as **methodology only** — madhhab- and sect-neutral, servant to the teacher and the *sanad*, issuing **no fiqh ruling** and interpreting **no verse** — with the E10 `CertaintyLabel` reading "named traditional scholarship" (never styled or ranked as more authoritative than the empirical grades), and a plain **"needs scholarly review"** note wherever the register marks sign-off as pending. The decay ḥadīth is presented calmly as the honest premise of loss-prevention, never weaponized into "you'll lose your hifz." The row renders **no Quran glyph and re-typesets no āyah** — a hadith is named by collection + number as UI text in the UI fonts, never via the QPC per-page glyph fonts.

## Implementation notes

This task is presentation-only and **renderer-not-author**: every headline, source, grading, and caveat comes from the T01 register row via the T03 read model — nothing religious is hand-written into a widget. The adab invariants are copy-correctness-critical → the banned-phrase/no-ruling assertions are pinned **test-first**, before the visuals.

1. **Files** (in the `features` umbrella package, `lib/src/science/widgets/`): extend T04's `science_source_row.dart` with the `[TRAD]` branch (a `switch` on the row's sealed `EvidenceGrade`, `trad` → the variant) plus two leaves — `trad_source_attribution.dart` (collection + number + grading as one attribution run) and `scholarly_review_note.dart` (the plain pending-sign-off line). No new base row, no new expansion mechanics, no screen changes.
2. **Variant selection is the grade, never a list of ids.** The branch keys off `EvidenceGrade.trad` from the T01 row — never a hand-maintained set of `C-NNN` ids. Dual-graded rows (C-045 `[TRAD]`/`[CS]`; C-016 `[EXP]`/`[TRAD]`) render **every** parsed source with its own attribution — the `[TRAD]` framing is added, the empirical citation is never dropped or hidden. (The typed shape of a multi-grade row is T01's contract; consume it, don't re-parse.)
3. **Attribution: collection + number + grading, intact, on-device.** Render the register's source exactly (e.g. *Ṣaḥīḥ al-Bukhārī 5032*, with its grading term); never truncate to "a hadith" or "the tradition says." The number renders in locale numerals via the shared `numberFormatFor(locale)` path + `type.numeral` (۵۰۳۲ for fa/ckb, ٥٠٣٢ for ar — never raw ASCII); any Latin/transliteration run is FSI/PDI bidi-isolated so it never reorders the RTL line (eng-rtl-and-bidi-layout applies).
4. **The grading shown is the register's — the app never grades a hadith.** Whatever grading term accompanies a citation (e.g. that a collection is ṣaḥīḥ) is part of the T01 row's source text, authored by the science foundation with its scholarly record; this task's widgets and keys must not add, soften, upgrade, or improvise a grading anywhere (CLAUDE contract: "never improvise fiqh, grade a hadith").
5. **Methodology framing, no ruling.** The face headline stays the register's plain, declarative, ḥāfiẓ-frame wording ("The tradition reviews the whole of what one holds periodically…"). No ruling verb or fiqh vocabulary is introduced anywhere in this task's chrome or keys (no "wājib/obligatory/forbidden/must"), no verse is quoted or interpreted, and non-hadith rows (C-036, C-040) present tradition as *described practice* ("offered, not imposed" — C-036's caveat), never as the app's verdict.
6. **The certainty label: composed, neutral, never elevated.** Compose the E10 `CertaintyLabel` for `trad` — "named traditional scholarship" — in the same "the evidence" slot and the **same neutral container** T04 uses for `[MA]`: no gold/ornamental/accent styling, no reordering that places `[TRAD]` above empirical grades, no wording implying religious authority outranks the evidence scale (ui-certainty-label point 3). The raw `[TRAD]` bracket tag never renders.
7. **"Needs scholarly review": data-driven, plain, calm.** The note renders iff the T01 row carries the pending-review flag (C-046; PRD §21 names the pending items) — the widget never decides or hardcodes pending-ness. Style: one quiet line in `type.caption`/`color.text.secondary` inside the evidence expansion, informational — **not** an error/warning fill, no urgency, no apology theatre. The wording is an ARB key (e.g. `scienceNeedsScholarlyReview`); it states the fact and stops.
8. **The decay ḥadīth is calm loss-prevention, never a threat.** C-035 renders as the honest premise of the app's methodology; banned outright: "you'll lose your hifz," countdown/loss framing, fear leverage, any pairing with a red/alarm treatment (C-035 caveat; voice §2 "calm"; adab skill point 10).
9. **Servant-to-the-teacher, in copy and chrome.** C-038/C-046 rows defer to the teacher and the *sanad*; nothing in this variant phrases the app as certifying, approving, or outranking a teacher (13-adab §6). The row explains; it never counts, sells, or nags.
10. **No muṣḥaf glyph, ever, on this surface.** The variant renders hadith references (and any translated hadith wording the register's headline carries) as plain UI text in the bundled UI fonts — **no QPC per-page glyph font, no āyah, no re-typeset sacred text, no muṣḥaf-style ornament** around the attribution. Muṣḥaf rendering is domain-mushaf-text-integrity's surface; this row must contain none of it.
11. **Strings via the ARB pipeline; scholar review recorded.** Register the keys this variant needs (the pending note, grading terms, attribution format) in `app_ar.arb` per eng-add-localized-string; T09 authors the transcreated fa/ckb/ar values. Every religious/methodology string is flagged for scholarly review in the conscience-pass record — it ships reviewed or the surface stays flagged pending (voice §9; CLAUDE contract #7/#16).
12. **Pitfalls to avoid:** forking the base row instead of branching T04's; keying the variant off claim ids instead of the grade; dropping the empirical citation on a dual-graded row; stripping collection/number/grading; rendering the raw `[TRAD]` tag; styling `[TRAD]` as more authoritative (gold, top-of-legend, "highest authority" copy); hardcoding the pending flag in the widget; a ruling verb or verse quotation; ASCII digits in a hadith number; threat-framing the decay ḥadīth; any QPC glyph or muṣḥaf ornament.

## Acceptance criteria

- [ ] The `[TRAD]` variant lives as a branch of T04's `ScienceSourceRow` (plus the `trad_source_attribution.dart` / `scholarly_review_note.dart` leaves), selected by `EvidenceGrade.trad` from the T01/T03 row — no forked base row, no id-list dispatch, no hand-written source string (verifiable by grep over the files).
- [ ] Every `[TRAD]` fixture row renders its **collection + number + grading intact** as on-device text (C-035 shows *Ṣaḥīḥ al-Bukhārī* + its number + grading), with the number in locale numerals via `numberFormatFor(locale)`/`type.numeral` and Latin runs FSI/PDI-isolated.
- [ ] The composed `CertaintyLabel` reads "named traditional scholarship" for `trad`, in the **same neutral container** as an `[MA]` row — no distinct authority styling, no reordering above empirical grades, no raw `[TRAD]` bracket tag anywhere in the UI.
- [ ] A row whose register entry is flagged pending renders the plain "needs scholarly review" note (`type.caption`/`color.text.secondary`, no error fill, no urgency); an unflagged row renders no note; the flag comes only from the T01 data.
- [ ] Dual-graded rows (C-045 `[TRAD]`/`[CS]`) render both the traditional and the empirical citation — neither dropped, neither hidden.
- [ ] The grading term rendered with a citation is exactly the register's source text — no widget, key, or format string adds, softens, or improvises a hadith grading.
- [ ] No string this task adds or renders contains a ruling verb, fiqh vocabulary, a verse quotation/interpretation, "safe to drop"/"mastered", threat/loss framing ("you'll lose your hifz"), a mandate word, `!`, or emoji — the banned-phrase lint passes over all fixtures and keys.
- [ ] The rendered tree contains **no QPC glyph font, no Quran text, and no muṣḥaf-style ornament** for any `[TRAD]` fixture — hadith references are UI text in the bundled UI fonts.
- [ ] Every user-facing string is an `l10n.*` ARB key registered in `app_ar.arb` (transcreated values land in T09; religious keys flagged for scholarly review); layout is RTL by geometry (`EdgeInsetsDirectional`, logical start/end); the variant's content merges into T04's single `MergeSemantics` phrase (headline + collection/number/grading + certainty phrase + pending note).
- [ ] The adab conscience pass (domain-adab-and-religious-integrity) is recorded for every `[TRAD]` headline, attribution, grading term, and the pending note.

- `features/test/science/trad_adab_invariants_test.dart` (unit/widget) — the banned-phrase/no-ruling assertion over every string the variant renders across all seven fixture rows (C-035/C-036/C-038/C-039/C-040/C-045/C-046) and every ARB key this task registers: no ruling verb or fiqh vocabulary, no "safe to drop"/"mastered"/"done", no "you'll lose your hifz"/loss-threat framing, no mandate word, no `!`/emoji, no raw `[TRAD]` bracket tag.
- `features/test/science/scholarly_review_note_test.dart` (widget) — pending flag on → the note renders once, in `color.text.secondary` with no `color.semantic.warning` fill and no alarm styling (Mihrab deliberately defines no error/danger token for user-facing states — 03-color-and-themes; the warning token is reserved for asset-integrity); flag off → absent from the tree; the flag is read from the fixture row (a widget-local override is impossible by construction).
- `features/test/science/trad_no_glyph_test.dart` (widget) — for every `[TRAD]` fixture, asserts no text run in the tree uses a QPC glyph font family and no muṣḥaf/page widget is present — the row is UI chrome and UI fonts only.
- Semantics: extends T04's merged-phrase test with a `[TRAD]` case — one node voicing headline + collection/number/grading + certainty phrase + (when pending) the review note, in the active locale.
- Offline guard: the suite runs under the throwing `HttpOverrides` (eng-write-dart-test) — proves rendering every `[TRAD]` fixture opens no socket. (The tap-a-link offline behaviour is T06's test; the consolidated per-locale golden/a11y sweep is T10's.)
