## Goal

Every user-facing string on the science surface exists as a **transcreated** (never literally translated) ARB value in all three locales — `app_ar.arb` as the template/base content language, `fa` and `ckb` diffed against it: the plain claim headlines (the locale rendering of each registered `CLAIMS.md` headline, in the ḥāfiẓ's frame), the source attributions (author/year/venue; collection + number + grading for `[TRAD]`), the certainty phrases the E10 `certaintyLabel(EvidenceGrade)` mapping resolves to plus the plain-words grade legend, the "the evidence" expansion label, the "needs scholarly review" note, and the "opens in your browser" / leaves-the-app hint. Sibling tasks T04/T05/T06/T07/T08 **key** their strings (`l10n.*`); this task authors the **values** and the plural/numeral/bidi wiring: every year/number renders via `numberFormatFor(locale)` in the locale digit set (never ASCII), every Latin author/venue/URL run is FSI/PDI bidi-isolated, any count carries Arabic's six CLDR plural categories. `ckb` ships flagged provisional pending native + scholar review; no `[TRAD]`/religious value ships without scholarly review. No widget and no golden is built here (T10).

## Implementation notes

This task is copy-and-values only: no widget, no provider, no register edit, no CLAIMS.md edit. It is **adab-correctness-critical** → the banned-phrase lint and the coverage/numeral/bidi tests are written first, then the values are authored against them.

1. **Inventory the keys, then author `ar` first.** Collect every `l10n.*` key the T04–T08 siblings introduced (row headline per claim id, attribution, "the evidence" label, certainty phrase per `EvidenceGrade`, legend title + one legend entry per grade, "needs scholarly review", external-link hint, screen title, theme-card titles, the T08 honesty/trust-signal copy). Author each value in `lib/l10n/app_ar.arb` (the `l10n.yaml` template) with an `@description` naming the owning `C-NNN` id (or "chrome" for non-claim strings) and any placeholder contract — the description is what the native reviewer and scholar read.
2. **Transcreate `fa` and `ckb` against `ar` — never literally translate.** Per voice §8: Persian in respectful-warm *šomā*/honorific register (a private companion, not a clerk); Arabic with imperatives softened into statements of readiness (a bare command verb reads curt); Sorani authored as provisional defaults with canonical encoding (U+06D5 ە for AE, U+06A9 ک for kaf, no stray ZWNJ, no Teh-Marbuta-for-AE), its `@description` flagged "needs native + scholar review". One voice, three idiomatic renderings — the *feeling* survives, not the word order.
3. **Headlines render the register, they never re-author it.** Each headline value is the locale transcreation of the registered `CLAIMS.md` headline in the ḥāfiẓ's frame (11 §3): common words, active voice, *murājaʿa*/pages/juz — no "free-recall paradigm", no "stability parameter" without a one-line plain gloss. If a registered headline cannot be rendered faithfully and plainly in a locale, stop and raise it against the register (out of scope to change here) — never quietly shift the claim's meaning so it no longer matches what the engine does.
4. **Attribution values are one ICU message with isolated placeholders.** Author/year/venue (e.g. *Cepeda et al., 2006 — meta-analysis*, the 11 §4 shape) enters as `{author}`/`{year}`/`{venue}` placeholders in a single full message — never spliced fragments. The Latin author/venue/URL run is wrapped `isolateLtr` (LRI…PDI — direction is *known*, so FSI is not the right tool) via the one `bidi.dart` helper before injection; the year is formatted through `numberFormatFor(locale)` **first** (fa/ckb ۲۰۰۶, ar ٢٠٠٦), then placed — an ASCII `2006` concatenated into RTL copy is a build-failing defect, not a nit.
5. **Certainty phrases + legend speak about the *evidence*, never the user's Quran.** The E10 `certaintyLabel(EvidenceGrade)` mapping resolves to `l10n.*` keys; this task authors those values per 11 §5: `[MA]` ≈ "among the best-established findings in memory science", `[EXP]` a single controlled study, `[TRAD]` named traditional scholarship — honest, graded-down wording for weaker grades, and **no** "proven", no star language, no percentage, no phrase a reader could hear as "this page is safe" (C-047: uncertainty said plainly).
6. **`[TRAD]` values are methodology, sourced, and gated.** The decay-ḥadīth headline (C-035) is rendered calmly as the honest premise of loss-prevention — never "you'll lose your hifz"; its attribution names *Ṣaḥīḥ al-Bukhārī* 5032 (and *Ṣaḥīḥ Muslim* 791) with grading, transliterated with correct honorifics per locale. The C-046 servant/no-fatwa copy stays sect/madhhab-neutral and issues no ruling in any rendering. The "needs scholarly review" note is plain and unapologetic (honesty, not embarrassment). **No `[TRAD]` or methodology-adjacent value ships without per-locale scholarly review** — until sign-off, it is marked provisional in the `@description` and surfaced by the T05 note.
7. **The external-link hint is honest and calm.** The T06 hint ("opens in your browser" / visibly leaves the app) states the consequence plainly — no alarm framing, no "warning". Any displayed URL/domain run is `isolateLtr`-wrapped so it cannot reorder the RTL line.
8. **The T08 honesty surfaces keep their registered meaning in every locale.** The cycle-ceiling-not-a-number framing and the no-streaks/no-guilt trust-signal copy are renderings of registered claims — transcreate them so the *structural* guarantee (the ceiling + overlearning, never a probability) and the deliberate absence of streaks/badges read plainly and calmly in fa/ckb/ar, with no locale drifting into a promise or a boast.
9. **Counts are six-category plurals.** Any count-bearing science string (e.g. a "{count} sources" line, if a sibling keyed one) is an ICU `plural` defining all six Arabic CLDR categories (`zero`/`one`/`two`/`few`/`many`/`other`) in `app_ar.arb`, with the count locale-numeral-formatted before placement — never a ternary or a `"$count"` splice.
10. **No direction, no layout, no sacred text in the values.** ARB values carry no hardcoded direction and no physical-side assumption (direction is locale-derived; layout is the widgets', T04/T07). No value quotes an āyah or reaches the muṣḥaf — the hadith citation is chrome text; the localization toolkit stops at the chrome boundary.
11. **Pitfalls to avoid:** literal translation that silently shifts register (voice §8); editing `CLAIMS.md` or "improving" a claim in one locale; ASCII digits or a Latin-block year in any value; FSI where the run's direction is known; concatenating attribution fragments; a certainty phrase that promises ("proven", "guaranteed", a percentage); weaponizing C-035; a mandate word, `!`, or emoji anywhere; locking ckb terminology before native + scholar review; keying a *new* string here (keys belong to T04–T08 — if one is missing, it lands in the owning sibling).

## Acceptance criteria

- [ ] Every `l10n.*` key rendered by T04/T05/T06/T07/T08 has a value in `app_ar.arb`, `app_fa.arb`, and `app_ckb.arb`; `gen_l10n` with `nullable-getter: false` compiles (a missing/typo key is a build error); no hardcoded user-facing literal exists in the science feature (grep-verifiable).
- [ ] `ar` is the authored template; `fa`/`ckb` values are transcreations diffed against it — Persian respectful-warm, Arabic imperatives softened to statements of readiness, `ckb` canonically encoded (U+06D5/U+06A9, no ZWNJ) and flagged "needs native + scholar review" in its `@description`.
- [ ] Every headline value renders its registered `C-NNN` claim faithfully in the ḥāfiẓ's frame — plain, idiomatic, jargon-glossed — and the `@description` names the claim id; no value changes a claim's meaning or invents a fact.
- [ ] Every attribution is a single ICU message: Latin author/venue/URL runs pass through the `bidi.dart` `isolateLtr` helper; every year/number renders via `numberFormatFor(locale)` in the locale digit block (fa/ckb Extended Arabic-Indic, ar Arabic-Indic) — zero ASCII digits in any rendered science string.
- [ ] The certainty phrases and grade-legend entries describe evidence strength honestly per grade with no "proven"/star/percentage/safety language; the `[TRAD]` values name collection + number + grading, issue no ruling, stay sect-neutral, and C-035 is framed calmly.
- [ ] The "needs scholarly review" note and the "opens in your browser" hint exist in all three locales, plain and non-alarming.
- [ ] Any count-bearing message defines all six Arabic CLDR plural categories in the template.
- [ ] No ARB value carries a hardcoded direction, a physical-side assumption, a spliced sentence fragment, or an āyah/muṣḥaf quotation; interpolation is one full ICU message per string.
- [ ] The never-ship banned-phrase lint passes over every added value in fa, ckb, and ar (no guilt/fear/loss, no mandate word, no "safe to drop"/"mastered"/"done", no `!`/emoji, no transaction word); the adab conscience pass is recorded; `[TRAD]`/religious values are cleared by (or explicitly marked pending) scholarly review.

## Tests

All deterministic and offline by construction (pure string/ARB assertions — no widget pumping beyond a minimal `Localizations` harness, no clock, no socket). Written first, then the values are authored to green.

- `features/test/science/science_arb_coverage_test.dart` (unit) — **written first**: enumerates every science-surface `l10n.*` key (from the generated `AppLocalizations`) and asserts a non-empty value exists in `ar`, `fa`, and `ckb`; asserts every count-bearing message in the template defines all six Arabic plural categories; asserts every `[TRAD]`-owning key's `@description` names its `C-NNN` id and review status.
- `features/test/science/science_banned_phrase_test.dart` (unit) — runs the never-ship banned-phrase lint over **every** value this task adds, in all three locales (guilt/fear/loss incl. "you'll lose your hifz" equivalents, mandate words, "safe to drop"/"mastered"/"done", `!`, emoji, "proven"/percentage-promise phrasing, transaction words) and fails on any hit.
- `features/test/science/science_numeral_bidi_test.dart` (unit) — pins the numeral path: a source year (e.g. 2006) rendered through an attribution string comes out ۲۰۰۶ under `fa`/`ckb` and ٢٠٠٦ under `ar`, injected as an isolated placeholder; asserts zero ASCII digits (U+0030–U+0039) in any rendered science string in all three locales.
- `features/test/science/science_attribution_bidi_test.dart` (unit) — a mixed run (Latin author/venue + locale year inside RTL copy, e.g. the *Cepeda et al., 2006* shape; and a URL/domain run from the link hint) round-trips without visual reordering: asserts the LRI/PDI (or FSI/PDI where direction is unknown) isolates are present around every Latin run and that no value raw-concatenates an opposite-direction fragment.
- `ckb` canonical-encoding lint — the existing canonical-`ckb` check (no stray U+200C, no Teh-Marbuta-for-AE, U+06D5/U+06A9 only) runs over `app_ckb.arb` and stays green.
- Per-locale goldens (fa × ckb × ar rows and screen on the real bundled fonts, 200% reflow, ckb-clipping proof) are **E19-T10's** — not duplicated here.

## Definition of Done

- [ ] All acceptance criteria met; the coverage, banned-phrase, numeral, and bidi tests were written first and are green; the `gen_l10n` build and the hardcoded-string/ASCII-digit greps pass in CI.
- [ ] **Offline / no-network**: strings are static ARB values bundled in the binary; nothing here fetches, and no value implies live content ("latest research" phrasing is forbidden — the register is bundled, C1/C2).
- [ ] **No AI / no microphone**: every value is human-authored and human-reviewed; no model generates or "improves" any wording (PRD C2, R5) — the no-AI posture is itself part of what these strings describe.
- [ ] **Quran text fidelity (R1)**: no value quotes, re-typesets, or localizes an āyah; the muṣḥaf is named "Ḥafṣ ʿan ʿĀṣim — Madani muṣḥaf" wherever a value references it (R2); hadith citations are chrome text with collection + number, never rendered muṣḥaf.
- [ ] **Never "safe to drop" / no promise**: no certainty phrase, legend entry, or headline rendering in any locale says or implies "safe to drop", "mastered", "done", or a retention guarantee; grades read as confidence about the evidence only (11 §5; C-047).
- [ ] **No gamification / no shame (R3, C6)**: no value carries guilt/fear/loss, streak, badge, or celebration framing; C-035's decay ḥadīth reads as calm methodology, never a threat.
- [ ] **Sect-neutral adab, scholar-gated**: every `[TRAD]`/methodology value is madhhab/sect-neutral, issues no fiqh ruling, is framed servant-to-the-teacher (C-046), and passed the domain-adab-and-religious-integrity conscience pass; religious copy is cleared by scholarly review per locale or ships explicitly marked pending — never silently.
- [ ] **RTL + fa/ckb/ar localization**: `ar` template + `fa`/`ckb` transcreations (not literal translations) for 100% of the science-surface keys; locale numerals via `numberFormatFor(locale)`; Latin runs FSI/PDI-isolated via the one helper; `ckb` canonical and provisional-flagged; no direction assumption in any value.
- [ ] **Accessibility**: the values double as the `MergeSemantics` phrase material T04 merges — each reads as one natural sentence per locale when concatenated by the row's semantic order; no value depends on visual position or color to carry meaning.
- [ ] **Deterministic tests**: all four test files are pure and clock/network-free; the lint list and digit assertions are byte-stable; the suite runs in CI on every PR, and T10's per-locale golden matrix consumes these values unchanged.
