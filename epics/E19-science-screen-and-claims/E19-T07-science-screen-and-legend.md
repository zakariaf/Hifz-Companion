## Goal

The "The science we follow" screen exists as the `science` feature module — a dumb `science_screen.dart` View + a 1:1 read-only `science_view_model.dart` + scoped `science_providers.dart` per **eng-add-feature-module** — a calm, scannable, read-only reference surface. It groups the register rows from the E19-T03 read model by theme, in fixed register order A–J (memory & forgetting → spacing & scheduling → the engine's math → retrieval & self-testing → interference & mutashābihāt → serial recall & the page unit → overlearning → traditional methodology → motivation & adab → cross-cutting honesty), into short cards whose entries are the composed E19-T04/T05 rows; it places the always-reachable plain-words grade legend (the E10-T06 leaf, `ui-certainty-label` point 7); and it mounts as a reference leaf behind Settings/About in the existing E07 shell (a typed `GoRoute` under the `ShellRoute`, RTL nav order preserved — **never** a sixth tab). It carries **no engagement mechanics**: no "N of M cards read" progress bar, no badge for finishing, no streak, no celebratory motion, no read-tracking state — the screen is reference, opened when wanted (11 §6). This task ARRANGES rows — it does not build row internals (T04/T05), link behaviour (T06), the honesty/non-coercion content (T08 fills declared slots inside this screen), or ARB values (T09) — and it sits *beside*, never inside, the E16-owned privacy/About panel.

## Implementation notes

This task is arrangement-only: no engine call, no repository write, no `DateTime.now()`, no network, no new claim text. The no-gamification invariant is **structural, not stylistic** → it is pinned test-first by a widget test that asserts the forbidden widgets/patterns are absent from the tree before the visuals are polished.

1. **Files** (in the `features` umbrella package, `lib/src/science/`, per eng-add-feature-module): `science_screen.dart` (dumb `ConsumerWidget` reading exactly one controller), `science_view_model.dart` (the 1:1 read-only `AsyncNotifier`), `science_providers.dart` (scoped, not global), `widgets/science_theme_card.dart` (one register group → one calm card arranging T04/T05 rows), `widgets/grade_legend_affordance.dart` (the placement wrapper that opens the E10-T06 legend leaf). Plus the typed `GoRoute` entry in `app/composition/router.dart`.
2. **The ViewModel is a read-only projection.** It watches the E19-T03 provider only and exposes an immutable UI state: the ordered A–J list of `(groupTitleKey, rows)` with empty groups omitted. No mutation command, no clock, no engine, no re-parse of register text (T01's job), no re-grouping heuristic — the register's grouping *is* the grouping. `.when(loading/error/data)` renders a calm retry on error, never a guilt message.
3. **Theme cards: short, scannable, fixed order.** One card per non-empty group, always in register order A–J — never reordered by "relevance", recency, or reading history. Card title in `type.title`, entries separated by `space.2`, card padding `space.4`, flat `color.surface` — a quiet reference page in a single vertical scroll, not a feed. Group titles are localized ARB keys in the ḥāfiẓ's frame (murājaʿa, pages, cycles — 11 §3), not lab jargon.
4. **Rows are composed, never rebuilt.** Each entry renders the E19-T04 `ScienceSourceRow` (the T05 `[TRAD]` variant dispatches on the row's grade) with the register row value passed straight through. This task writes zero headline/source/certainty/link internals, and hand-writes **no** claim into a card — an unregistered fact is the release-blocking defect the T02 gate exists to catch.
5. **The grade legend is always reachable.** A quiet ≥48dp (`touch.min`) affordance in the screen header (ARB key, e.g. `scienceLegendAffordance` — "what these labels mean") opens the E10-T06 plain-words legend leaf as a calm sheet. Per `ui-certainty-label` point 7 it is translated plain language, never a "★★★★★" key — and it is reachable from the top of the screen at all times, never buried inside a row expansion or below the fold as the only path.
6. **Mount behind Settings/About, inside the E07 shell.** Add a typed `GoRoute` (e.g. `/settings/science`) under the existing `ShellRoute` — the bottom nav keeps exactly five tabs in RTL order. The entry is one quiet Settings/About row ("The science we follow") *beside* the E16 privacy/About panel, never inside its what-stays/what-we-send rows. The route inherits the E07 `appReady` redirect guard (the verified bundled register is present before render); navigation is the typed route, never an imperative `Navigator.push`, never from inside the controller.
7. **No engagement mechanics — structurally absent.** No progress bar, badge, streak, score, counter, "N of M read", or celebratory motion exists anywhere in the module (11 §6; PRD R3/C6; 13-adab §4; C-041/C-044). The screen persists **nothing**: no "visited"/"read"/scroll-position state is written anywhere — opening the screen is not an event.
8. **Reserve the T08 slots, author none of their copy.** The screen declares the two content slots (the cycle-ceiling honesty framing; the no-streaks/no-guilt trust-signal card) as compositional insertion points T08 fills; this task ships them absent/empty with a marked TODO, writing no honesty copy itself.
9. **Strings, RTL, numerals.** Every chrome string (screen title, Settings entry-row label, the ten group titles, the legend affordance, the calm retry line) is an `l10n.*` key this task registers in the ar template — values transcreated in T09; no hardcoded literal. Layout is `EdgeInsetsDirectional`/`AlignmentDirectional` only; the back affordance mirrors under RTL. The chrome shows **no numerals at all** (no counts); years/numerals inside rows are T04's job via `numberFormatFor(locale)`.
10. **Accessibility + pitfalls.** Card titles are `Semantics` headers so a screen-reader user can jump groups; the legend affordance announces label + button role; 200% text scale reflows with no truncation or horizontal scroll; entry uses the standard nav transition only, degraded under reduce-motion. Pitfalls: grouping/parsing in the View (T03/T01 own data shape); a sixth bottom-nav tab; the legend reachable only from inside an expansion; a per-card "read" checkmark; styling the loading spinner as progress-toward-done; a deep link that bypasses the `appReady` guard; any `DateTime.now()` or write path in the module.

## Tests

All deterministic, offline by construction, seeded fixtures, no clock (there is no date on this surface). The structural no-gamification test is **written first**.

- `features/test/science/science_view_model_test.dart` (unit) — `ProviderContainer.test()` with a seeded fake T03 provider: the UI state lists groups in A–J order, omits empty groups, passes rows through unmodified, and is immutable; a recording repository/db double asserts **zero writes** across build, refresh, and disposal; no clock provider is read.
- `features/test/science/science_screen_test.dart` (widget) — **written first**: the loaded state renders the theme cards in register order with T04/T05 row widgets as entries; the **structural no-gamification assertion**: the data-state tree contains no `LinearProgressIndicator`/determinate progress semantics, no badge/streak/counter widget, and no "N of M"-shaped text in any locale; the legend affordance is present, ≥48dp, and opens the E10-T06 leaf; the error state shows a calm retry with no guilt string.
- `features/test/science/science_theme_card_test.dart` (widget) — one seeded group renders a single card whose title is a `Semantics` header and whose entries appear in the register's row order; an empty group renders no card at all; the card holds no tappable chrome besides its composed rows (no expand/collapse "completion" affordance of its own).
- `features/test/science/science_route_test.dart` (widget/router) — the Settings/About entry row navigates to the science route under the `ShellRoute`; the bottom nav still exposes exactly five tabs in RTL order; with a fake un-ready `appReady` double, the route redirects per the E07 guard instead of rendering.
- `features/test/science/science_strings_test.dart` (unit) — every chrome key this task registers exists in the ar template; no ARB key of a "cards read"/count-progress form exists; the banned-phrase lint passes over the chrome keys' values once T09 lands (guarded here for the ar placeholders).
- Offline guard: the suite runs under a throwing `HttpOverrides` (eng-write-dart-test) — the screen opens no socket. (The per-locale full-screen golden matrix, grayscale/deuteranope grade check, and 200%-scale goldens are consolidated in E19-T10.)
