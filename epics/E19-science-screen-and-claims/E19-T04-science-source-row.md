## Goal

The atomic row of "The science we follow" exists: `ScienceSourceRow` maps **exactly one** E19-T03 register row to a calm two-layer surface. The face is a **plain-language headline** in the ḥāfiẓ's own frame (*murājaʿa*, pages, juz, cycle — `type.body`, common words, active voice); the named-and-dated source (author/year/venue as readable **on-device text**), the composed E10 `CertaintyLabel`, and any caveat live in an optional **"the evidence"** expansion. The whole row is `MergeSemantics`-merged into **one localized phrase** (headline + source + confidence label + "external link"), decoration `ExcludeSemantics`. This task owns the base (empirical) row anatomy and its two-layer/semantics/RTL scaffolding: it **composes — never re-authors —** E10-T06's `CertaintyLabel` / `certaintyLabel(EvidenceGrade)` mapping, and it renders **no hand-written science** — every word on the row comes off the verified register row it is handed. The `[TRAD]` variant (E19-T05), the external-link launch behaviour (E19-T06 — this task leaves only the slot), the screen/legend (E19-T07), and the ARB values (E19-T09) are siblings, not here.

## Implementation notes

This task is presentation-only and **test-first on the render + semantics invariants**: no parsing, no provider, no clock, no socket, no launch logic. The row is handed one typed register row (T01's model, via T03) and formats it; if a field it needs is absent, that is a T01/T02 data defect — never a fallback the row invents.

1. **Files** (in the `features` umbrella package, `lib/src/science/widgets/`, per the eng-add-feature-module anatomy — the `science` module scaffold + screen mount is E19-T07's, this task adds only the leaf composition and its tests): `science_source_row.dart` (the two-layer row) and `source_citation.dart` (the named/dated on-device reference line with the link slot). Both take a pre-built register-row value; the **only** local state is the ephemeral collapsed/expanded flag (an explicit two-state model per 07-components §6) — no persistence, no Riverpod state, no `DateTime.now()`.
2. **The face is the plain headline, nothing else.** One `Text` in `type.body`, the ḥāfiẓ's frame (murājaʿa/pages/juz/cycle), active voice; no source, grade, effect size, or paradigm label on the face (11 §3). Any technical term (FSRS, retrievability) appears only inside the expansion with its one-line gloss — the gloss text itself comes from the register row/ARB, never composed in the widget.
3. **"The evidence" expansion: source → certainty → caveat, on demand.** Opens/closes with `motion.duration.medium` + `motion.curve.standard`, degrading to instant under reduce-motion. It contains: the `SourceCitation` line (author/year/venue, `type.caption`/`color.text.secondary`), the composed E10 `CertaintyLabel` (confidence sentence + short text tag, e.g. "meta-analysis", as the glossed secondary), and the caveat/simplification note when the row carries one (C-047's "surfaced as a limit, not hidden" path). Expansion is inline reveal, never a navigation push.
4. **View, never author.** Every rendered string traces to the passed register row (id, headline, source(s), sealed `EvidenceGrade`, caveat, optional URL) or to an ARB key this task registers; no literal in the widget files asserts a fact (grep-verifiable). The raw `[MA]`-style bracket tags are an authoring convention and never appear in the UI (ui-certainty-label point 4).
5. **Compose the grade — never restyle it.** The grade renders **only** via E10-T06's `CertaintyLabel`: one neutral container for all grades, strength carried by the text phrase + non-color glyph. Forbidden in this row forever: ★ ratings, "proven," a percentage, traffic-light/hue-coded strength, any retention number, any wording about *the user's* pages being safe — the grade is confidence about the **evidence** (11 §5), and the "never safe to drop" axiom is untouchable.
6. **The citation is on-device text; the year is a locale numeral.** Author/year/venue render as readable text (useful in airplane mode); the year routes through `numberFormatFor(locale)` (E10-T01) with the pinned numbering system — ۱۹۹۹ for fa/ckb, ١٩٩٩ for ar, **never** ASCII digits spliced into the localized run (`type.numeral`). The Latin author/venue run is FSI/PDI-isolated so it never reorders the RTL line.
7. **The link slot, not the link.** When the row carries a URL, reserve the affordance at the logical **end**: the non-color "opens externally" glyph + the keyed "opens in your browser" hint, the tappable region ≥48dp `touch.min`, wired to an optional callback. No `url_launcher` import, no launch/offline logic — E19-T06 plugs in here. With no URL, the slot collapses and "external link" drops out of the semantic phrase.
8. **One merged semantic phrase.** Wrap the row in `MergeSemantics` so a screen reader hears headline + source + confidence label + "external link" as **one** localized node — the year and Latin runs voiced via their locale/bidi tags, the glyph announced as words, dividers/ornament `ExcludeSemantics`. The expansion control additionally exposes its expanded/collapsed state.
9. **RTL by geometry, keys not values.** `EdgeInsetsDirectional`/`AlignmentDirectional` only (`space.4` padding, `space.2` gaps); direction derived from the locale, never hardcoded. Every user-facing string is an `l10n.*` key registered through the ARB pipeline (ar template) — E19-T09 authors/transcreates the fa/ckb/ar values; nothing user-facing is hardcoded, and the copy register passes the adab floor (calm, declarative, no counts, no urgency, no decay-as-threat).
10. **Pitfalls to avoid:** re-implementing the grade badge or `certaintyLabel` mapping locally (compose E10-T06); rendering the raw `[MA]` bracket tag; an ASCII year or un-isolated Latin run; hue-coding the grade or any color-alone meaning; building link launch (T06) or `[TRAD]` collection+number framing (T05) here; parsing `CLAIMS.md` text in the widget (T01 owns parsing); a "N of M sources read" count or badge-for-expanding; putting the source or grade on the collapsed face; truncating at 200% instead of reflowing.

## Acceptance criteria

- [ ] `science/widgets/science_source_row.dart` and `source_citation.dart` exist in the `features` package; each takes a pre-built register-row value; grep over the files finds no parsing, no provider, no `DateTime.now()`, no networking or `url_launcher` symbol, and no literal science claim/citation string.
- [ ] The collapsed face shows **only** the plain headline in `type.body` (user's frame); source, grade, and caveat appear only inside "the evidence" expansion, which opens inline at `motion.duration.medium`/`motion.curve.standard` and is instant under reduce-motion.
- [ ] The grade renders **only** via the composed E10 `CertaintyLabel`: confidence sentence + short text tag + non-color glyph in one neutral container identical across grades — no star, "proven," percentage, hue-coded strength, retention number, or raw bracket tag anywhere in the tree.
- [ ] The citation renders author/year/venue as on-device text; the year renders via `numberFormatFor(locale)` in the locale digit set (Extended Arabic-Indic fa/ckb, Arabic-Indic ar); the Latin author/venue run is FSI/PDI-isolated; no ASCII digit appears in any localized run.
- [ ] With a URL present, the external-link slot renders at the logical end (glyph + keyed "opens in your browser" hint, ≥48dp `touch.min`) and fires only the injected callback; with no URL the slot is absent from layout and semantics.
- [ ] The row is `MergeSemantics`-merged into one localized phrase — headline + source + confidence label + "external link" (when present) — with decoration `ExcludeSemantics` and the expansion state exposed.
- [ ] The caveat/simplification note renders in the expansion when (and only when) the register row carries one, in the same calm register — a limit stated plainly, never hidden and never dramatized (C-047).
- [ ] Layout is RTL by geometry (`EdgeInsetsDirectional`, `space.*`, no `left`/`right`); the row reflows at 200% text scale with no truncation or horizontal scroll; text meets ≥4.5:1 across light/sepia/dark.
- [ ] One shared anatomy serves every empirical grade ([MA]/[RCT]/[EXP]/[CS]/[OBS]/[TEXT]) with no per-grade fork or styling branch — per-grade phrase coverage is already pinned by E10-T06's own tests — so E19-T05 can extend the row (extra `[TRAD]` fields) without re-implementing it.
- [ ] Every user-facing string is an `l10n.*` ARB key (ar template) flagged for E19-T09 transcreation; no hardcoded user-facing text; the wording passes the adab conscience pass (calm, no coercion, no counts).

## Tests

All deterministic, offline by construction (the suite bootstrap installs a throwing `HttpOverrides`; eng-write-dart-test), real bundled UI fonts, seeded register-row fixtures built from verified `CLAIMS.md` entries — never invented rows. **Written first** for the render + semantics invariants; the consolidated per-locale golden matrix, deuteranope sweep, and link-tap offline guard live in E19-T10.

- `features/test/science/science_source_row_test.dart` (widget) — **written first**: a C-041 fixture ([MA]/[EXP]) shows the plain headline alone on the collapsed face; expanding reveals *Deci, Koestner & Ryan, 1999* + the composed `CertaintyLabel`; a C-047 fixture ([OBS]) additionally renders its caveat ("stated as a limit") in the expansion; asserts the tree contains no `★`, no `%`, no "proven", no raw `[MA]`/`[OBS]` bracket tag, and no retention-percentage or "safe to drop" wording for any fixture.
- `features/test/science/science_source_row_semantics_test.dart` — `MergeSemantics` yields exactly one node whose localized phrase carries headline → source → confidence label → "external link" (when a URL exists) and omits "external link" when none does; decorative glyph/divider are excluded; the link slot and expansion control are ≥48dp; expanded/collapsed state is exposed.
- `features/test/science/science_source_row_numerals_bidi_test.dart` — across fa/ckb/ar the year renders ۱۹۹۹ (fa/ckb) / ١٩٩٩ (ar) via `numberFormatFor(locale)`; an ASCII-digit scan over the rendered text fails on any `0-9`; the Latin author/venue run is wrapped in FSI/PDI and the RTL line order is stable around it.
- `features/test/science/science_source_row_no_color_test.dart` — the grade survives without color: with color stripped (grayscale render), the text tag + non-color glyph still distinguish an [MA] from an [OBS] fixture; the badge container is byte-identical in styling across grades (no traffic light). (The full grayscale/deuteranope golden sweep is E19-T10.)
- `features/test/science/science_source_row_reflow_test.dart` — at 200% text scale across fa/ckb/ar the headline and expansion wrap with no `RenderFlex` overflow, truncation, or horizontal scroll; text-contrast guideline assertions pass across light/sepia/dark.
- Link-slot contract: tapping the slot fires the injected callback exactly once and opens no socket under the throwing `HttpOverrides`; no launch/offline behaviour asserted here (E19-T06 owns it).
