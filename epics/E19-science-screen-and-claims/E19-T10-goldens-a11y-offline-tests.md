## Goal

The consolidated test closure for the science surface — tests only, no production code. Three deliverables: (1) the **per-locale golden matrix** the row/screen tasks deferred here — the expanded **C-041** row (the [MA]/[EXP] no-streaks trust-signal claim), the expanded **C-035** row (the [TRAD] decay ḥadīth, *Ṣaḥīḥ al-Bukhārī* 5032, via the T05 variant), and the full "The science we follow" screen (theme cards + grade legend + the T08 honesty surfaces), each captured across **fa × ckb × ar at 1× and 200% text scale** on the **real bundled UI fonts** — proving the longest transcreation (ckb) reflows without clipping; (2) the **grayscale/deuteranope check** that the evidence grade survives with color removed — the `CertaintyLabel`'s text tag + non-color glyph still convey and distinguish the grades, never color alone; (3) the **`HttpOverrides` offline guard** proving a source-link tap in the composed screen triggers no in-app network call and the whole surface renders in airplane mode from bundled data. This task does **not** re-test unit/parser logic (T01), the coverage gate (T02), or read-model logic (T03) — those are pinned in their own tasks; it sweeps the *integrated* surface T04–T09 built.

## Implementation notes

This task ships test files only — zero production widget, provider, or string changes. If a golden or guideline exposes a defect (a ckb clip, a color-only grade, a stray socket), the fix lands in the owning sibling's files and this suite re-runs; this task never patches the surface itself.

1. **Files** (all under `features/test/science/`, masters under `features/test/science/goldens/`): `science_row_locale_golden_test.dart`, `science_screen_locale_golden_test.dart`, `science_grade_color_independence_test.dart`, `science_a11y_guidelines_test.dart`, `science_rtl_reading_order_test.dart`, `science_offline_guard_test.dart`. Golden files are tagged `@Tags(['golden'])`; the rest run untagged in the fast job.
2. **Fixtures are the real register rows, never hand-authored.** Seed the T03 provider (Riverpod override, in-memory) with the *parsed* bundled register entries for **C-041** and **C-035** — renderer-never-author holds in tests too: no claim headline, source, or grade string is typed into a fixture by hand, so a register correction flows into the goldens instead of silently diverging from them.
3. **The matrix shape:** {C-041 row, expanded · C-035 row, expanded · full screen} × {fa, ckb, ar} × {`TextScaler.linear(1.0)`, `TextScaler.linear(2.0)`} = 18 masters, named `goldens/science_<surface>_<locale>_x<scale>.png`. Each pump wraps in `MaterialApp` with the target `locale` (app-wide `Directionality.rtl` follows from the locale), the T09 delegates, and pinned `devicePixelRatio`/`physicalSize`/theme; animations disabled; `await expectLater(finder, matchesGoldenFile(...))`.
4. **Real bundled UI fonts, deliberately.** Load the app's bundled UI fonts via `FontLoader` in `setUpAll` — the eng-write-dart-test allowance of a font-independent strategy for layout goldens is **not taken here** (the epic DoD forbids it): the ckb-reflow proof depends on real string metrics, and Ahem squares would fake it. Never register a KFGQPC QPC page font — no āyah is typeset anywhere on this surface; C-035 appears as collection + number UI text.
5. **200% is proven twice:** the ×2.0 goldens freeze the reflowed layout, and programmatic assertions back them — no `RenderFlex` overflow error surfaces during the pump, and the screen exposes no horizontal scroll extent (SC 1.4.4/1.4.10; checklist A4). Assert the load-bearing runs (headline, source attribution, certainty phrase, "opens in your browser" hint) are fully visible in ckb, the longest transcreation.
6. **Grayscale + deuteranope (A3, 09 §4, 11 §7):** re-pump the C-041 and C-035 rows under a `ColorFiltered` harness — once with a saturation-0 (grayscale) color matrix, once with a standard deuteranopia-simulation matrix — golden-capture each, and assert programmatically that the `CertaintyLabel`'s **text tag and non-color glyph** are present and that the [MA] and [TRAD] renderings remain mutually distinguishable with hue removed. The grade must read perfectly for a user who sees no color.
7. **`meetsGuideline` sweep (A1, A6, A7):** over the pumped screen run `textContrastGuideline` in every appearance (light/sepia/dark/night per 09 §3), plus `androidTapTargetGuideline`, `iOSTapTargetGuideline`, and `labeledTapTargetGuideline` — the T06 link affordance must be ≥48×48dp and carry a localized (never English-only) semantic label in each of fa/ckb/ar.
8. **RTL reading order (A8, 09 §8):** per locale, walk the semantics tree in traversal order and assert it matches the visual order — each row reads as **one** merged phrase (headline → source → confidence label → external-link hint, T04's `MergeSemantics` contract), and the mixed runs inside it neither display nor read reordered: FSI/PDI-isolated Latin author/venue runs (Deci, Koestner & Ryan), years and hadith numbers in the locale digit set (۱۹۹۹ for fa/ckb, ١٩٩٩ for ar; Bukhārī ٥٠٣٢) via the shared numeral path — never raw ASCII spliced into an RTL string.
9. **The offline guard (testing-strategy §7):** the shared throwing-`HttpOverrides` bootstrap stays installed for every test in this suite. Pump the full screen from the bundled fixtures — it must render completely with zero network (the airplane-mode proof for this surface). Then tap the C-041 row's source link with the T06 launch boundary replaced by a **recording fake**: assert exactly one OS handoff was recorded and no in-app `HttpClient` was created (the override would throw loudly). Repeat with the fake reporting "cannot launch" to cover the composed offline-degrade path — still zero sockets, no error surface beyond T06's calm degradation.
10. **Pitfalls to avoid:** re-pinning T01/T02/T03 logic here (parser branches, gate failures, provider caching — owned elsewhere); typing claim/source/grade text into a fixture by hand; Ahem or any placeholder font; a QPC glyph font in a test of this surface; goldens generated on macOS or an un-pinned SDK (masters come only from the pinned golden job's environment via a reviewed `--update-goldens`); `pumpAndSettle()` against an indefinite indicator (none should exist on this calm surface — finding one is itself a defect to raise); letting the link test reach a real platform launcher instead of the recorded boundary; asserting a retention percentage or star rating anywhere (their *absence* is part of what the goldens freeze).

## Acceptance criteria

- [ ] The 18-master golden matrix exists ({C-041 row · C-035 row · full screen} × fa/ckb/ar × 1×/200%), is `@Tags(['golden'])`, renders on the real bundled UI fonts loaded via `FontLoader` (no Ahem, no QPC font registered anywhere in the suite), and is byte-stable on the pinned Linux golden job.
- [ ] The ckb ×2.0 goldens show every load-bearing run unclipped, and the programmatic checks pass in all three locales: no `RenderFlex` overflow, no horizontal scroll extent at 200%.
- [ ] Under both the grayscale and the deuteranopia simulation, the grade is conveyed by its text tag + non-color glyph, and the C-041 ([MA]) and C-035 ([TRAD]) renderings remain distinguishable — never color alone.
- [ ] `meetsGuideline` passes over the screen: `textContrastGuideline` in all four appearances, `androidTapTargetGuideline` + `iOSTapTargetGuideline` (link affordance ≥48×48dp), `labeledTapTargetGuideline` with fa/ckb/ar labels.
- [ ] Per-locale RTL reading-order assertions pass: semantics traversal = visual order; each row is one merged phrase; Latin runs FSI/PDI-isolated; years/hadith numbers in the locale digit set.
- [ ] Under the throwing `HttpOverrides`, the whole surface renders from bundled fixtures, a link tap records exactly one OS handoff with zero in-app sockets, and the cannot-launch path degrades calmly with still zero sockets.
- [ ] Every suite runs in CI on every PR — goldens in the pinned golden job, guideline/reading-order/offline tests in the fast job; no gate is skipped or auto-blessed.
- [ ] The committed `goldens/` directory contains exactly the named masters (no orphan or unreviewed image); each master entered the repo through a reviewed diff, never a CI-side regeneration.
- [ ] This task changed no production code; every fixture row is the real parsed C-041/C-035 register entry, injected via a T03 provider override.

## Tests

All deterministic and offline by construction: seeded register fixtures (no parser re-test), no clock, the throwing `HttpOverrides` bootstrap, pinned fonts/DPR/theme, in-memory Riverpod overrides only.

- `features/test/science/science_row_locale_golden_test.dart` (golden, `@Tags(['golden'])`) — the expanded C-041 [MA] row and C-035 [TRAD] row, fa × ckb × ar × 1×/200%, real bundled UI fonts; pins the deferred per-locale row matrix including the T05 collection+number framing and the "needs scholarly review" note where the fixture carries it.

- `features/test/science/science_grade_color_independence_test.dart` (widget + golden) — grayscale and deuteranopia `ColorFiltered` pumps of both fixture rows; asserts the text tag + non-color glyph carry the grade and the two grades stay distinguishable without hue (A3).
- `features/test/science/science_a11y_guidelines_test.dart` (widget) — the `meetsGuideline` sweep: `textContrastGuideline` per appearance, both tap-target guidelines, `labeledTapTargetGuideline`; asserts the link label resolves through the T09 ARB pipeline in each locale (A1, A6, A7).
- `features/test/science/science_rtl_reading_order_test.dart` (widget) — per-locale semantics-traversal-equals-visual-order assertions; one merged phrase per row; bidi-isolation and locale-numeral assertions on the Latin author/year and hadith-number runs (A8).
- `features/test/science/science_offline_guard_test.dart` (widget) — the throwing-`HttpOverrides` airplane-mode render of the full screen; the link-tap handoff via the recording T06 boundary fake with zero in-app sockets; the cannot-launch degrade path, still zero sockets.

## Definition of Done

- [ ] All acceptance criteria met; every suite green in CI on every PR — goldens byte-stable in the pinned Linux job, the rest in the fast job; masters regenerated only by a locally-run, human-reviewed `--update-goldens`.
- [ ] **Offline / no-network**: the throwing `HttpOverrides` stays installed suite-wide; the surface renders in airplane mode from bundled data; a source-link tap triggers no in-app fetch (OS handoff only); this task adds no networking import, giving the banned-import and dependency-allow-list gates nothing to catch (PRD §20 gate 6).
- [ ] **No AI / no microphone**: nothing in this suite records, transcribes, or simulates audio or a model; the fixtures are static register rows (PRD C1/C2).
- [ ] **Quran text fidelity (R1)**: no test renders, masks, or re-typesets an āyah or registers a QPC glyph font; the [TRAD] ḥadīth appears as collection + number UI text (*Ṣaḥīḥ al-Bukhārī* 5032), and the goldens use only the bundled UI fonts — never Ahem, never the page fonts.
- [ ] **Never "safe to drop" / no promise**: no assertion or golden introduces a retention percentage, star rating, "proven" badge, or "mastered"/"safe" state; the grade is frozen as confidence-about-the-evidence (text tag + glyph) and its color-independence is proven, not weakened.
- [ ] **No gamification / no shame (R3, C6)**: the screen goldens freeze a surface with no streak, badge, progress bar, or "N of M read" counter, and the C-041 fixture renders the registered no-coercion claim as a sourced trust signal — the suite would fail if engagement chrome ever appeared.
- [ ] **Renderer, never author**: every fixture is the real parsed C-041/C-035 row injected through the T03 provider; no claim, citation, or grade string is hand-written in test data, so the goldens can never launder an unregistered fact.
- [ ] **RTL + fa/ckb/ar localization**: the full fa × ckb × ar matrix passes on T09's transcreated strings; locale numerals via the shared numeral path; FSI/PDI-isolated Latin runs; ckb reflows without clipping at 200%; no locale is "assumed from another" (PRD §20 gate 5).
- [ ] **Accessibility (WCAG 2.2 AA)**: the automated halves of checklist rows A1, A3, A4, A6, A7, A8 (09 §10) are closed for this surface by this suite; A9 (manual TalkBack/VoiceOver in fa/ckb/ar) is recorded as a pending human pass for release — never claimed as automated.
- [ ] **Deterministic tests**: no wall clock, no network, no real DB/assets (in-memory Riverpod overrides only); fonts, DPR, size, theme, and the golden runner are pinned; the suite produces identical results on every run.
