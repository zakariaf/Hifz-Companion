## Goal

The `docs/science/CLAIMS.md` register exists inside the app as **typed, immutable, read-only data**: one value object per registered row carrying its `C-NNN` id, the plain claim headline (as the app states it), the value/rule the engine uses, the named source(s) verbatim (author/year/venue, or hadith collection + number + grading), the parsed **sealed `EvidenceGrade`(s)** from E10-T06, the app surface, and the caveat — grouped A–J (A memory & forgetting · B spacing · C engine math · D retrieval · E interference · F serial recall · G overlearning · H methodology · I motivation · J cross-cutting honesty). The data ships **inside the app binary / verified core pack** as a byte-copy of the register doc, is loaded and parsed **once**, and is never fetched. The parser is **fail-closed**: an unknown or missing grade, a missing column, an empty field, or a duplicate id is a typed, release-blocking data defect — never a render fallback. This is the epic's sole register-text → typed-data task; it writes no gate (T02), no provider (T03), no widget (T04/T05/T07), and no ARB string (T09). The parser suite is written **first**.

## Implementation notes

**TEST-FIRST:** write `claims_register_parser_test.dart` (§Tests) before the parser body. A mis-parsed grade or a silently dropped caveat ships a wrong methodology claim straight to a ḥāfiẓ — the fixtures must exist and fail before the parser is filled in.

1. **Files** (in the `features` umbrella package — the only layer that may reference the E10-T06 `EvidenceGrade`, per the downward-only dependency rule — under `lib/src/science/register/`):
   - `claim_group.dart` — `enum ClaimGroup` with the ten A–J groups, in register order.
   - `claim_source.dart` — immutable `ClaimSource`: the citation text **verbatim** from the source cell (author/year/venue, or collection + number + grading) plus the optional URL, split out only so T06 can render a link; the readable text never depends on the URL.
   - `claim_row.dart` — immutable `ClaimRow`: `id` (validated `C-NNN` shape), `group`, `headline` (Claim-as-stated column, verbatim), `valueRule`, `sources` (non-empty `List<ClaimSource>`), `grades` (non-empty ordered `List<EvidenceGrade>`, first = primary as authored), `surface`, `caveat`. All fields `final`; `const` where possible; no setter, no copy-with-mutation surface.
   - `claims_register.dart` — immutable `ClaimsRegister` collection: `rows` (register order), `byId(String)`, `byGroup(ClaimGroup)`; plus the thin one-time `loadClaimsRegister(AssetBundle)` that reads the bundled asset and delegates to the pure parser. No caching cleverness beyond parse-once; no clock; no I/O other than the single asset read.
   - `claims_register_parser.dart` — the **pure** `ClaimsRegister parseClaimsRegister(String registerText)` plus a sealed `ClaimsRegisterDefect` error family (unknown grade token, missing/extra column, empty field, malformed id, duplicate id, unknown group heading). Pure Dart: no Flutter import beyond what the value types need, no `dart:io`, no `DateTime`, no randomness.
2. **The bundled asset is a byte-copy of the doc.** Register the asset (e.g. `assets/science/claims_register.md`) as a build-time byte-copy of `docs/science/CLAIMS.md`, and pin the pair with a lockstep SHA-256 check (test or `tool/` gate script in the §11.1.1 build-time-manifest discipline) that fails when they diverge. This makes "renderer, never author" mechanical: there is no second authored artifact to drift, and corrections ship as an app/pack update because the asset travels in the binary/core pack.
3. **Parse the seven-column group tables, nothing else.** The parser walks the `## <letter>. <name>` group headings and each table row, mapping cells positionally to the seven columns. It ignores the intro, legend, and References sections (they are doc apparatus, not rows). It does **not** interpret, reflow, translate, summarize, or normalize any cell content — markdown emphasis and links inside a cell are preserved in the stored text (stripping presentation is the renderer's business, and only where the docs allow).
4. **Grades reuse `EvidenceGrade.parse` — compound cells are lists.** Split the grade cell on `/`, trim, and feed each token to the E10-T06 `EvidenceGrade.parse`. A row therefore exposes a **non-empty ordered list** (C-016 → `[exp, trad]`; C-041 → `[ma, exp]`); how multiple grades render is T04's concern, carrying them faithfully is this task's. Any token that is not one of the seven throws the typed defect — **no default, no "closest match", no skip-the-row**.
5. **`[TRAD]` cells round-trip byte-exact.** The transliterated source strings carry combining diacritics (*Ṣaḥīḥ*, *ʿarḍa*, *manāzil*) and mixed-script runs; the parser must be UTF-8-clean end to end so C-035/C-036/C-039 sources re-emit identical to the doc. The typed row adds no interpretation: no ruling field, no "authenticity" flag, nothing beyond the register's own words — the no-fiqh-ruling and needs-scholarly-review framing lives in the caveat/source text exactly as authored.
6. **No field is silently empty.** Every parsed row has a non-empty id, headline, value/rule, ≥1 source, ≥1 grade, surface, and caveat. An empty cell is a `ClaimsRegisterDefect`, because a row missing its source or caveat is precisely the "unsourced claim" the register exists to prevent (CLAIMS intro; skill pattern 2).
7. **Loaded once, never fetched.** `loadClaimsRegister` reads the bundled asset exactly once at composition time (T03 decides when); there is no refresh path, no remote URL, no conditional re-fetch. No networking symbol, no `HttpClient`, no `DateTime.now()` appears anywhere in `science/register/` (the banned-import gate must have nothing to catch).
8. **Known data defect — C-048 (STOP-AND-RAISE, do not improvise).** The register's C-048 grade cell currently reads `[TRAD-equivalent project rule]`, which is not one of the seven tokens. Per the fail-closed rule the parser must reject it — which means the full-register parse cannot go green until the science foundation normalizes that cell (a `CLAIMS.md` amendment, out of scope for this epic per the EPIC's out-of-scope list). Raise the amendment against the foundation and leave the end-to-end asset test red-flagged as blocked on it; do **not** hard-code a special case, coerce the cell to `trad`, or edit `CLAIMS.md` from this task.
9. **Pitfalls to avoid:** redefining `EvidenceGrade` or re-implementing tag parsing locally (reuse E10-T06); a fallback/default grade for an unknown token; hand-authoring "just this one" row in Dart (every row comes from the parsed asset); storing the grade as a `String`; a mutable list escaping `ClaimsRegister` (return unmodifiable views); normalizing/prettifying source text (it must round-trip); parsing `docs/science/CLAIMS.md` from the filesystem at runtime instead of the bundled asset; a network call, clock read, or model anywhere in the load path; writing ARB strings or widgets here (T09/T04+).

## Acceptance criteria

- [ ] `claim_group.dart`, `claim_source.dart`, `claim_row.dart`, `claims_register.dart`, `claims_register_parser.dart` exist under `features/lib/src/science/register/`; every value type is immutable (all-`final` fields, no mutation surface, unmodifiable collections).
- [ ] Each parsed `ClaimRow` carries all seven columns typed: validated `C-NNN` id, A–J `ClaimGroup`, verbatim headline, value/rule, ≥1 verbatim `ClaimSource`, ≥1 ordered E10-T06 `EvidenceGrade`, app surface, and caveat — no field silently empty, ids unique.
- [ ] The grade cell is parsed via the reused `EvidenceGrade.parse` (never a local re-implementation or a raw `String`); compound cells (`[EXP] / [TRAD]`) yield ordered lists; an unknown token throws a typed `ClaimsRegisterDefect` — no fallback, no skipped row.
- [ ] `[TRAD]` source strings round-trip byte-exact, diacritics intact (C-035 *Ṣaḥīḥ al-Bukhārī* 5032 / *Ṣaḥīḥ Muslim* 791; C-039 *Ṣaḥīḥ al-Bukhārī* 4998; C-036 seven manāzil), and the typed row adds no ruling, authenticity verdict, or interpretation beyond the register's own text.
- [ ] The register ships as a bundled asset that is a byte-copy of `docs/science/CLAIMS.md`, pinned by a lockstep SHA-256 check that fails on any divergence; `loadClaimsRegister(AssetBundle)` reads it exactly once and there is no other load or refresh path.
- [ ] `ClaimsRegister` exposes `rows`, `byId`, and `byGroup` lookups only — no mutation, no provider (T03), no widget (T04+), no gate logic (T02), no ARB string (T09).
- [ ] No networking import/symbol, no `DateTime`/clock read, no randomness, and no model anywhere under `science/register/` (verifiable by grep; the banned-import gate stays green).
- [ ] The C-048 `[TRAD-equivalent project rule]` grade cell is raised to the science foundation as a register amendment and documented as the known blocker of the end-to-end asset parse — with no coercion or special case coded around it.

## Tests

All deterministic, offline by construction: pure-Dart parsing over fixture strings and the bundled asset, no clock, no widget pump; every suite installs the E10-T02 throwing-`HttpOverrides` bootstrap in `setUp`.

- `features/test/science/register/claims_register_parser_test.dart` (unit) — **written first**:
  - every one of the seven grades parses at least once into the right `EvidenceGrade` — from verbatim register-row fixtures where one exists (C-041 `ma`, C-016 `exp`, C-025 `obs`, C-017 `text`, C-035 `trad`) and from synthetic seven-column fixtures for `rct` and `cs` (the register currently has no pure-`[RCT]` row — noted in the test);
  - compound grade cells parse to ordered lists: C-016 → `[exp, trad]`, C-041 → `[ma, exp]`;
  - **`[TRAD]` round-trip**: the C-035, C-036, and C-039 fixture rows re-emit their source strings byte-identical (collection + number + grading, diacritics and mixed-script runs intact);
  - **no-fallback rule**: an unknown grade token (`[XYZ]`, empty cell, and the literal `[TRAD-equivalent project rule]`) throws the typed `ClaimsRegisterDefect` — the suite asserts the *type*, not just "throws";
  - every parsed row exposes non-empty id + headline + value/rule + ≥1 source + ≥1 grade + surface + caveat; a fixture with an empty caveat cell fails the parse;
  - malformed id (`C-9`, `X-001`), duplicate id, missing column, and unknown group heading each throw their typed defect;
  - group mapping: fixture rows under each of the ten A–J headings land in the right `ClaimGroup`.
- `features/test/science/register/claims_register_asset_test.dart` (unit) — the end-to-end contract on the real bundled asset: it loads via `loadClaimsRegister` exactly once, parses with zero defects, yields unique ids, all ten groups populated, and `byId`/`byGroup` agree with `rows`. (Documented as blocked-red on the C-048 amendment until the foundation normalizes the cell — the failure is the fail-closed design working, not a test to skip.)
- Lockstep check (test or `tool/` gate script, run in CI): SHA-256 of the bundled asset equals SHA-256 of `docs/science/CLAIMS.md`; any divergence fails.
- **Offline guard**: with the throwing `HttpOverrides` installed, the full load-and-parse path completes — proving it opens no socket; a negative check asserts a deliberate `HttpClient()` attempt throws the named error (eng-write-dart-test pattern 8).

## Definition of Done

- [ ] All acceptance criteria met; the parser suite was written first and is green; the asset suite is green except the documented C-048 blocker, which is raised to the science foundation as a register amendment.
- [ ] **Renderer, never author**: every field of every typed row mirrors a `docs/science/CLAIMS.md` cell; no claim text, source, grade, or caveat is hand-written in Dart; the byte-copy asset + lockstep checksum make drift a build failure, and corrections ship only as an app/pack update (11 §2; PRD §11.1.1).
- [ ] **Offline / no-network**: the register is bundled and parsed locally, loaded once, never fetched; no networking symbol under `science/register/`; the throwing-`HttpOverrides` suites pass (PRD C1).
- [ ] **No AI / no microphone**: nothing here records, transcribes, infers, or generates — the parser is a deterministic text-to-value mapping over pre-authored, reviewed register text (PRD C2, R5).
- [ ] **Quran text fidelity (R1)**: this task renders nothing and re-typesets nothing; hadith citations are carried as on-device *text* (collection + number), never as rendered muṣḥaf glyphs; verbatim round-tripping preserves every diacritic of the transliterated sources.
- [ ] **Never "safe to drop" / no invented certainty**: the typed row adds no field, flag, or derivation that could soften a caveat or promise an outcome — the no-promise rows (C-016, C-017, C-025, C-047) reach the screen exactly as registered, and the grade stays evidence-strength only (ui-certainty-label pattern 1).
- [ ] **Sect-neutral adab**: `[TRAD]` rows (C-035, C-036, C-039, C-046) pass through as named methodology with collection + number + grading verbatim — no fiqh ruling, no authenticity verdict, no reordering of `[TRAD]` above empirical grades; anything ambiguous in the register is raised for scholarly review, never resolved in code.
- [ ] **No gamification / no shame**: this data spine introduces no mechanic, counter, or copy of any kind; the non-coercion claims (C-041, C-048) are carried as data for T07/T08 to render calmly.
- [ ] **RTL + fa/ckb/ar**: no user-facing string ships from this task; the localized headlines/attributions are T09's ARB work keyed by `C-NNN`, and the typed rows preserve the canonical register text (UTF-8/bidi-safe) those transcreations trace back to.
- [ ] **Accessibility**: no widget is rendered here; the a11y obligations (merged semantics, contrast, reflow, non-color grade) attach to T04–T07/T10, which consume this data unchanged.
- [ ] **Deterministic tests**: pure functions over fixed fixtures and a pinned asset — no clock, no randomness, no network; the sealed defect family makes every failure mode a typed, named assertion; all gates stay green.
