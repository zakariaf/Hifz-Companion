## Goal

Every reminder string ships **transcreated — never literally translated — into fa/ckb/ar** through the `gen_l10n` ARB pipeline, and the **release-blocking banned-phrase voice gate** runs over all of them in all three locales. This task OWNS all reminder copy; siblings only reference keys. The inventory: the row title + the honest one-liner under it (the E18-T06 widget consumes the keys), the daily notification title/body — the calm readiness statement glossed "Your revision for today is ready." (PRD §14; **C-043**) — the catch-up note title + count-bearing body values for the key contract E18-T09 defined (empathy → fact → path → choice; **C-042**/**C-041**), the catch-up toggle label + its one help-framed sentence, and the permission rationale/denied/blocked/open-settings wording E18-T08 registered as pending keys. Values are authored in `app_ar.arb` (the `ar` template/base content language) and transcreated with the per-locale register set **deliberately**: respectful-warm Persian, Arabic imperatives softened into statements of readiness, ckb canonical-encoded and flagged provisional pending native + scholar review. Every value passes the never-ship lint — no guilt/fear/loss, no mandate word, no "safe to drop"/"mastered"/"done", no exclamation mark or emoji, no commercial word — and the forbidden "Welcome back… N days" pattern exists nowhere as a key or value. No widget, scheduling, persistence, permission-flow, or numeral-rendering code lands here.

## Implementation notes

This task is copy + gate only: ARB values, `@description` metadata, and the test-side lint. No production Dart beyond what the lint test needs. The copy is the app's single most dangerous *adab* surface (EPIC.md — Risks), so the gate is wired **first** and the values are authored against it.

1. **Files.** `lib/l10n/app_ar.arb` (the template — new keys + final values + `@description` metadata), `lib/l10n/app_fa.arb` and `lib/l10n/app_ckb.arb` (transcreated values), and the two test files below under `features/test/reminders/`. No other file changes: the widgets (T06), controller (T03/T09), and permission flow (T08) already read `l10n.*`.
2. **Fix the inventory before writing a word.** Enumerate every reminder-surface key: `reminderRowTitle`, the honest one-liner (e.g. `reminderRowOneLiner`), the daily notification title + body (e.g. `reminderNotificationTitle` / `reminderNotificationBody`), the catch-up toggle label + help sentence, E18-T09's catch-up title + count-bearing body, and E18-T08's rationale/denied/blocked/open-settings keys. Nothing else: onboarding copy is E11's, the on-screen Today catch-up banner is E12's, Settings-shell copy is E16's. Adding a key no sibling contracted means updating that sibling's contract, not silently widening this one.
3. **Author `app_ar.arb` first; transcreate against it.** Every key lands in the `ar` template with an `@description` carrying translator/scholar context and its trace — C-043 on the daily title/body, C-042/C-041 on the catch-up pair, "states a checkable app fact; no CLAIMS row" on the permission strings, "needs native + scholar review" on anything term-set- or methodology-adjacent. `fa` and `ckb` values are transcreations diffed against `ar` — if a diff reads like a word-for-word mapping, it is wrong.
4. **Per-locale register, set deliberately (voice §8).** *fa*: respectful-warm — *šomā*/honorific verb forms as a calm stance, *taʿārof*-aware, never cold over-formality nor the over-familiar *to*. *ar*: number/gender-appropriate second person; every directive softened into a statement of readiness — no bare command verb. *ckb*: canonical Unicode (U+06D5 ە for AE, U+06A9 ک for kaf; no ZWNJ, no Teh-Marbuta-for-AE), register and any religious vocabulary set by native reviewers per PRD §13.4 — the values ship flagged provisional and are never inferred from fa or ar.
5. **The daily body is the calmest row of the tone matrix.** One neutral statement of readiness per locale, glossing "Your revision for today is ready." — no urgency, no countdown, no exclamation, no second persuasive line. The title stays equally plain (the app name or the active term-set's general "revision" word — never a hook). Any borrowed track/revision term comes from the swappable term-set (ICU `select`/region-override), never re-hard-coded here.
6. **The catch-up body follows empathy → fact → path → choice (voice §4).** Gloss: calm acknowledgment, the honest fact ("You missed N days") **only as the lead-in**, the concrete path ("an M-day catch-up that still completes your cycle"), and the choice left with the user. The body is one full ICU message over T09's `daysMissed`/`planLengthDays` placeholders with **all six** Arabic CLDR plural categories (`zero`/`one`/`two`/`few`/`many`/`other`) — never a spliced `"$count"`, never "N days lost," never a deadline.
7. **The one-liner states the checkable fact.** A neutral reminder at a time you choose; silence it anytime; local-only, nothing sent (ui-reminder-row item 7). No "we care about your privacy" rhetoric — the sentence is the in-context rationale E18-T08's OS dialog appears over, so it must be *true* and plain in all three locales.
8. **No digit ever lives in a value.** Counts and times arrive as pre-formatted placeholders (`numberFormatFor(locale)` — T07/T09 wiring); a literal digit in any ARB value this task authors — ASCII, Arabic-Indic, or Extended Arabic-Indic — is a defect. Interpolation is one full ICU message; fragments are never concatenated (RTL word order will not survive it); values carry no physical-side or hardcoded-direction assumption (FSI/PDI isolation is the `bidi.dart` helper's job at the view layer, not the string's).
9. **The banned-phrase voice gate is executable and release-blocking.** Extend the never-ship lint (the same test-side lint family E12-T04 established) to run over **every ARB value under this task's keys in fa, ckb, and ar**: guilt/fear/loss framing and its locale equivalents, mandate words, "safe to drop"/"mastered"/"done," exclamation marks (U+0021 and locale variants) and emoji, commercial-transaction words. It additionally asserts the forbidden resume-after-gap pattern — "Welcome back… you haven't opened the app in N days" — exists as **no key and no value** in the reminder namespace (voice §3: resume is silent; that row has no string). Landing these values must also turn E18-T09's already-wired `catch_up_note_banned_phrase_test` green.
10. **The adab conscience pass + human review are recorded.** Run the `domain-adab-and-religious-integrity` checklist over the full inventory and record the pass; per-locale native-speaker review for register and scholar review for any religious/methodology-adjacent wording per voice §9 / PRD §20.5 — cleared, or shipped explicitly provisional (ckb) issuing no ruling. No string speaks for the Quran, quotes a verse or hadith (this copy needs none — **never fabricate one**), implies loss of hifz, or implies revision is skippable.
11. **Pitfalls to avoid:** literal translation (silent register drift); an exclamation mark "for warmth"; a cheerful greeting or any welcome-back key; guilt dressed as concern ("you'll miss your revision" — banned by T08's contract too); a digit or date inside a value; gluing fragments; hard-coding a term-set word; attaching a CLAIMS id to the permission strings; authoring widget layout (T06), toggle behavior (T09), permission flow (T08), or numeral rendering (T07); locking ckb wording before native + scholar review.

- [ ] The banned-phrase lint passes over every value this task adds in fa/ckb/ar — no guilt/fear/loss, no mandate word, no "safe to drop"/"mastered"/"done," no `!`/emoji, no commercial word — and the "Welcome back… N days" pattern exists as no key or value in the reminder namespace.

- [ ] E18-T09's `catch_up_note_banned_phrase_test` is green with the landed values; E18-T08's pending flags are cleared to final transcreated values.

## Tests

All deterministic and offline by construction: the lint and coverage suites read static ARB content — no clock, no socket, no OS surface; the shared throwing-`HttpOverrides` guard is installed. The gate is **written first**, before the values are polished.

- `features/test/reminders/reminder_copy_banned_phrase_test.dart` (unit, **written first**) — runs the never-ship lint over every ARB value under this task's keys in fa, ckb, and ar: fails on any guilt/fear/loss framing (and its listed locale-equivalent patterns), mandate word, "safe to drop"/"mastered"/"done," exclamation mark, emoji, or commercial term; asserts no key or value in the reminder namespace matches the forbidden welcome-back / "N days since you opened" pattern; names C-043/C-042/C-041 as its trace in the test description.
- `features/test/reminders/reminder_copy_coverage_test.dart` (unit) — every key in the fixed inventory resolves in all three ARB files (zero missing keys, and the gate fails on a key present in one locale but not another); the count-bearing catch-up body defines all six Arabic CLDR plural categories; no literal digit in any authored value in any locale; every ckb value is canonically encoded (U+06D5 ە, U+06A9 ک; no U+200C) and every review-pending key's `@description` carries the provisional flag.
- Sibling gates re-run green: E18-T09's `catch_up_note_banned_phrase_test` (was failing on missing values) and the `features/**` hardcoded-string + ASCII-digit CI greps — no new suite needed, asserted in CI.
- The recorded adab conscience pass and the per-locale native/scholar review register (in the ARB `@description`s + the task's review note) — a human gate logged as part of Done, not a Dart test; the per-locale visual reflow proof lives in E18-T11's goldens.

- [ ] **No AI / no microphone (R5)**: nothing here records, listens, or generates; the copy never implies the app hears the user's recitation.
- [ ] **Quran text fidelity (R1)**: N/A by construction, asserted — this copy is UI chrome; it quotes no verse, names no hadith, and fabricates no citation; the muṣḥaf surface is untouched.
- [ ] **Never "safe to drop" (§7.12)**: no value calls a page or the backlog done, mastered, finished, or skippable; the catch-up note offers the engine's plan and never shrinks it in words.
- [ ] **No gamification / no shame (R3, C6)**: no streak, badge, or celebration language; no guilt/fear/loss framing; the resume-after-gap surface stays wordless; the daily body traces to C-043 and the catch-up framing to C-042/C-041.
- [ ] **RTL + fa/ckb/ar localization (PRD §13.6)**: every string transcreated (not literally translated) through `gen_l10n` with zero missing keys and zero hardcoded user-facing text; one-message ICU interpolation, six Arabic plural categories, no digit in values, no direction assumption; ckb canonical-encoded and provisional per §13.4.
- [ ] **Accessibility**: the values read naturally as `Semantics` sources per locale (plain sentences, no meaning carried by punctuation or emoji); the wiring itself is T06/T08's and is not regressed.
- [ ] **Sect-neutral adab**: the full inventory cleared the `domain-adab-and-religious-integrity` conscience pass and the voice §9 gate in all three locales — invitation not command, servant not authority, no fiqh ruling; religious/methodology-adjacent wording carries scholar review or an explicit provisional flag.
