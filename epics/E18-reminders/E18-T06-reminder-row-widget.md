## Goal

The dumb `ReminderRow` widget — the presentation shell of the epic's one configuration surface. Four elements, composed from E10 Mihrab primitives: (1) a **single switch, OFF by default** — never pre-ticked; opt-in is one explicit tap and one tap silences it again (design-system 10 §9's protective default made visible); (2) a **reminder-time picker that exists in the tree only once the reminder is enabled** — while off there is nothing to schedule, so no time affordance renders; (3) **one honest one-liner** beneath the row — the transcreation slot for "A neutral reminder at a time you choose. Silence it anytime." (a checkable local-only fact, no privacy rhetoric); (4) the **catch-up-note toggle as an independent sibling switch** — a structural slot only, also off by default, never nested under or coupled to the reminder switch. The row watches E18-T03's `ReminderController` state and calls its three mutations (`setEnabled`, `setReminderTime`, `setCatchUpNoteEnabled`) — nothing else. Layout is `EdgeInsetsDirectional`-only, the switch announces a `Semantics` label + on/off value per locale, every target meets 48×48dp (`touch.min`), and any time run is FSI/PDI-isolated. It *configures* a reminder: it renders no muṣḥaf, mutates no engine state, computes no schedule, and reaches no OS API. Copy values are E18-T10's (this task references ARB key slots only), the formatted time is E18-T07's (an opaque pre-rendered string slot), permission UX is E18-T08's, the catch-up note's behavior and copy are E18-T09/T10's, and the per-locale golden is E18-T11's.

## Implementation notes

This task is presentation-only: no engine call, no repository, no scheduler, no clock read, no string literal. It is the epic's *adab-critical* structure — the five-dark-pattern discipline is pinned by widget tests written **before** visual polish.

1. **Files** (in the `features` umbrella package, `lib/src/reminders/`, per eng-add-feature-module): `widgets/reminder_row.dart` — the domain-blind `ReminderRow` leaf (`template.dart` BLOCK 1): primitives + callbacks only (`enabled`, `title`, `honestLine`, `formattedTime`, `timeSemanticsLabel`, `isCatchUpNoteEnabled` + its label, `onEnabledChanged`, `onEditTimePressed`, `onCatchUpNoteChanged`); it imports no engine, data, scheduler, or l10n symbol. `widgets/reminder_settings_view.dart` — the `ConsumerWidget` wiring leaf (BLOCK 3): watches T03's provider, resolves `l10n.*` keys, hands the row its values and routes callbacks to the three mutations. Do not promote `ReminderRow` to shared `ui/` yet — that happens only if E11 (onboarding) actually reuses it (eng-add-feature-module item 10).
2. **Off-by-default is inherited, never re-decided.** The row renders whatever `enabled` value the watched T03 state carries — whose default traces to T02's schema `DEFAULT 0`. The widget never self-initializes to `true`, holds no shadow toggle state, and nothing is pre-ticked (10 §9). The `AsyncNotifier` loading/error states render via `.when` as a quiet placeholder / calm retry — never a toggle guessed on.
3. **One tap each way, whole-row target.** A `SwitchListTile`-style E10 switch primitive: the entire row is the tap target (≥48dp tall, `touch.min`), a single tap enables, a single tap silences. **No confirmation dialog, no "are you sure?", no extra step in either direction** — silencing must cost exactly as much as enabling (§11 obstruction; §9 reversible). `MergeSemantics` keeps the label + switch one announced node.
4. **The time picker is conditional by existence, not by disabling.** `if (enabled)` — the affordance is *absent* from the tree while off (one decision per moment, §9), present and ≥48dp once on. Tapping it invokes `onEditTimePressed`; the wiring leaf opens the picker and routes the confirmed value to `setReminderTime`. The *displayed* chosen time is the `formattedTime` slot — already rendered by T07 in the user's calendar + locale numerals; the row wraps it with the known-direction bidi isolate (`isolateLtr`, eng-rtl item 6) and never concatenates or formats a digit itself.
5. **The honest one-liner is a caption, not a banner.** One line under the row in `type.caption` + `color.text.secondary`: the `reminderHonestLine` key slot (T10's transcreation of "A neutral reminder at a time you choose. Silence it anytime." — the §9 table's checkable local-only fact). No "we care about your privacy" rhetoric, no icon theatre, no second sentence.
6. **The catch-up toggle is a sibling, structurally independent.** A second switch of the same anatomy, off by default, bound to `setCatchUpNoteEnabled` — rendered as a *peer* row, never indented under, gated by, or auto-flipped with the daily-reminder switch (E18-T09 owns everything it means). Turning the daily reminder off must not touch it, and vice versa.
7. **RTL by geometry; tokens by name.** `EdgeInsetsDirectional` / `AlignmentDirectional` only; insets from the `space.*` scale; labels in `type.body`; no raw hex/px/ms/duration anywhere (a lint failure per CLAUDE.md #12); no hardcoded `Directionality`. The one template serves fa/ckb/ar; longer ckb copy reflows within the same logical insets.
8. **Accessibility.** The switch exposes a per-locale `Semantics` label (the `reminderTitle` key) + toggled on/off value (10 §9; PRD §18); the time affordance announces `timeSemanticsLabel` + button role; all targets ≥48×48dp with `space.2` separation; OS text-scale respected without any target shrinking below `touch.min`; state is never conveyed by color alone.
9. **Five-dark-pattern discipline, structurally.** Nagging: exactly one reminder switch, no cadence/frequency control, no re-engagement surface. Obstruction: silence is one tap (note 3). Sneaking: nothing pre-checked; the local-only fact is on-screen (note 5). Interface interference: the off/silent path is the same control with the same visual weight — never buried, shrunk, or de-emphasized relative to opting in. Forced action: the row gates nothing; every other feature works with it off (§11).
10. **Pitfalls to avoid:** a shadow `bool` in widget state that can drift from the controller (watch, don't copy); formatting the time in the row (ASCII digit leak — T07's boundary); any string literal (every visible/announced text is an `l10n.*` key slot — values are T10's); a confirm step on disable; coupling the catch-up switch to the reminder switch; the row importing the scheduler/repository or calling anything but the three mutations; `DateTime.now()` anywhere; `EdgeInsets.only(left:/right:)` (grep-banned); a streak chip, "N days in a row", counter, or celebratory motion on toggle; permission UX in the row (T08 wraps).

## Tests

All widget tests are deterministic and offline by construction: T03's controller is replaced via `overrideWith` with a **recording fake controller** (the row is tested against the seam it calls, not against persistence — T03 owns the write-path suites), a fixed injected clock if any provider requires one, and the suite-wide throwing `HttpOverrides` guard. Structure/adab tests are written **first**.

- `features/test/reminders/reminder_row_test.dart` (widget — **written first**):
  - first render over default (all-off) state → the reminder switch is off; no pre-ticked control anywhere in the tree;
  - opt-in is a **single tap** → the fake controller records exactly one `setEnabled(true)`; a second single tap records `setEnabled(false)` — and **no confirmation dialog appears in either direction**;
  - the time-picker affordance is absent while disabled and present after the fake republishes an enabled state; tapping it and confirming routes one `setReminderTime` call through the fake;
  - the catch-up sibling: one tap records exactly one `setCatchUpNoteEnabled(true)`; toggling it leaves the reminder switch untouched (and vice versa);
  - the fake records **no** call other than the three mutations — the row reaches no repository, scheduler, or OS surface.
- `features/test/reminders/reminder_row_semantics_test.dart` (widget) — the switch exposes a `Semantics` node with a localized label and a toggled **on/off value** in each of fa/ckb/ar; the time affordance announces label + button role; `meetsGuideline(androidTapTargetGuideline)` (and `labeledTapTargetGuideline`) passes; at a large OS text-scale every target still meets 48dp.
- `features/test/reminders/reminder_row_structure_test.dart` (widget) — the five-dark-pattern structural asserts: exactly **one** reminder switch in the tree; **no** second reminder row, cadence/frequency control, streak chip, counter, or "days" adornment widget; the honest one-liner is present exactly once; disabling completes with zero intervening dialogs/routes (obstruction guard).
- Out of scope here, pinned by siblings: the per-locale RTL/numeral goldens (E18-T11), the banned-phrase lint over the string *values* (E18-T10), persist-order and scheduler-call invariants (E18-T03), fire-time DST vectors (E18-T04). The offline `HttpOverrides` guard runs over every suite above.
