## Goal

Pin the assembled reminder row's RTL layout and locale-numeral rendering with per-locale golden images. One `matchesGoldenFile` suite pumps the composed `ReminderRow` (E18-T06) in its **enabled** state — switch on, conditional time picker visible showing the E18-T07-rendered time, the honest one-liner, and the catch-up sibling toggle — under each of `fa`, `ckb`, and `ar`, on the **real bundled UI fonts** and the **pinned golden runner**, and freezes the pixels. The goldens prove three things no unit test can: the row reads start→end (visually right→left) with the label at start and the control at end; the chosen time renders in the correct locale digit block (Extended Arabic-Indic ۰۱۲۳۴۵۶۷۸۹ for fa/ckb, Arabic-Indic ٠١٢٣٤٥٦٧٨٩ for ar — no ASCII leak, no reordered bidi corruption); and ckb's longer copy reflows within the same logical insets without truncating a load-bearing label. This is the epic's concrete artifact for the PRD §20 gate 5 release gate. It is a **visual pinning task only**: no new widget, no new logic, no new string — T06 owns the row's behavior tests, T07 owns the numeral-rendering logic and its unit tests, T10 owns the copy and the banned-phrase lint. This task freezes what they built.

## Implementation notes

This task is test-only: one golden suite, zero production code, zero new strings. If a golden exposes a defect (a physical inset, an ASCII digit, an unmirrored chevron, a truncated ckb label), the **fix belongs to T06/T07** — this task's deliverable is the pinned proof, not the repair.

1. **File**: `features/test/reminders/reminder_row_golden_test.dart`, tagged `@Tags(['golden'])` at the top so it runs only in the pinned, Linux-only golden CI job (testing-strategy §8). Masters live beside it under `goldens/` as `reminder_row_ar.png`, `reminder_row_fa.png`, `reminder_row_ckb.png`, plus `reminder_row_reflow_ckb.png` — four committed images.
2. **Fixture state, injected not simulated.** Pump the composed `ReminderRow` inside a `MaterialApp` declaring the real localization delegates and `supportedLocales: [ar, fa, ckb]`, forcing the locale per case — direction must come from the locale, **never** a hardcoded `Directionality(TextDirection.rtl)` wrapper (eng-rtl-and-bidi-layout rule 1). Riverpod overrides (eng-write-dart-test pattern 9) supply a fixed `ReminderPreferences` (`isEnabled: true`, a fixed `reminderMinutesSinceMidnight`, `isCatchUpNoteEnabled` in one fixed, deliberate state) and the fixed injected clock, so the row mounts already-enabled with the picker slot showing — do not drive taps or animations to reach the state. T02's defaults are off/off and an absent row reads as defaults, so the override must inject an explicit saved-prefs value.
3. **Pick a digit-revealing fixture time.** Choose a stored minutes value whose rendered digits differ visibly between the two digit blocks (e.g. one containing ۴/٤- and ۵/٥-class digits, where Extended Arabic-Indic and Arabic-Indic glyphs diverge most), taken **through T07's entry point via the widget** — the test never calls `NumberFormat` or builds a time string itself; it renders exactly what the app renders.
4. **Real bundled UI fonts, loaded via `FontLoader` in `setUpAll`** — the Perso-Arabic UI font for fa/ar and the Sorani-coverage font for ckb (PRD §13.5), registered under the same family names the Mihrab theme uses. The font-independent (`Ahem`) strategy that eng-write-dart-test pattern 7 permits for generic layout goldens is **forbidden here** (eng-rtl-and-bidi-layout rule 10): locale digit glyphs and Sorani letters are the very subject under test, and `Ahem` renders every glyph as an identical square, making the golden pass vacuously.
5. **Pin everything**: fixed `devicePixelRatio`, fixed `physicalSize` (one standard phone logical size), fixed theme (Mihrab tokens via the real theme — no ad-hoc styles), animations disabled; `await expectLater(finder, matchesGoldenFile('goldens/reminder_row_<locale>.png'))` per locale. Regenerate masters only via a local `--update-goldens` run on the pinned environment, reviewed in the diff; CI only verifies (testing-strategy §5/§8).
6. **Reading-order proof, geometrically.** Alongside the pixels, one lightweight geometry assertion per locale pins start→end order under RTL: the row's leading label center-x is **greater** than the trailing switch's center-x (label at visual right, control at visual left). This catches a physical-side regression even if a future master is re-blessed carelessly — pixels and geometry must agree.
7. **ckb reflow golden.** Pump the ckb case a second time on a **narrower pinned surface width** so the longer Sorani copy must wrap, and capture `reminder_row_reflow_ckb.png`. Keep the default `flutter_test` failure on `RenderFlex` overflow live (no overflow-swallowing harness), and assert no load-bearing label (the row title, the rendered time, the one-liner) is ellipsized — wrapping within the same logical insets is correct; truncation is a defect.
8. **One parameterized loop, identical anatomy per locale.** Structure the suite as a single loop over `[ar, fa, ckb]` so the fixture, pump, geometry assertion, and master name are identical per locale — the only variables between masters are the locale, its font, and its strings. Keep the catch-up sibling toggle in the **same** fixed state in every master so a cross-locale diff isolates locale effects only; the ckb reflow case is the loop's single extra case.
9. **Offline by construction.** The suite runs under the shared throwing-`HttpOverrides` bootstrap (eng-write-dart-test pattern 8) — any socket open is a loud, named failure. Fonts and ARB strings are bundled assets; nothing in this suite may fetch anything.
10. **Pitfalls to avoid:** a hardcoded `Directionality` wrapper (hides physical-side bugs — direction derives from the locale); `Ahem` or any placeholder font; an unpinned DPR/size/theme (masters drift per machine); `pumpAndSettle()` after mounting (pump explicit durations if any implicit animation exists); formatting the time in the test instead of consuming T07's path through the widget; asserting copy wording or banned phrases (T10's gate, not this suite); duplicating T06's behavior tests (toggle semantics, conditional visibility, a11y); blessing masters from anywhere but the pinned environment; letting the reflow case pass by silently truncating instead of wrapping; a disabled-state golden presented as the "default" that normalizes a pre-ticked switch (ds-10 §9 — the enabled state is an explicit fixture, labeled as such in the test name).

## Tests

This task **is** its tests. All deterministic, offline by construction, run via `flutter test --tags=golden` on the pinned, Linux-only golden CI job.

- `features/test/reminders/reminder_row_golden_test.dart` (golden, `@Tags(['golden'])`):
  - per-locale enabled-row goldens `goldens/reminder_row_{ar,fa,ckb}.png` — real bundled fonts via `FontLoader`, locale-derived direction, fixed `ReminderPreferences` + fixed injected clock so the shown time is stable, a digit-revealing fixture time consumed through T07's entry point, pinned DPR/size/theme, animations disabled;

- CI wiring: the file's `golden` tag routes it into the existing pinned golden job (testing-strategy §8) — this task adds **no** new CI job; if that job does not yet collect `features/test/reminders/**`, that is a one-line include in the existing job, not a new gate.
