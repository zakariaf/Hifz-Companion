## Goal

The epic's consolidation task: every Settings and profiles surface reaches **full fa/ckb/ar ARB coverage** — every section header, picker option, sample preview, switcher label, dialog line, and `Semantics` string is a `gen_l10n` key transcreated (never literally translated) into all three locales, with the ckb set flagged **provisional** pending native + scholar review; **per-locale RTL golden screenshots** capture the grouped Settings surface and the active-profile switcher on the **real bundled UI fonts** (never Ahem — the Sorani extra letters and both digit blocks must actually be exercised); and the **epic-wide offline guard** proves no preference change and no profile switch opens a socket. This task authors/transcreates the strings the earlier tasks keyed and owns the aggregated golden + gate coverage — it builds **no** control and re-architects **no** surface (T01–T11 own those). It closes the epic against PRD §20 gate 5 for the E16 namespace: zero missing keys, zero hardcoded user-facing strings, canonical Sorani encoding, correct digit blocks on dates *and* numbers, mixed runs FSI/PDI-isolated, and the adab conscience pass recorded over every string in all three locales.

## Implementation notes

This task is strings, goldens, and gates only: it authors ARB values, captures screenshots, and installs checks. It builds no widget, computes no date, reorders no page, opens no socket — and it proves the last point for the whole epic.

1. **Sweep the E16 key namespace first.** Enumerate every user-facing string across the Settings and profiles surfaces (section headers; every option label and sample preview in the language/theme/font-size, calendar/numeral, term-set, muṣḥaf/riwāyah, and cycle-preset/budget pickers; the switcher's labels; every `Semantics` label/hint). Each must be a key in `app_ar.arb` (the template/base) with an `@description` carrying translator/scholar context, plus transcreated `fa` and `ckb` values. `nullable-getter: false` turns any miss into a compile error; the grep gate catches any literal that bypassed `AppLocalizations` in the E16 `features/**` files.
2. **Transcreate, never literally translate** (eng-add-localized-string step 10). Persian: respectful-warm *šomā* register; Arabic: imperatives softened into statements of readiness; Sorani: register and religious vocabulary set by native reviewers — every ckb value's `@description` carries the "needs native + scholar review" provisional flag. Term-set vocabulary stays an ICU `select`/region-override, never an edited base string.
3. **Enforce canonical Sorani encoding.** Author ckb with U+06D5 (ە) for AE and U+06A9 (ک) for kaf; the lint added to the localization gate rejects any stray U+200C (ZWNJ) and any Teh-Marbuta-for-AE substitution in the E16 keys before build, so the bundled font never receives malformed input.
4. **Complete every plural.** Any count-bearing Settings string (budget minutes, new-lines/day, a profile count) is an ICU `plural`; the completeness check asserts all six Arabic CLDR categories in `app_ar.arb`, and the count is formatted through `numberFormatFor(locale)` before placement — never a `"$count"` splice.
5. **Verify isolation of every mixed run.** User-typed profile names in the switcher route through `isolate()` (FSI — direction unknown); digit runs and Latin tokens (a version string in About) through `isolateLtr` (known direction). The switcher golden seeds one Arabic-script and one Latin-script profile name so the isolation is photographed, not assumed.
6. **Assert digit blocks on dates AND numbers.** Because of the documented `intl` date-vs-number inconsistency, the per-locale checks assert both the calendar picker's date previews and the numeral picker's/budget control's numbers render U+06F0-block glyphs under fa/ckb and U+0660-block glyphs under ar — per surface, never assumed uniform.
7. **Per-locale RTL goldens on real fonts** (eng-write-dart-test Pattern 7; eng doc 12 §8). Pump the grouped Settings screen (all five sections, pickers instantiated) and the active-profile switcher under each of fa/ckb/ar with that locale's numerals; load the **real bundled UI fonts** via `FontLoader` in `setUpAll` — never Ahem, which would defeat the Sorani-coverage and digit-block assertions; pin `devicePixelRatio`, `physicalSize`, theme; disable animations; `@Tags(['golden'])` for the pinned Linux-only golden lane. The goldens prove: reading order runs start→end (chevrons, selected marks, and insets at the logical start), the correct digit block per locale, and ckb's longer copy **reflowing without truncating** any load-bearing label.
8. **Install the epic-wide offline guard.** The shared test bootstrap's throwing `HttpOverrides` stays installed while a suite drives *every* preference change (language, theme, font-size/zoom, calendar, numeral, term-set, muṣḥaf/riwāyah, cycle-preset, Pure-cycle, daily-budget) and a profile switch end-to-end against in-memory fakes — any socket open is a loud named failure, proving the epic's "no server because there is no socket" posture in one place.
9. **Run and record the adab conscience pass.** The never-ship banned-phrase lint runs over every E16 ARB value in all three locales: no guilt/fear/loss, no mandate word, no "safe to drop"/"mastered"/"done", no gamification/celebration, no app-as-authority phrasing, no observance ruling, no `!`/emoji. Religious/methodology-adjacent wording (the Hijri caveat, term-set names) stays flagged pending scholar review where not yet cleared — flagged, never silently shipped as final.
10. **Pitfalls to avoid:** rebuilding or "fixing" a T01–T11 surface while sweeping (file an issue, don't drift); authoring E17/E18/E19 copy because it "lives in Settings too"; rendering the goldens with Ahem or on an un-pinned runner (byte-instability, and the Sorani/digit assertions become vacuous); letting CI regenerate a golden master; assuming date and number digits agree without the per-surface check; a hardcoded `Directionality` in a golden harness (direction must come from the pumped locale); locking the ckb term-set as final; literal-translating so the register drifts; leaving any user-facing literal outside ARB.

## Acceptance criteria

- [ ] Every user-facing string on every E16 surface resolves through `AppLocalizations` from a key present in `app_ar.arb`, `app_fa.arb`, and `app_ckb.arb`; the coverage check finds zero missing keys and the grep finds zero hardcoded literals in the E16 `features/**` files.
- [ ] Every fa/ckb/ar value is a transcreation to the per-locale register (fa respectful-warm, ar softened imperatives, ckb native-reviewed register); every ckb value's `@description` carries the provisional "needs native + scholar review" flag.
- [ ] The canonical-ckb lint passes: no stray U+200C, no Teh-Marbuta-for-AE, AE as U+06D5 and kaf as U+06A9 throughout the E16 ckb values.
- [ ] Every count-bearing E16 string is an ICU `plural` with all six Arabic categories in `app_ar.arb`; every count/date renders via `numberFormatFor(locale)` / the E09 presenter — no ASCII digit splice anywhere in the namespace.
- [ ] Per-locale (fa/ckb/ar) RTL goldens of the grouped Settings surface and the active-profile switcher exist, rendered on the real bundled UI fonts, `@Tags(['golden'])`, byte-stable on the pinned golden lane; they show start→end reading order, the correct digit block per locale, ckb reflow without truncation, and FSI/PDI-isolated mixed runs (Latin profile name, version string).
- [ ] The epic-wide offline guard passes: with the throwing `HttpOverrides` installed, every preference change and a profile switch complete with zero connection attempts.
- [ ] The adab banned-phrase lint passes over every E16 ARB value in all three locales, and the conscience pass is recorded; pending scholar-review items are flagged, not shipped as final.
- [ ] No production widget, provider, or schema file is created or re-architected by this task — its diff is ARB values, golden masters, and test/gate files (plus at most string-key wiring fixes surfaced by the sweep).

## Tests

All deterministic and offline by construction: in-memory fakes, the injected `CalendarDate` (never a real clock), the shared throwing-`HttpOverrides` bootstrap, real bundled fonts, pinned golden runner.

- `features/test/settings/settings_l10n_coverage_test.dart` (gate) — asserts 100% key parity of the E16 namespace across `app_ar.arb`/`app_fa.arb`/`app_ckb.arb`; greps the E16 `features/**` files for string literals passed to `Text`/`tooltip:`/`semanticsLabel:`/`label:`; asserts every `plural` in the namespace defines all six Arabic categories; runs the canonical-ckb codepoint lint (no U+200C, no Teh-Marbuta-for-AE).
- `features/test/settings/settings_rtl_golden_test.dart` (golden, `@Tags(['golden'])`) — per-locale goldens of the grouped Settings screen under fa/ckb/ar on the real bundled UI fonts: start→end order, locale digit blocks on the calendar previews **and** the numeral/budget numbers (the date-vs-number check), ckb reflow without truncation.
- `features/test/profiles/profile_switcher_rtl_golden_test.dart` (golden, `@Tags(['golden'])`) — per-locale goldens of the active-profile switcher seeded with one Arabic-script and one Latin-script profile name; pins that both names render FSI/PDI-isolated in correct visual order inside RTL chrome.
- `features/test/settings/settings_offline_guard_test.dart` (widget/integration-style) — under the throwing `HttpOverrides`, drives every T03–T07 preference change and a T09 profile switch against fakes; any socket open fails loudly; also asserts the ckb Material dialog chrome shows Sorani labels (the vendored delegate is registered).
- `features/test/settings/settings_banned_phrase_test.dart` (unit) — the adab lint over every E16 ARB value in fa/ckb/ar: guilt/fear/loss, mandate words, "safe to drop"/"mastered"/"done", gamification/celebration words, app-as-authority phrasing, observance-ruling phrasing, `!`, emoji — fails on any hit and records the pass.

## Definition of Done

- [ ] All acceptance criteria met; the coverage gate, canonical-ckb lint, plural check, banned-phrase lint, goldens, and offline guard are green in CI; golden masters were generated locally on the pinned runner and reviewed in the diff.
- [ ] **Offline / no-network:** the epic-wide `HttpOverrides` guard proves no preference change or profile switch opens a socket; this task adds no network path and the E16 namespace imports no networking symbol.
- [ ] **No AI / no microphone:** nothing here records, transcribes, infers, or recommends; the sweep confirms no "recommended for you" or telemetry string exists in the namespace.
- [ ] **Quran text fidelity (R1):** no localization mechanism built or verified here reaches the muṣḥaf — no UI numeral, UI font, mirroring, or bidi control touches the glyph layer; the muṣḥaf picker strings name the edition and state the riwāyah ("Ḥafṣ ʿan ʿĀṣim — Madani muṣḥaf"), never "the Quran" in the absolute.
- [ ] **Never "safe to drop" (decay axiom):** the banned-phrase lint pins that no E16 string in any locale calls a page or a preference "safe", "done", "mastered", or frames a cycle/budget choice as making revision skippable.
- [ ] **No gamification / no shame (R3):** no streak, badge, score, confetti, `!`, or emoji anywhere in the namespace; no guilt/fear/loss copy in any locale; a child profile's strings carry the same calm register.
- [ ] **RTL + fa/ckb/ar localization:** 100% ARB coverage with transcreated values (ckb provisional, canonically encoded); layout photographed RTL-by-geometry per locale; numerals in the locale block via `intl` on dates and numbers alike; mixed runs FSI/PDI-isolated; ckb reflows without truncation; no hardcoded user-facing string.
- [ ] **Accessibility (WCAG 2.2 AA):** every E16 control's `Semantics` label/hint exists in all three locales (part of the coverage sweep); the goldens confirm legible layout; per-surface ≥48dp/text-scale assertions remain green in the owning tasks' suites.
- [ ] **Sect-neutral adab:** the conscience pass is recorded over every string in all three locales — no fiqh ruling, no observance ruling on the Hijri strings, no app-as-authority phrasing; religious/methodology wording not yet scholar-cleared stays explicitly flagged provisional.
- [ ] **Deterministic tests:** injected `CalendarDate` and seeded fakes only; goldens byte-stable on the pinned fonts and Linux-only golden lane; CI never regenerates a master; all E16 gates stay green.
