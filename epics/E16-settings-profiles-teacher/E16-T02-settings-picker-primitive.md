## Goal

Build the one reusable **single-choice Settings picker primitive** that every Display-section picker (T03–T06) and the cycle picker (T07) instantiates — and make its contract airtight before any of them exists. The primitive is a **named radiogroup** (a `Semantics` container labelled with the preference name) of ≥48dp `touch.min` labelled members on the M3 single-select state model, in which the selected member is carried by **shape + text — the radio glyph plus its label — never hue alone**, with a visible focus ring, states mirrored under RTL. Choosing an option routes through **exactly one notifier method** that persists the value transactionally **before** republishing in-memory state; the affected surfaces then re-render **from the persisted value** via a watched stream, never a local `setState`. The primitive is a **pure display transform by construction**: it takes already-localized strings and a callback, imports no engine and no DAO, and a selection mutates no engine state, no `due_at`, no schedule. This is the load-bearing "a harmless picker can never mutate the schedule" guarantee (the epic's first risk); the concrete option-sets, the profile system, and the destructive confirm are siblings.

## Implementation notes

This task is a widget + a contract, no concrete preference: no option-set, no `CalendarPresenter` wiring (T04), no `EngineConfig` field (T07), no profile (T08+). It is **test-first on the write path and the no-slider invariant** — those two tests exist and fail before the widget is fleshed out.

1. **Files** (`features` package, `lib/src/settings/`, per 02-project-structure §3.4): `widgets/settings_single_picker.dart` — the domain-blind `SettingsSinglePicker<T>` and its `SettingsPickerOption<T>` value (a `value`, an already-localized `label`, an optional already-localized supporting line); `widgets/settings_picker_row.dart` if row anatomy warrants its own leaf; `features/test/settings/support/picker_contract_harness.dart` — the reusable contract-test harness T03–T07 re-run against their instantiations.
2. **Dumb by construction.** The widget takes: the localized group name, the option list, the currently-selected `T` (read by the caller from its watched provider), an `enabled` flag, and one `Future<void> Function(T)` `onSelect`. It holds **no** selected-state field of its own, imports nothing from `data`/`engine` (grep-verifiable), and never reads a clock. Tapping an option only invokes `onSelect`; the selection marker moves when the caller rebuilds with the new **persisted** value (04 §3) — never optimistically.
3. **The persist-before-republish contract** (04 §4; eng-create-riverpod-store): each instantiation binds `onSelect` to one notifier method whose repository call opens one `db.transaction`, writes the preference, and commits **before** the notifier republishes and before the watched stream re-emits. The controller's `await` returns only after commit. This task documents the contract on the widget's `///` API doc and pins it in the harness so every instantiation inherits the proof, not just the pattern. Write-path failure propagates to a calm retry affordance — never a silent swallow, never guilt copy.
4. **M3 single-select anatomy** (07-components §6): rows on the M3 single-select pattern (`RadioListTile<T>`-shaped; a short `SegmentedButton` variant is permitted where an instantiation's set is short) with the five states — enabled, pressed (state layer), disabled (dimmed role, reads as waiting), focused (visible `color.outline` ring), selected (filled emphasis + radio glyph) — all drawn as state layers over owned `color.*` roles, labels in `type.body`/`type.caption`, never ad-hoc opacity or a bespoke per-picker style.
5. **Selected = shape + text, grayscale-safe** (SC 1.4.1; PRD §18): the selected member is identifiable by the radio glyph (shape) and its label with the group's stated current value — strip all hue and a deuteranope still reads the choice. No hue-only tick, no color-fill-only selection.
6. **No `Slider`, no dial, no free text — ever** (design principle 1; PRD §15.1–15.2): the primitive's public API only accepts a finite named option list, so a "retention slider" cannot be expressed; the harness additionally asserts `find.byType(Slider)` (and any dial/`TextField`) finds nothing in any picker tree.
7. **Geometry & grouping**: each option ≥48dp `touch.min`, rows ≥`space.2` apart (ui-settings-picker Pattern 7); OS text-scale growth never shrinks a row below 48dp; the primitive renders inside T01's grouped sections and adds no section chrome of its own.
8. **RTL by geometry** (12-localization-and-rtl §1): `EdgeInsetsDirectional`/`AlignmentDirectional` only; the selected affordance leads at the **start** (right), any disclosure trails at the **end** (left); the focus ring and state layers follow the component under RTL, and focus/traversal order matches visual order for fa/ckb/ar.
9. **Named radiogroup semantics** (07-components §6; PRD §18): a `Semantics` container names the group with the preference name; each member exposes its localized label + a selected/not-selected value, `inMutuallyExclusiveGroup`, with enabled/disabled flags; keyboard/switch-control reaches every member with the visible focus ring.
10. **Every string arrives as an ARB key** (12 §7; eng-add-localized-string): the primitive declares zero literals; group names, option labels, and supporting lines are `l10n.*` values passed in by instantiations (fa/ckb/ar; ckb per policy); any numeral inside a label is the caller's job via E09's `numberFormatFor`, FSI/PDI-isolated (T04's concern, not built here).
11. **Selection is quiet** (07-components §6 anti-pattern; epic DoD): pressed feedback is the M3 state layer and at most one restrained haptic tick — no confetti, chime, glow, streak, badge, or "recommended"/"optimal" affordance anywhere in the primitive's API or rendering.
12. **Pitfalls to avoid:** a local `setState` selected flag (the marker must be persisted-value-driven); republishing or moving the marker before the commit returns (breaks crash-safety); letting the widget import a DAO/engine "just for one picker"; a second write path per instantiation instead of the one bound method; hue-only selection; a `Slider`/dial/free-text escape hatch; hardcoded `left`/`right`; a recommendation subtitle (adab + no-inference); building row anatomy again in T03–T07 (they instantiate, never re-build).

## Acceptance criteria

- [ ] `settings/widgets/settings_single_picker.dart` exists in the `features` package: a domain-blind, stateless-by-contract `SettingsSinglePicker<T>` taking already-localized strings, a finite option list, the persisted selected value, and one `onSelect` callback; grep over the file shows no `data`/`engine` import, no `DateTime.now()`, no user-facing literal.
- [ ] Selecting an option invokes exactly one bound notifier method; the preference persists in one transaction that **commits before** the notifier republishes and before any stream re-emits; the selection marker moves only when the caller rebuilds from the persisted value — never on tap alone.
- [ ] A selection writes a presentation preference and nothing else: zero engine calls, zero `due_at`/schedule/`review_log` writes (recording doubles prove it).
- [ ] The group is a named radiogroup: a `Semantics` group label + per-member localized label, selected/not-selected value, `inMutuallyExclusiveGroup`, enabled/disabled flags.
- [ ] The selected member is redundant as shape + text (radio glyph + label) and distinguishable with hue stripped; states are M3 state layers over `color.*` roles with a visible `color.outline` focus ring; disabled reads as waiting.
- [ ] No `Slider`, dial, or free-text field can appear in any picker tree — precluded by the API and asserted by the harness.
- [ ] Every member is ≥48dp `touch.min`, rows ≥`space.2` apart; OS text scale never shrinks a row below 48dp.
- [ ] Layout is RTL by geometry (`EdgeInsetsDirectional`/`AlignmentDirectional`, no physical `left`/`right`); the selected affordance leads at the start; states and focus mirror under RTL for fa/ckb/ar.
- [ ] The reusable contract-test harness ships and is documented so T03–T07 each re-run it against their instantiation.

## Tests

All deterministic and offline by construction: seeded fixtures, recording doubles, no clock, real bundled fonts for goldens. Test-first on the write path and the no-slider invariant.

- `features/test/settings/settings_picker_write_path_test.dart` (widget, **written first**) — a recording repository + fake notifier prove: one selection produces **exactly one** transactional preference write; the recorded commit strictly precedes the notifier's republish/stream re-emit (ordering pinned by the recorder's event log); the marker does **not** move on tap before the persisted value re-emits; zero engine/`due_at`/`review_log` writes occur; a failing repository surfaces the calm retry path with no state republished.
- `features/test/settings/settings_single_picker_test.dart` (widget, **written first** for the no-slider case) — `find.byType(Slider)` (and dial/`TextField`) finds nothing; every member ≥48dp under default and enlarged text scale; the `Semantics` tree exposes the named group, per-member labels, selected value, `inMutuallyExclusiveGroup`; keyboard focus shows the visible focus ring; disabled state announces disabled and reads as waiting.
- `features/test/settings/settings_picker_grayscale_golden_test.dart` (golden) — selected vs unselected rows rendered and compared **with hue stripped** (grayscale decode): the selected member remains identifiable by radio glyph + text alone (SC 1.4.1).
- `features/test/settings/settings_picker_rtl_test.dart` (widget + golden) — under `TextDirection.rtl` for fa/ckb/ar: the selected affordance sits at the visual right (start), trailing affordances at the left (end); no physical-inset offsets; state layers/focus ring track the mirrored geometry; ckb's longer labels reflow within the same insets without truncation.
- `features/test/settings/support/picker_contract_harness.dart` — packages the write-path, no-slider, radiogroup-semantics, and 48dp assertions as a reusable harness invoked by T03–T07 (and re-used by T12's consolidated suite).
- Offline guard: the suite runs under an `HttpOverrides` that fails any socket open (eng-write-dart-test) — proves a selection opens no network connection.

- [ ] **No AI / no microphone**: no inference, no "recommended for you", no audio path — the primitive stores a stated choice and nothing else (R5).
