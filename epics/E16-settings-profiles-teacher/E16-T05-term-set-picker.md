# E16-T05 — Term-set picker: the regional sabaq/sabqi/manzil vocabulary, independent of UI language, ckb provisional

## Goal

The Settings picker that lets a ḥāfiẓ choose the **regional revision vocabulary** — the *sabaq / sabqi / manzil* track labels, the traditional grade verbs, and the cycle names — **independently of the UI language**, so the day looks like the day *this* user's teacher recognizes. It instantiates the E16-T02 single-choice primitive with the term-set option set and persists the choice into `cycle_config.term_label_set` / `region_preset` (schema owned by E03) through the single write path; the switch re-resolves E09's logical term keys (`track.far`, `grade.again`, `cycle.weeklyKhatm`, …) through the regional override layered over the locale's base ARB, re-labelling the Today section headers, the page-card track chips, the grade band's traditional verbs, and the cycle names — and mutating **nothing else**: no `due_at`, no card, no engine state, no glyph. The **ckb (Sorani) term-set is provisional**: marked as such both in-surface and in its ARB metadata (pending native-speaker + scholarly review, PRD §21.1), and correctable as a **data-only** change with no code edit. No regional default is presented as the only correct term, and no track/grade/cycle label exists as a hardcoded literal anywhere.

## Implementation notes

This task is a thin instantiation: one option set, one persisted preference, zero new mechanics. The encoding and no-hardcoded-literal assertions are correctness-critical for the localization contract → they are written **test-first**, before the picker is styled.

1. **Files** (in the `features` umbrella package, `lib/src/settings/`, per the E16-T01 scaffold): `widgets/term_set_picker.dart` — builds the term-set option list and hands it to the T02 primitive with a selection callback; no state of its own, no engine, no clock. The option-set ids come from E09's term ARB data (the region presets behind `term_label_set`/`region_preset`) — this file **defines no new preset id** and re-implements no radiogroup row.
2. **Each option previews its own vocabulary, in its own words.** An option's label/subtitle renders that term-set's actual track words (its Far-revision / Near-revision / New-lesson terms per the PRD §13.4 defaults) so the user recognizes their teacher's vocabulary at a glance — resolved from ARB, never typed as literals. No option carries "recommended", "standard", or any marker implying one region's terms are the correct ones (12-localization §6 anti-pattern).
3. **Independent of UI language.** The persisted `term_label_set`/`region_preset` is layered as a regional override **on top of** whatever locale base ARB is active — a Sorani speaker on the fa UI can choose the مەنزڵ set; an Arabic speaker can choose المنزل vs الدور phrasing — without touching T03's language preference. Do not couple the two pickers, auto-follow the locale, or reset the term-set on a language switch.
4. **Persist through the single write path.** Selection routes through one controller/notifier method (the T02 wiring) that writes exactly the two `cycle_config` columns transactionally **before** republishing in-memory state; the View writes nothing, reads no `DateTime.now()`, and triggers no engine call — the affected surfaces re-render because their ARB resolution re-runs, not because anything was recomputed.
5. **What relabels (and what must not).** Today's Far→Near→New section headers, the page-card track chips, the grade band's traditional verbs (§6.3), and cycle names (e.g. the weekly-khatm name on T07's cards) all resolve from logical keys and re-render with the new set. The muṣḥaf page relabels **nothing** — term-sets are chrome; the glyph layer, surah/juz markers, and riwāyah statement are untouched (12-localization §8).
6. **ckb is marked provisional, in-surface and in-data.** The ckb option row carries a quiet localized caption (factual register, e.g. "provisional — pending native-speaker and scholarly review"; no warning triangle, no alarm color); every ckb term ARB entry carries the "needs native + scholar review" `@description` annotation (eng 12 §3). A future corrected Sorani vocabulary lands as an ARB data edit only — verify no code path switches on a ckb term *value*.
7. **Canonical Sorani encoding is enforced at authoring time.** ckb term strings use U+06D5 (ە) for AE and U+06A9 (ک) for kaf; no stray U+200C (ZWNJ), no Teh-Marbuta (U+0629) where ە belongs, no heh+ZWNJ AE hack (12-localization §7). The encoding test runs over every ckb term value so the bundled font never receives malformed input.
8. **RTL + reflow** (eng-rtl-and-bidi-layout): `EdgeInsetsDirectional`/`AlignmentDirectional` only; term words embedded in an explanatory run are FSI/PDI-isolated; any numeral in a preview ("the 7 manāzil") renders via `numberFormatFor(locale)`. ckb's longer transcreated labels and the provisional caption reflow within the same insets — no truncation of a load-bearing term.
9. **Accessibility** rides the T02 primitive: each option is a ≥48dp radiogroup member announcing its name + selected value with a visible focus ring; the ckb row's `Semantics` includes the provisional caption so a screen-reader user hears the same honesty a sighted user sees.
10. **Pitfalls to avoid:** a hardcoded "Manzil"/"Sabqi"/"Sabaq" literal in any widget; auto-switching the term-set with the UI language (or vice-versa); presenting a regional default as the only correct term; shipping ckb dressed as final, or burying its provisional status in a tooltip; a term-set switch that calls the engine, rebuilds the day, or writes anything beyond the two config columns; madhhab-slanted vocabulary or a "more authentic" framing on any option; relabelling anything on the glyph page; editing base ARB strings instead of the regional override.

## Acceptance criteria

- [ ] `settings/widgets/term_set_picker.dart` exists in the `features` package, instantiates the E16-T02 primitive (no new radiogroup anatomy, no `Slider`/switch/free text), and contains no engine call, no `DateTime.now()`, no write outside the controller method (verifiable by grep over the file).
- [ ] The options are the named region presets from E09's term ARB data; each previews its own track vocabulary resolved from ARB; no option carries a "recommended"/"standard"/"correct" marker.
- [ ] Selecting an option persists exactly `cycle_config.term_label_set`/`region_preset` through one controller method, transactionally **before** republish; no other column, no `due_at`, no card field, and no engine state changes.
- [ ] After a switch, the Today section headers, page-card track chip, grade verbs, and cycle names render the new set's ARB values; no track/grade/cycle label exists as a hardcoded literal in this task's files.
- [ ] The term-set composes freely with the UI language: a fa-UI + ckb-term-set combination renders correctly, and switching either preference leaves the other unchanged.
- [ ] The ckb option renders its provisional caption in-surface (calm, factual, announced via `Semantics`); every ckb term ARB entry carries the provisional `@description` annotation; correcting the ckb set is a data-only change.
- [ ] Every ckb term ARB value is canonically encoded: U+06D5 for AE, U+06A9 for kaf, no stray U+200C, no Teh-Marbuta-for-AE.
- [ ] Layout is RTL by geometry (`EdgeInsetsDirectional`, no `left`/`right`); mixed runs are FSI/PDI-isolated; ckb's longer labels reflow within the same insets without truncation; every row stays ≥48dp under OS text scale.

## Tests

All deterministic, offline by construction, on the real bundled fonts, with seeded fixtures (no hidden clock, no network). The encoding and no-hardcoded-literal tests are written **first**.

- `features/test/settings/term_set_picker_test.dart` (widget) — selecting a term-set routes through the controller: a recording repository asserts exactly **one** transactional write touching only `term_label_set`/`region_preset` (persist observed **before** the republished state), and zero engine/`review_log` writes; no `Slider` exists in the tree; the ckb option renders its provisional caption and announces it via `Semantics`; selected state is shape + text, exactly one option selected.
- `features/test/settings/term_set_relabel_test.dart` (widget) — after a switch, seeded consuming leafs (a Today section header, a page-card track chip, a grade verb, a cycle name) render the new set's ARB-resolved values; asserts every rendered label came from a logical key (no hardcoded "Manzil"/"Sabqi"/"Sabaq" literal in the tree or the task's sources); asserts the seeded `due_at`/card fields are byte-identical before and after the switch; asserts a UI-language change leaves the persisted term-set untouched and vice-versa.
- `features/test/settings/ckb_term_encoding_test.dart` (unit) — **written first**: iterates every ckb term-set ARB value asserting no U+200C, no U+0629 where U+06D5 belongs, kaf as U+06A9 (not U+0643), no heh+ZWNJ AE hack; asserts every ckb term entry carries the provisional `@description` annotation.
- `features/test/settings/term_set_golden_test.dart` (golden) — per-locale (fa/ckb/ar) RTL goldens of the picker, plus the fa-UI + ckb-term-set cross combination; the ckb-reflow golden proves the longer labels and provisional caption fit the same insets without truncation.
- Offline guard: the suite runs under an `HttpOverrides` that fails any socket open (eng-write-dart-test) — a term-set change opens no socket. (The consolidated Settings-wide per-locale goldens and ARB-coverage gate live in E16-T12.)

## Definition of Done

- [ ] All acceptance criteria met; the encoding and no-hardcoded-literal tests were written first and are green; the per-locale goldens run in CI on the real bundled fonts.
- [ ] **Offline / no-network**: the picker works in airplane mode; the `HttpOverrides` guard passes; no telemetry on which vocabulary was chosen.
- [ ] **No AI / no microphone**: the picker stores a named choice; nothing recommends, infers, records, or transcribes (C2, R5).
- [ ] **Quran text fidelity (R1)**: the term-set relabels UI chrome only — no glyph, marker, or riwāyah statement on the muṣḥaf page is re-typeset, re-labelled, or localized (12-localization §8).
- [ ] **Never "safe to drop" (decay axiom)**: no vocabulary option or preview frames a track as optional, finished, or skippable — whatever the manzil track is called, it remains un-skippable; renaming changes words, never the §7.12 invariants.
- [ ] **Display-transform discipline**: a test proves the switch changes only the two `cycle_config` columns and relabels chrome — no `due_at`, card, or engine state mutates; the View is dumb and writes through the single persist-before-republish path.
- [ ] **No gamification / no shame (R3)**: switching is quiet — no confetti, chime, praise, or "optimal" framing; the provisional caption is honest information, not an alarm or a guilt cue.
- [ ] **RTL + fa/ckb/ar localization**: every option label, preview, and caption is an ARB key in fa/ckb/ar, transcreated not literally translated; the ckb term-set ships marked provisional (PRD §21.1) with canonical Sorani encoding enforced; layout is RTL by geometry with FSI/PDI-isolated runs and locale numerals.
- [ ] **Accessibility (WCAG 2.2 AA)**: each option is a labelled radiogroup member (name + selected value) with a visible focus ring and ≥48dp target; the provisional status is available to screen readers; states mirror correctly under RTL.
- [ ] **Sect-neutral adab**: the vocabulary options carry no madhhab slant and no region is presented as more correct or more pious; the ckb terms stay flagged for native + scholarly review before defaults lock; the option copy passed the domain-adab-and-religious-integrity conscience pass in all three locales.
- [ ] **Deterministic tests**: all tests use seeded fixtures and recording doubles (no hidden clock, no network); goldens are byte-stable on the pinned fonts; all gates stay green.
