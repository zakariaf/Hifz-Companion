## Goal

Run and **record** the release-blocking adab/religious-integrity conscience pass over the *whole assembled shipping app* — the human checkpoint the green machine gates are necessary for but cannot supply. This task audits what the feature epics built; it authors **no** screen, string, or claim. The deliverable is a committed release artifact — a filled conscience-review record seeded from the `domain-adab-and-religious-integrity` skill's `template.md` scaffold — enumerating a per-locale (fa/ckb/ar), per-surface verdict on each gate: **R1** the muṣḥaf is byte-exact, never decorated, never re-typeset; **R2** the riwāyah is named ("Ḥafṣ ʿan ʿĀṣim — Madani muṣḥaf"), zero tafsīr/translation/commentary ships, sect/madhhab-neutral; **R3/C6** no XP/streak/badge/leaderboard/confetti on any surface, no guilt/fear/loss copy, and the decay axiom — no "safe to drop"/"mastered"/"done"/"finished" anywhere; **R5** no microphone/recording/account/telemetry; **R6** teacher sign-off overrides the machine, no fiqh ruling, the app never speaks *for* the Quran; plus the **voice gate** (reverent · calm · plain-and-warm · honest, adab first) and the plain "needs scholarly review" flag on every surface whose sign-off is pending. The existing never-ship banned-phrase lint (`tool/check_adab_lint.dart`) is **re-run and consumed**, not re-authored. Any one gate gotten wrong ends the project (PRD §4); a HOLD verdict blocks the release regardless of green CI.

## Implementation notes

This task writes no production code and no copy: it executes a structured human review and commits its record. The one permitted code change is *extending the lint's per-locale pattern table* (with fixture tests) when the human pass finds a never-ship pattern the seed list misses — the machine must catch next time what the human caught once.

1. **Create the record** at `docs/release/adab-conscience-pass-v<version>.md` (net-new directory, introduced here; E20-T09 adds its two checkpoint records beside it) by copying `.claude/skills/domain-adab-and-religious-integrity/template.md` and filling every `// TODO`. Structure: one R1–R6 + voice-gate verdict block **per locale** (fa, ckb, ar), each enumerating every navigable surface of the assembled app — onboarding/cold-start (incl. the riwāyah statement and the privacy line), Today (list, budget line, catch-up banner, all-done/silent-resume states), recite/grade flow + teacher sign-off, the muṣḥaf reader, the mutashābihāt trainer, Progress/heat-map, Settings (profiles, cycle presets, reminder row, backup card, destructive confirms), the science screen, About/Credits, and every notification string.
2. **R1 — reverence:** point at the green machine gates (the `restraint` SHA-256 re-hash, the pinned-Linux muṣḥaf goldens) for byte-exactness, then walk every surface that shows or borders sacred text and confirm the adab half no grep can see: no badge/counter/ring/glow/border/celebration on or near an āyah, markers diagnostic only, sober page motion, zoom/sepia/dark transform the layer never the text (design 13 §1, §3). The *on-device scholar proof* is E20-T09 — record it here as pending, do not claim it.
3. **R2 — riwāyah + neutrality:** confirm "Ḥafṣ ʿan ʿĀṣim — Madani muṣḥaf" renders at onboarding and in Settings in all three locales, never "the Quran" absolutely; grep assets and ARB values for any tafsīr/translation/commentary content (must be zero); confirm Tanzil/QUL/KFGQPC attribution in About/Credits and that the Quran text is identical across locales (only chrome localizes).
4. **R3/C6 — no gamification, no shame:** sweep every surface for XP/points/levels/badges/leaderboards/ḥasanāt-counter/confetti/celebration widgets and streak mechanics (none may exist, even opt-in punitive); confirm all-done/empty/return-after-gap states greet nothing and blame nothing; confirm the heat-map reads as calm decay (green receding to neutral), never a scoreboard. The decay axiom: no "safe to drop"/"mastered"/"done"/"finished" verdict in any locale, in copy *or* implication (a page's cycle never ends).
5. **R5 — privacy as trust:** confirm `app/android/app/src/main/AndroidManifest.xml` declares no `RECORD_AUDIO` (or any audio) permission and `app/ios/Runner/Info.plist` contains no `NSMicrophoneUsageDescription`; point at the green no-network/dep-allowlist gates for no-telemetry/no-account; record that **C-048** is the traced claim these facts confirm — this pass verifies, never re-originates it.
6. **R6 — servant to the teacher:** confirm the teacher sign-off control exists on the grade flow and its copy credits the teacher ("recorded with your teacher's sign-off" register), never the app ("Approved"); point at the green INV-5 engine property for the override mechanics; confirm no string anywhere issues a fiqh ruling, speaks *for* the Quran or Allah, or pronounces on the user's spiritual state (voice §5; design 13 §6).
7. **Voice gate, per locale:** score each surface's copy on reverent/calm/plain-warm/honest (adab first — a clear-but-harsh string fails first); hard-news surfaces (catch-up, decay, budget overflow) follow empathy → fact → path → choice; honorifics and transliteration correct where names/terms appear. This is *transcreation review*, not translation checking — the ckb/fa register must carry the feeling, which the English-seeded lint cannot judge.
8. **Re-run the machine layer and record it:** `bash tool/check_l10n_complete.sh` (its layer E runs `dart run tool/check_adab_lint.dart` over `packages/l10n/lib/src/arb`) and `dart test tool/test/check_adab_lint_test.dart`, on the pinned toolchain (3.41.2) — paste the green run into the record. If the human pass finds a never-ship phrase the lint missed: file the string fix against its owning epic (E11–E19), **and** add the pattern to the lint's per-locale seed table with a fixture in `tool/test/check_adab_lint_test.dart`, re-running the `docs/gate-validation.md` seeded-violation drill for the changed gate (eng-add-ci-check).
9. **Scholarly-review boundary:** enumerate every surface whose scholarly/native sign-off is still pending (ckb register and religious terminology, methodology-adjacent wording, the mutashābihāt dataset until T09, the endorser — PRD §13.4, §21) and confirm each says "needs scholarly review" plainly in-app; a pending review is recorded as pending, never silently passed. **C-047** is the honesty covenant behind these flags.
10. **Verdict and pitfalls:** the record closes with SHIP or HOLD per locale; any HOLD blocks the release — the covenants outrank the calendar. Pitfalls: mistaking green CI for the pass (the lint is necessary-not-sufficient by its own header); "while I'm here" copy tweaks (file against the owning epic — this epic adds no string); reviewing English-only or literal translations; letting a pending scholar review slide through unflagged; performing T09's on-device proof or dataset sign-off here; celebrating the record itself (it is a sober artifact, no verdict emoji/exclamation).

## Tests

The pass consumes existing deterministic gates; it authors new test code only if the lint's pattern table grows.

- `tool/check_l10n_complete.sh` (re-run, green) — layer E executes `tool/check_adab_lint.dart` over every ARB value in fa/ckb/ar; the `restraint` CI job runs it on the pinned 3.41.2 toolchain; the green output is captured verbatim in the record.
- `tool/test/check_adab_lint_test.dart` (re-run, green) — the lint's own fixture suite; **extended** with a per-locale fixture for any never-ship pattern the human pass adds to the seed table (each new pattern proves it flags a crafted violation and stays quiet on clean copy).
- `docs/gate-validation.md` drill (only if the lint changed) — the seeded-violation matrix re-run for the adab gate: one banned phrase planted in a throwaway ARB flips the gate red with its named message; revert flips it green; never committed.
- Existing gates pointed at (not re-authored, must be green at pass time): the `restraint` SHA-256 asset/text integrity re-hash and muṣḥaf goldens (R1 mechanics), the engine INV-5 teacher-override property and the "never safe to drop" invariant run (`dart test` in `packages/engine`), the no-network/dep-allowlist checks (R5) — the record links the green run of each.

## Definition of Done

- [ ] All acceptance criteria met; the record is committed as a release-blocking artifact — the release does not proceed on green CI alone (PRD §20; engineering 11 §8: human checkpoints are *recorded sign-off artifacts*).
- [ ] **Offline / no-network**: the pass confirms and records that no surface phones home — no telemetry, no account, no per-user network; the only socket is the one-time verified asset download (PRD §17, C1); nothing in this task adds network use.
- [ ] **No AI / no microphone**: manifests carry no audio permission or usage string; grading is human-only throughout (C2, R5); recorded as confirming C-048, not re-claiming it.
- [ ] **Quran text fidelity (R1)**: byte-exactness pointed at the green SHA-256 + golden gates; the human walk confirms the muṣḥaf is never decorated, re-typeset, or celebrated over — the chrome defers to the words (design 13 §1, §3); the on-device scholar proof stays flagged pending → E20-T09.
- [ ] **Never "safe to drop" (decay axiom)**: no copy, state, or implication in any locale ends a page's cycle — "weakening / strengthening / due" only; the lint's forbidden-verdict class is green and the human pass confirms the transcreations (PRD §7.12; skill checklist).
- [ ] **No gamification / no shame (R3, C6)**: zero XP/streak/badge/leaderboard/confetti/ḥasanāt-counter anywhere; no guilt/fear/loss copy in any locale; hard news is empathy → path → choice (design 13 §4; voice §3–§4).
- [ ] **Servant to the teacher (R6)**: sign-off overrides the machine (INV-5 green), copy credits the teacher, no fiqh ruling, never speaks for the Quran; sect/madhhab neutrality held — riwāyah named, zero tafsīr (R2).
- [ ] **RTL + fa/ckb/ar**: the pass reviewed all three locales as transcreations (register and feeling, not literal accuracy); pending native/scholar reviews (ckb foremost) are flagged plainly, per-locale verdicts recorded (voice §8–§9; PRD §13.4).
- [ ] **Accessibility**: the reviewed surfaces carry the E08-recorded accessibility posture (never color alone, localized `Semantics`); this pass adds no surface and so degrades none — any a11y finding is filed against the owning epic.
- [ ] **Deterministic tests**: every consumed gate is deterministic and pinned (3.41.2, real bundled fonts, no `--update-goldens` in CI); the lint extension (if any) ships with fixtures and the gate-validation drill re-run; all gates stay green.
