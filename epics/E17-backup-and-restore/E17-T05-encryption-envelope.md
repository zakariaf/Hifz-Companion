## Goal

The `.hifzbackup` file gains its opt-in confidentiality layer. When the caller supplies a passphrase, `HifzBackup.export` seals the T03 canonical JSON inside a mode-`0x02` **Argon2id → ChaCha20-Poly1305** envelope, and `HifzBackup.import` opens it as **step 7** of T02's normative parse order. Export: NFC-normalize the passphrase → UTF-8 → Argon2id (RFC 9106; v1 params `65536` KiB / `3` iterations / parallelism `1`) → a 32-byte key → seal with ChaCha20-Poly1305 (RFC 8439) under a fresh CSPRNG 16-byte salt + 12-byte nonce, AAD = the file's 16-byte binary header. Import: validate the envelope's Argon2 memory against `[19456…1048576]` and iterations against `[1…16]` **before any derivation** — a hostile header must never buy minutes of pre-auth memory-hard work — then NFC-normalize, derive, and open; **every** AEAD failure surfaces the single `wrongPasswordOrDamaged` (a wrong passphrase and a damaged ciphertext are indistinguishable by design). The file key derives only from the passphrase and is **independent of the device DB key** (a portable file must open on a different device); the passphrase is never stored, never in `flutter_secure_storage`, never logged; a forgotten passphrase is unrecoverable — no hint, no recovery path. The crypto entry points stay isolate-sendable so E17-T07 runs them off the UI isolate. This task owns only the envelope bytes and their import-side rules: the container header is E17-T02's, the plaintext integrity harness is E17-T04's, and the encryption toggle + honesty copy are E17-T08's.

## Implementation notes

This task is pure bytes and crypto inside `backup/` — no I/O, no UI, no network, no DB, no user-facing string. **Test-first** per doc 10 §10: the encrypted round-trip, wrong-passphrase, and param-clamp tests are written against the T01 façade before the envelope code fills in.

1. **Files** (inside the T01 `backup/` package): `lib/src/encryption_envelope.dart` — the envelope codec (seal/open over the §6 byte layout) with every offset/size/range as a full-word named constant carrying a `///` doc tracing to its §6 row; `lib/src/passphrase_key_derivation.dart` — NFC normalization + Argon2id behind a small injectable KDF seam. Wire both into the `HifzBackup.export`/`import` bodies: `passphrase == null` ⇒ mode `0x01` (untouched T02/T03/T04 path), else mode `0x02`. Pubspec gains `cryptography` — decision #12's single sanctioned addition; nothing else.
2. **The envelope layout is the §6 table, byte for byte.** Big-endian throughout: `[0]` KDF id `0x01` · `[1..4]` memory KiB UInt32 (v1 export writes `65536`) · `[5..8]` iterations UInt32 (v1 `3`) · `[9]` parallelism (v1 `1`) · `[10..25]` 16-byte salt · `[26..37]` 12-byte nonce · `[38..38+m)` ciphertext · trailing 16-byte Poly1305 tag. Assert every offset in a golden test — a drifted offset silently breaks every future import.
3. **Export path:** NFC-normalize the passphrase → UTF-8 → `Argon2id(memory: 65536, iterations: 3, parallelism: 1, hashLength: 32)` derived with the salt → seal T03's canonical JSON bytes with `Chacha20.poly1305Aead()`, `aad:` = the exact 16 header bytes from T02's header-prefix API (build the header first, then seal — never a re-derived copy). Salt and nonce come fresh from the CSPRNG (`Random.secure()`-backed) on **every** export: fresh salt ⇒ fresh key ⇒ nonce reuse is foreclosed by construction. The finished envelope is the body T04's SHA-256 stamps; the mode byte is `0x02`.
4. **Import path is parse step 7, nothing more.** It runs only after T02/T04's steps 1–6 pass (so the envelope bytes are already integrity-verified). Read the KDF id first: anything other than `0x01` is refused **before any derivation** as `newerFormat` — §6 stores the KDF id for forward agility, so an unknown id means a newer format generation, mirroring §3's format-byte rule; record that mapping in a `///` doc as a stated decision, never guess and never `wrongPasswordOrDamaged`. Then validate memory ∈ `[19456…1048576]` and iterations ∈ `[1…16]` **before** derivation. Only then: NFC → UTF-8 → derive with the header's params (not the v1 constants) → AEAD-open with AAD = the received 16 header bytes → hand the plaintext to the step-8 seam.
5. **"Clamp" means validate-and-refuse, never coerce.** The §10 row is "out of range ⇒ rejected … **zero** derivation calls": do not pull a hostile value *into* range and proceed — a coerced param would derive a key the exporter never used and misreport a param problem as a wrong passphrase. Surface the refusal as the structural `malformedPayload` (the envelope header is malformed content, not a crypto failure), and record that mapping in a `///` doc as a stated decision, mirroring T02's reserved-byte treatment — the doc names the rejection, not the enum member, so the choice must be visible, never silent drift.
6. **One indistinguishable crypto error.** Every AEAD-open failure — wrong passphrase, flipped ciphertext byte, altered AAD, clipped tag — throws exactly `BackupError.wrongPasswordOrDamaged`. No retry counter, no "probably the password" hint, no distinct tag-vs-decrypt signal, no logging of attempts, inputs, or key material (§6; coding-standards Pattern 7).
7. **Key independence and no recovery, structurally.** `backup/` imports neither `flutter_secure_storage` nor anything from `/data` (doc 05 §5); the passphrase exists only as a call argument and the derived key only as a local — never persisted, never cached across calls, never logged. There is no recovery path to build and no "hint" field in the envelope; nothing beyond "this is a Hifz backup" leaks from the cleartext bytes.
8. **Isolate compatibility, not isolate spawning.** Keep `export`/`import` static and closure-free over sendable types (`Uint8List`, `String`) so T07 can hand them to `Isolate.run`; the `cryptography` APIs are async — await them inside the façade; never touch a Flutter binding or a global.
9. **NFC mechanism — resolve before coding.** §6 and decision #12 mandate NFC normalization, but the Dart SDK ships no Unicode normalizer and `cryptography` provides none; the decision log names no NFC dependency. **Stop and settle this via a written decision-log amendment** (a minimal vetted pure-Dart normalizer, or NFC tables vendored inside `backup/`) before implementation — do NOT silently skip normalization (a passphrase typed decomposed on the new device would stop opening the file) and do not add an unapproved package (non-negotiable 17).
10. **Test seams:** the KDF and the random-bytes source are injectable (package-private constructor or `@visibleForTesting` parameter, defaulting to Argon2id and the CSPRNG) so the param-clamp spy can count derivations and the committed encrypted golden is reproducible from pinned salt/nonce; the public façade signature stays exactly T01's.
11. **Pitfalls to avoid:** deriving before validating the params (the pre-auth DoS this task exists to foreclose); coercing an out-of-range param into range; distinct wrong-passphrase vs corrupt-ciphertext errors; a PBKDF2 fallback "for speed"; deriving from or storing anything in the device keystore; reusing a salt or nonce across exports; hashing the plaintext instead of the whole envelope in mode `0x02`; leaking `schemaVersion` or any payload hint into the cleartext envelope; deriving with the v1 constants instead of the header's params on import; lowering the v1 export params below §6's values; logging the passphrase, key, or plaintext anywhere.

## Acceptance criteria

- [ ] `HifzBackup.export(snapshot, passphrase: p)` emits a mode-`0x02` container whose body matches the §6 envelope layout byte for byte (KDF id, UInt32 BE params, 16-byte salt, 12-byte nonce, ciphertext, trailing 16-byte tag), with v1 params `65536`/`3`/`1` and a fresh CSPRNG salt + nonce per export — two exports of the same snapshot+passphrase differ.
- [ ] The passphrase is NFC-normalized then UTF-8-encoded before Argon2id on both export and import; a passphrase typed in decomposed (NFD) form opens a file exported with the composed (NFC) form; the NFC-mechanism decision-log amendment (note 9) exists before the code does.
- [ ] The AEAD is ChaCha20-Poly1305 with AAD = the file's 16 header bytes taken from T02's header-prefix API; an altered header byte fails the open (AAD binding proven at the envelope level).
- [ ] Import validates memory ∈ `[19456…1048576]` and iterations ∈ `[1…16]` **before** any derivation; an out-of-range header is refused (`malformedPayload`, the mapping `///`-documented) with **zero** KDF invocations, spy-proven; a KDF id ≠ `0x01` is refused pre-derivation as `newerFormat`.
- [ ] Every AEAD-open failure surfaces exactly `BackupError.wrongPasswordOrDamaged` — no other error, signal, retry counter, or log line distinguishes a wrong passphrase from damaged ciphertext.
- [ ] `backup/`'s dependency graph grew by exactly `cryptography` — no `flutter_secure_storage`, no Drift/`sqlite3`, no networking, no Flutter (grep/banned-import-gate verifiable); no code path stores, caches, or prints the passphrase, the derived key, or the plaintext.
- [ ] The container's SHA-256 covers the whole envelope in mode `0x02` (T04's mode-agnostic digest reused unchanged); pre-decryption corruption still surfaces `integrityFailed` at step 6, before step 7 ever runs.
- [ ] `export`/`import` remain static, closure-free entry points over `Uint8List`/`String`, awaiting the async crypto internally — ready for T07's `Isolate.run` without change.

## Tests

All pure-Dart `package:test` in `backup/test/`, run with `dart test`, simulator-free, offline by construction (the throwing-`HttpOverrides` bootstrap stays installed), under the ≥2-`TZ` CI matrix; property generators seeded with the seed logged on failure. **Written first**, against the T01 façade.

- `backup/test/encryption_envelope_test.dart` (unit + golden) — every §6 offset and v1 param constant asserted on a freshly exported file; the committed v1 encrypted golden fixture (pinned salt/nonce via the injectable seams) decodes to its byte-exact known snapshot, joining T04's fixture set; two exports of the same inputs produce different salt/nonce/ciphertext; opening with one altered AAD header byte ⇒ `wrongPasswordOrDamaged` (AAD binding).
- `backup/test/encrypted_round_trip_test.dart` (property) — `import(export(s, p), p) == s` for arbitrary snapshots and passphrases containing emoji, CJK, combining marks, and spaces (§10 row), Arabic-script/RTL passphrases included; the NFC pin: an NFD-typed passphrase opens an NFC-exported file; byte-identical behaviour under both `TZ` lanes.
- `backup/test/wrong_passphrase_test.dart` (negative) — a wrong passphrase ⇒ `wrongPasswordOrDamaged`; a ciphertext byte flipped **with the body SHA-256 recomputed** (so steps 1–6 pass) ⇒ the same single `wrongPasswordOrDamaged`; a flipped envelope byte *without* recomputing the hash ⇒ `integrityFailed` at step 6, never the crypto error — the two errors stay distinct and correctly ordered.
- `backup/test/argon2_param_clamp_test.dart` (negative + spy) — memory below `19456` / above `1048576`, iterations `0` / above `16` ⇒ refused as `malformedPayload` AND the injected KDF spy records **zero** derivation calls; boundary values (`19456`, `1048576`, `1`, `16`) derive and open normally; KDF id `0x02` ⇒ `newerFormat` with zero derivations; import derives with the *header's* in-range params, not the v1 constants (a fixture exported at non-default in-range params opens).
