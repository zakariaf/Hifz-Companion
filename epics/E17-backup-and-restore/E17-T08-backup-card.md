## Goal

The calm Settings surface where the "never trapped" promise becomes visible: a dumb `BackupCard` View over the E17-T07 controller with (1) an **Export** row and an **Import (restore)** row — plain E10 list-tile/button rows, one un-obstructed tap each; (2) a plain **status line** — "Last backup: <localized date>" / "No backup yet" — rendered from the controller's read model in the user's calendar and locale numerals, never a streak or a scold; (3) the **optional-encryption toggle**, protective-default-**on**, reversible, explained in one honest line, with the plaintext-is-readable line shown when it is off; (4) a calm **stale-backup nudge** that offers a fresh export and never escalates; (5) the **no-recovery tradeoff copy** — both halves of ownership stated plainly (you own this file; therefore you hold the only copy); and (6) the **replace-vs-merge confirmation** — two explicit, separately-confirmed actions wired to the T07/T06 restore path. The card shows **no cloud glyph, no "Sign in"/"Upload", no "syncing…" spinner** — export progress reflects only real CPU/crypto work — and never implies a recoverable server copy. The erase entry point and its gate are E17-T09, not here.

## Implementation notes

This task is presentation-only: the View mutates no persisted state, opens no socket, and calls no `DateTime.now()` — every action routes through one E17-T07 controller method and the status date arrives as an injected-`CalendarDate`-derived value. The copy is correctness-critical for adab and trust → the no-cloud assertion, the banned-phrase lint, and the confirmation-copy tests are written **first**.

1. **Files** (in the `features` umbrella package, `lib/src/settings/`, per eng-add-feature-module; the card is hosted by E16's Settings surface): `widgets/backup_card.dart` (the dumb `BackupCard` — Export/Import rows, status line, encryption toggle, nudge slot), `widgets/backup_stale_note.dart` (the calm nudge), `widgets/restore_mode_dialog.dart` (the replace-vs-merge confirmation). Each takes a pre-built read-model value + callbacks; no state of its own beyond ephemeral dialog visibility.
2. **The card is dumb.** It renders the T07 controller's sealed status model (`noBackupYet` / `lastBackupAt(CalendarDate)` / `exporting(progress)` / error variants) and dispatches taps to controller methods. No `HifzBackup` call, no file IO, no clock, no repository — a grep over the widget files finds none (ui-backup-card ¶10).
3. **Ownership copy states both halves in the same breath** (privacy §8; voice §2): the leading line frames the backup as a file the user keeps that the app moves nowhere, and the matching responsibility — lose this phone *and* the file and the record is gone, because there is no cloud and no account. Empathy-then-fact (voice §4): acknowledge the record matters, state the checkable fact, offer the export. Never "your data is safe," never fear-leverage of the spiritual stakes.
4. **Export/Import rows** are plain E10 rows (≥48dp `touch.min`, `space.2` apart), verbs in the locale's idiom ("Save backup" / "Restore from a file"), each one un-obstructed tap into the controller. Export progress renders only the controller's *real* serialize/encrypt progress — no indeterminate "syncing…" theater (privacy §2); completion is the quiet voice-§2 line ("Backup saved. All profiles, on this phone."), no celebration.
5. **Status line:** `type.caption`/`type.body` in `color.text.secondary` on the card surface — "Last backup: <date>" with the date rendered via the E02 presenter in the user's calendar (Hijri Umm al-Qurā / Solar-Hijri Jalālī / Gregorian) and locale numerals (۰۱۲ fa/ckb, ٠١٢ ar); "No backup yet" is a neutral fact. Never a streak, score, or "overdue" scold (voice §7).
6. **Encryption toggle:** an E10 `Switch` row, protective-default-**on** and visually primary (privacy §9), reversible, one honest sentence ("Locks your backup file with a password only you hold."). When off, the card shows the engineering-10-§2 plaintext line: an unencrypted backup is readable by anyone who opens the file. The no-recovery consequence is stated plainly — a forgotten passphrase cannot be reset, nothing is stored — never softened into a recovery promise. The pref persists via the T07 controller (persist-before-republish).
7. **Stale nudge:** when the controller's read model flags the last backup as old, render one quiet line ("Your last backup is from <date>") + a single export offer, in `color.text.secondary` on `color.surface.container` — **no** `color.semantic.warning`, no red/danger fill, no icon-of-alarm, dismissible in one tap, never re-escalating (privacy §10, §11-nagging). Staleness is computed by the controller from the injected `CalendarDate`, never in the View.
8. **Replace-vs-merge confirmation:** picking a file for import opens `restore_mode_dialog.dart` with **two explicit actions, separately confirmed, neither pre-selected** (engineering 10 §7): Replace — "This will replace all data currently in Hifz Companion"; Merge — "This will add the imported reviews to your existing history" (the teacher↔student path). Each confirm dispatches the matching T07→T06 method; Cancel is always available and never visually buried (privacy §11-interface-interference).
9. **Error copy keeps corruption and wrong-key distinct** (engineering 10 §3, §5): `integrityFailed` → the file is damaged/incomplete; `wrongPasswordOrDamaged` → the voice-§3 register ("Couldn't read this backup file. The password may be wrong — try again. Your data on this phone is unchanged."). Every error names cause, consequence, next step — no "Oops!", no blame, and always the reassuring *fact* that the live store is untouched.
10. **Strings, RTL, a11y** (eng-add-localized-string, eng-rtl-and-bidi-layout): every string is an `l10n.*` key in `app_ar.arb` (base) + transcreated fa/ckb (sensitive copy — tradeoff, encryption, errors — reviewed per locale per voice §9); layout by `EdgeInsetsDirectional`/`AlignmentDirectional` only; the backup **file name** (a mixed Latin/number run like `Hifz-2026-06-16.hifzbackup`) is FSI/PDI-isolated wherever shown; toggle and dialog announce label + role + state via `Semantics`; targets ≥48dp with visible focus rings.
11. **Pitfalls to avoid:** any cloud glyph/"Sign in"/"Upload"/"synced" string (even as a disabled affordance); a fake progress animation; pre-selecting Replace or blurring the two modes into one button; hiding the plaintext-readable line when encryption is off; a red/warning-filled stale nudge or one that returns after dismissal; computing staleness or the date in the widget; "your data is safe (with us)" or any recovery implication; a guilt line about an old backup; building erase UI (T09's) or leaf-widget anatomy (E10's); hardcoded strings or ASCII digits.

- [ ] Import presents Replace and Merge as **two explicit, separately-confirmed actions** with the verbatim §7 copy (transcreated), neither pre-selected; each dispatches the correct T07→T06 method; Cancel is unburied.
- [ ] Error states keep `integrityFailed` and `wrongPasswordOrDamaged` copy distinct, each with cause + next step + "your data on this phone is unchanged."
- [ ] Every string is an `l10n.*` ARB key in fa/ckb/ar (sensitive copy flagged for per-locale review); layout is RTL by geometry; the file name is FSI/PDI-isolated; targets ≥48dp; toggle/dialog/rows announce label + role + state; the five-strategy dark-pattern audit and the adab conscience pass are recorded.

## Tests

All deterministic and offline (the card opens no socket by construction), real bundled fonts, injected `CalendarDate` fixtures — no real clock, no `TZ` dependence in the View. Test-first on the no-cloud and copy invariants. No CLAIMS row applies: the card introduces no user-facing factual claim (the status date is a display-only render).

- `features/test/settings/backup_card_no_cloud_test.dart` (widget) — **written first**: pumps the card in every state (no-backup, dated, exporting, stale, each error) across fa/ckb/ar and asserts **no** cloud/sync/account glyph (icon predicate) and **no** "Sign in"/"Upload"/"sync" string anywhere in the tree; asserts no indeterminate progress indicator when the controller reports no work.
- `features/test/settings/backup_card_test.dart` (widget) — Export/Import rows (≥48dp, button role) dispatch to a recording fake controller and mutate nothing themselves (a recording repository double asserts zero writes); the status line renders "No backup yet" and "Last backup: <date>" from a fixture `CalendarDate` in locale numerals + the fixture calendar; the encryption toggle defaults on, announces its state, persists only via the fake controller, and toggling off reveals the plaintext-readable line.
- `features/test/settings/restore_mode_dialog_test.dart` (widget) — the dialog shows two distinct, non-pre-selected actions with the §7 replace/merge copy; confirming each calls the matching fake-controller method exactly once; Cancel calls nothing; each error variant renders its distinct copy (`integrityFailed` ≠ `wrongPasswordOrDamaged`).
- `features/test/settings/backup_stale_note_test.dart` (widget) — the nudge renders only when the read model flags staleness, uses no warning/red fill (color assert), dismisses in one tap, and does not reappear within the session after dismissal.
- `features/test/settings/backup_banned_phrase_test.dart` (unit) — the never-ship banned-phrase lint over every ARB value this task adds in fa/ckb/ar: guilt/fear/loss framing, mandate words, "your data is safe", "synced"/"upload"/"cloud", transactional words ("upgrade/premium/unlock"), `!`, emoji.
- `features/test/settings/backup_card_golden_test.dart` (golden) — per-locale (fa/ckb/ar) goldens of the card (dated status + nudge, no-backup, toggle-off with plaintext line) and the replace-vs-merge dialog, on the real bundled fonts, RTL, with a bidi-isolated `Hifz-….hifzbackup` file-name run and locale-numeral date.
- Offline guard: the suite runs under an `HttpOverrides` that fails any socket open (eng-write-dart-test) — the card and dialog make no network call in any state.
