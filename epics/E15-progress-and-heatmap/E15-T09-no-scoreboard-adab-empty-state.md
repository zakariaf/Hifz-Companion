## Goal

The adab layer that keeps the whole Progress surface honest situational awareness and never a scoreboard. Three things are wired onto the E15-T02 scaffold around the E15-T03 grid: (1) the **welcoming first-run / empty Progress state** — before any coverage exists, a calm fact plus one gentle next step into cold-start, never a guilt nag and never "Welcome back, N days"; (2) the **optional, opt-in, PRIVATE continuity indicator** — **OFF by default**, non-punitive, its value derived on read from the append-only `review_log`, with **no reset-to-zero streak mechanic**; (3) the **honest-recession missed-day behaviour** — a gap changes the map honestly (some green recedes, rendered by the T01→T04 pipeline as ordinary state) with **no shame UI**, and Progress offers one quiet, help-framed route to the **E12-owned catch-up plan** (it never builds the banner or the plan). The task also pins the negative space: no streak / best-day / points / level / leaderboard widget anywhere on or near the map, and completing a juz or session produces **no confetti, green flash, badge, or sound**. Every string is transcreated calm copy per locale, cleared by the never-ship banned-phrase pass.

## Implementation notes

This task is presentation plus exactly **one** persisted preference (the opt-in flag). No engine call, no `review_log` write, no `DateTime.now()`. Its invariants are mostly *negative space* — things that must never exist on this surface — so the adab widget tests and the banned-phrase lint are written **first**, before the visuals.

1. **Files** (in the `features` umbrella package, `lib/src/progress/`, per the T02 scaffold): `widgets/progress_empty_state.dart` (the first-run face), `widgets/continuity_indicator.dart` (the opt-in row + the indicator line), `widgets/catch_up_route_line.dart` (the single quiet route to Today). Wire them into `progress_screen.dart`'s switch over the T02 read model — add branches/slots only, do not re-architect the switch.
2. **First-run / empty state.** When the streamed model holds no memorized page, render the `ui-empty-state` first-run face in place of the grid: the calm fact plus **one** gentle next step into cold-start placement (gloss: "Your Quran map will appear here once you mark the juz you hold" → an invitation into onboarding, never a command). Flat `surface`/Level 0–1 `surfaceContainer`, `type.body`/`type.caption`, `color.text.secondary`, generous `space.*`; no mascot, no red, no `!`. Forbidden anywhere in this task's files/keys: "Welcome back", any "N days" greeting, any "you haven't …" phrasing. (A *partial* library renders as T03's grid with T04's muted cells — that is not this state.)
3. **Continuity indicator semantics — non-punitive by construction.** OFF by default (fresh install and any restore that lacks the flag). The value is **derived on read**: a windowed continuity fact — gloss "revised on N of the last ۳۰ days" — computed from append-only `review_log` dates as `CalendarDate` serial days against the injected clock, via a small read-only query in the data layer following the T01 read-model pattern, exposed through the ViewModel. Never a stored counter (derived health is never stored), and never a consecutive-day streak that snaps to zero on one miss — the breakable streak is precisely the punitive mechanic C-041/C-042 refuse. No target, no goal line, no "best", no comparison. The exact formulation/wording is cleared by the adab conscience pass before lock.
4. **The opt-in control.** A quiet row on the Progress surface (label + switch, ≥48dp `touch.min`); the flag persists through the **single write path** as a user preference (repository transaction commits before the in-memory republish, per `eng-create-riverpod-store`) — no new Drift table, no schema change, and no notification wiring (that is E16's `ui-reminder-row`). When off, the indicator is **absent from the tree entirely** (not greyed): nothing rendered, nothing announced, nothing in goldens.
5. **Private means private.** The indicator renders only on the user's own Progress surface: never on a teacher/halaqa surface, never in an export/share flow, never beside anything comparative. Placement is quiet — below/aside the grid, never as a header "score" over the map (08-data-visualization §8 bans anything scoreboard-like *on or near* the map). `color.text.secondary` on a flat surface; no medal, trophy, flame, or fire iconography of any kind.
6. **Missed day = honest recession, zero new rendering.** Recession is simply the T01-streamed lower `R` drawn by T04's ramp — this task adds **no** missed-day paint, overlay, red/amber mark, dimming, or broken-streak graphic on top of it. What it adds is the single calm route: when the backlog signal is true, one quiet help-framed line (gloss: "A catch-up plan is ready on Today") navigates via `go_router` to the Today tab, where the E12-T05 banner presents the re-spread plan. The line names **no day count** and carries no blame — the empathy-then-plan register (with its counts) belongs to the banner, not to Progress chrome (voice §3/§4).
7. **Never re-derive the gap.** The backlog-exists signal comes from the same E12-owned controller logic that shows the Today banner (computed from the injected `CalendarDate`), surfaced to the Progress ViewModel as a pre-built boolean. This View never reads `DateTime.now()`, never counts days, never calls the engine, never inspects `review_log` directly.
8. **The no-celebration guarantee.** When the streamed model improves — a page turns greener, a juz reaches full strength, a session completes elsewhere — the only motion on Progress is T04's standard cell transition (`motion.duration.short`, `motion.curve.standard`, reduce-motion → instant). This task pins the negative space: no confetti/party/fireworks widget, no success-green flash (there is no `color.semantic.success` token to reach for), no badge, no sound, no success/reward haptic, anywhere on the surface (06-motion §2/§4; 03-color §6).
9. **Strings via the ARB pipeline, transcreated for fa/ckb/ar** (`eng-add-localized-string`): keys e.g. `progressFirstRunFact`, `progressFirstRunNextStep`, `progressContinuityOptInLabel`, `progressContinuityValue` (ICU `plural`, ar's six categories), `progressCatchUpRoute` — in `app_ar.arb` (template) + transcreated fa/ckb (ckb flagged pending native + scholar review); every count renders in the locale numeral set via `numberFormatFor(locale)` with mixed runs FSI/PDI-isolated; register per voice §3/§8 — statements of readiness, softened Arabic imperative, warm-respectful Persian.
10. **RTL + accessibility.** `EdgeInsetsDirectional`/`AlignmentDirectional` only; one calm `Semantics` announcement per surface (the empty state announces fact + next step; the indicator, when on, announces value + label in the active locale; the route line announces label + button role with a visible focus ring); ≥48dp targets throughout; ckb's longer copy reflows within the same insets.
11. **Pitfalls to avoid:** a consecutive-day streak with reset-to-zero; the flag ON by default, or a nag prompt asking the user to opt in; storing a continuity counter; counting days or reading the clock in a widget; any red/amber tint, warning icon, or "overdue" framing on the route line; a celebratory transition when the map improves; "Welcome back"/"you're behind"/"N days lost" in any locale; placing the indicator over the grid like a score; building any banner/plan UI on Progress; turning the opt-in row into a notification setting; an `!` or emoji in any string.

## Tests

All deterministic, offline by construction, real bundled fonts, seeded read-model fixtures and the injected `CalendarDate` (never a real clock). The adab/negative-space tests and the lint are written **first**.

- `features/test/progress/progress_empty_state_test.dart` (widget) — **written first**: the zero-coverage model renders the calm fact + one next step (invitation register); asserts the absence of any "Welcome back"/"N days"/guilt text across fa/ckb/ar; tapping the next step navigates toward cold-start (a fake `go_router` records the push) with **zero** writes (a recording repository asserts none).
- `features/test/progress/continuity_indicator_test.dart` (widget) — default state is off with the indicator **absent** from tree and semantics; toggling on persists the flag through the recording repository (transaction before republish, and no other write); when on, the value renders in locale numerals via ICU plural; a fixture with a one-day gap shows the windowed value adjust honestly with no reset-to-zero, no red, no broken-streak widget.
- `features/test/progress/missed_day_recession_test.dart` (widget) — a seeded post-gap model renders lower-`R` cells with unchanged chrome (no overlay/red mark/shame widget anywhere in the tree); exactly one route line appears; it renders no day count; tapping it pushes the Today route on the fake router; with the backlog signal false, the line is absent.
- `features/test/progress/no_scoreboard_test.dart` (widget) — the negative-space guard: pumps zero-coverage, populated, post-gap, improving, and juz-completed models and asserts no widget/key/`Semantics` node matching streak/best-day/points/level/leaderboard/badge/confetti exists on the surface, and no success haptic fires (a fake haptic boundary records zero reward calls); a source scan asserts no confetti/celebration package import under `lib/src/progress/`.
- `features/test/progress/adab_banned_phrase_test.dart` (unit) — the never-ship banned-phrase lint over every ARB value this task adds in fa/ckb/ar (guilt/fear/loss, "you're behind", "N days", mandate words, "safe to drop"/"mastered"/"done", `!`, emoji); pins that no "welcome back"-family key exists at all.
- `features/test/progress/adab_states_golden_test.dart` (golden) — per-locale (fa/ckb/ar) goldens of the first-run face, the indicator-on state, and the missed-day route line on real bundled fonts; these goldens feed E15-T10's consolidated RTL + greyscale/deuteranope + offline suite.
- Offline guard: the suite runs under the `HttpOverrides` socket-failing harness (`eng-write-dart-test`) — nothing in this task may open a socket; the consolidated cross-surface harness is E15-T10's.
