## Goal

The details-on-demand end of the heat-map's *overview → zoom → details* mantra: tapping a page cell opens a **page-detail sheet** that tells the ḥāfiẓ, honestly and calmly, where this one page stands. Three read-only parts: (1) a drill-down header row composed from **E10's page-card** (track chip + calm decay indicator + "Page N · Juz M" in locale numerals); (2) the **retrievability statement** — a **range in words** with its **basis** ("estimated — not yet recited" / "from self-rating"), paired with the concrete **next-due date** rendered by the one `CalendarPresenter` in the user's chosen calendar and locale numerals — **never** a false-precise single percent, never raw `R`/D/S, never a bare "weak" standing alone; (3) a **short history** from the append-only `review_log` (localized date · grade in the traditional verb · source), read-only, no internals. Two ≥48dp handoffs — *recite this page* (E12) and *open in the reader* (E13) — navigate away; the sheet itself renders **no Quran glyph**. Everything shown comes pre-derived from the E15-T01 read model; this task computes nothing.

## Implementation notes

This task is presentation-only: no engine call, no `review_log` write, no `DateTime.now()`, no calendar arithmetic. It renders a sheet-shaped projection of the E15-T01 read model and hands off via `go_router`. The honesty invariants (range in words, no bare percent, no raw `R`/D/S) and the adab floor are **copy correctness-critical** → pinned test-first by widget tests + the banned-phrase lint before the visuals are polished.

1. **Files** (in the `features` umbrella package, `lib/src/progress/`, per eng-add-feature-module): `widgets/page_detail_sheet.dart` — the `PageDetailSheet` plus one `showPageDetailSheet(BuildContext, pageId)` entry point (modal bottom sheet) that T03's cell tap and later T07's list rows both call; `widgets/retrievability_statement.dart` — the range-in-words + basis + next-due block; `widgets/review_history_list.dart` — the short read-only history. All dumb stateless widgets taking pre-built values; wire the tap in the T02 scaffold's existing providers without re-architecting it.
2. **The sheet's input is a projection, not the raw model.** The 1:1 ViewModel maps T01's streamed per-page model to a sheet value carrying: the words-range band, a basis enum (cold-start prior / self-rating / teacher sign-off, per PRD §7.10, §8.1–§8.2), the `due_at` `CalendarDate`, and the capped history rows. **No raw `R`/`D`/`S` double crosses into the widget layer** — grep-able over the `widgets/` files; the widget cannot format what it never receives.
3. **Header row = E10's page-card, composed not rebuilt.** Track chip + calm decay indicator + "Page ۲۵۳ · Juz ۱۳" headline in locale numerals, FSI/PDI-isolated, `MergeSemantics` into one localized phrase (ui-page-card checklist). The row shows the calm band label only — never a percentage, never `R` — and is not a second independent tap target inside the sheet.
4. **The retrievability statement is a range in words + basis + due date, as one unit.** Band/range phrasing in words (ARB, transcreated), with the basis text — the doc's exemplars are "estimated — not yet recited" and "from self-rating"; a teacher-confirmed basis names its source per §8.2 — always paired with the concrete next-due date so no vague word stands alone (08 §5). If a coarse numeric range accompanies the words, **both endpoints** render via `numberFormatFor(locale)` and it is always a range — a single crisp figure is forbidden (08 §4; C-025). `type.body` on a flat surface; basis in `type.caption` / `color.text.secondary`.
5. **Next-due through the one `CalendarPresenter` only.** The streamed `due_at` `CalendarDate` → the user's chosen calendar (Jalālī default for fa · Hijri Umm al-Qurā · Gregorian) → locale numerals remapped downstream of the conversion → FSI/PDI-isolated into the sentence. The view never constructs a `Jalali`/`HijriCalendar` and never recomputes a due date; switching the Settings calendar re-renders this line and changes nothing else (12-localization §5).
6. **History: short, read-only, over the append-only log.** A capped list (the most recent handful, newest first) of rows from T01's read path over `review_log`: localized date via the same `CalendarPresenter` · the grade as the **traditional verb from the active term-set** (PRD §13.4) · the source ("self" / "teacher", with the optional `teacher_label`). Never render `r_predicted`/`s_*`/`d_*`; an Again/lapse row is stated plainly in neutral tokens — no red, no strike-through, no shame styling; a teacher row may carry the quiet teacher-source marker, no trophy styling.
7. **Handoffs navigate, never mutate.** Two ≥48dp `touch.min` affordances: *recite this page* → the E12 recite/grade route; *open in the reader* → the E13 reader route at this page — both via `go_router` pushes. The sheet renders **no glyph, no āyah preview** (the muṣḥaf lives only in the reader); no grade, config, or log write originates here.
8. **Strings via the ARB pipeline, transcreated for fa/ckb/ar** (eng-add-localized-string): range/basis phrasing, next-due sentence, history labels, handoff labels — every one an `l10n.*` key in `app_ar.arb` (template) + transcreated `fa`/`ckb` (ckb flagged pending native+scholar review); date/number placeholders flow through the presenter/formatter, never string-spliced; any count through ICU `plural` (ar's six categories).
9. **RTL + accessibility by construction** (eng-rtl-and-bidi-layout): `EdgeInsetsDirectional`/logical start-end only; the sheet announces one calm `Semantics` summary (page identity + range-in-words + basis + next-due) in the active locale; history rows read as merged phrases; handoffs announce label + button role with a visible focus ring; the sheet entrance uses `motion.duration.short` + `motion.curve.standard` and degrades to instant under reduce-motion.
10. **Pitfalls to avoid:** recomputing `R`/`due_at`/history in the widget (T01 owns all health data); formatting a raw `R` as a percent "just for the sheet"; a bare "weak" with no range and no due date; presenting a cold-start prior as confident; constructing a calendar object or hardcoding a Gregorian grid in the view; ASCII digits in any run; any `UPDATE`/`DELETE` shape over `review_log` (or any write at all); "safe to drop"/"mastered"/"done" phrasing; celebratory styling on a strong page or shame styling on a lapse row; a glyph preview; making the header row's chip/indicator separately tappable.

## Acceptance criteria

- [ ] `progress/widgets/page_detail_sheet.dart`, `retrievability_statement.dart`, `review_history_list.dart` exist in the `features` package; each is a dumb stateless widget taking a pre-built value with no engine call, no `DateTime.now()`, no calendar construction, and no write (verifiable by grep over the files).
- [ ] Tapping a T03 grid cell opens the sheet via the single `showPageDetailSheet(...)` entry point; the header row is E10's page-card (track chip + decay indicator + locale-numeral "Page N · Juz M", one merged `Semantics` phrase) and shows no percentage and no raw `R`.
- [ ] Retrievability is stated as a **range in words with its basis** — a cold-start-prior page reads "estimated — not yet recited," a self-rating-only page reads "from self-rating" (teacher-confirmed names its source) — always paired with the next-due date; **no single-value percent and no raw `R`/D/S string appears anywhere in the sheet's widget tree**.
- [ ] The next-due date renders through the one `CalendarPresenter` in the user's chosen calendar (Jalālī / Hijri Umm al-Qurā / Gregorian) with locale numerals remapped downstream and the run FSI/PDI-isolated; changing the calendar preference re-renders the date without touching any stored state.
- [ ] The history is a capped, read-only list derived from the append-only `review_log`: localized date · term-set grade verb · source (+ optional `teacher_label`); `r_predicted`/`s_*`/`d_*` never render; a lapse row uses neutral tokens with no alarm/shame styling.
- [ ] The two handoffs (*recite this page* → E12, *open in the reader* → E13) are ≥48dp, navigate via `go_router`, and cause zero writes; the sheet renders no Quran glyph.
- [ ] Every user-facing string is an `l10n.*` ARB key present in fa/ckb/ar (ar template; ckb flagged pending native+scholar review); no hardcoded user-facing text; no ASCII digit reaches a widget.
- [ ] Layout is RTL by geometry (`EdgeInsetsDirectional`, no `left`/`right`); the sheet announces one calm `Semantics` summary per open; focus ring visible on the handoffs; reduce-motion degrades the entrance.
- [ ] The never-ship banned-phrase lint passes over all three locales for every string this task adds (no guilt/fear/loss, no "safe to drop"/"mastered"/"done", no mandate word, no `!`/emoji); the adab conscience pass is recorded.

## Tests

All deterministic, offline by construction, real bundled fonts, seeded fixtures with a fixed injected `CalendarDate` (never a real clock). Test-first on the honesty/adab invariants.

- `features/test/progress/page_detail_sheet_test.dart` (widget) — **written first**: a seeded cold-start-prior page renders the range in words + "estimated — not yet recited"; a self-rating-only page renders its range + "from self-rating"; asserts **no** single-value percent (`%`/`٪` with one number) and **no** raw `R`/`D`/`S` text anywhere in the tree; both handoffs are ≥48dp, push the expected E12/E13 routes on a recording router, and a recording repository asserts **zero** writes.
- `features/test/progress/next_due_presenter_test.dart` (widget) — from one fixed `CalendarDate` due date, the next-due line renders in Jalālī + Extended Arabic-Indic under `fa`, Umm al-Qurā Hijri + Arabic-Indic under `ar`, and Gregorian when chosen — all through the injected `CalendarPresenter` fake/real presenter, FSI/PDI-isolated; asserts the widget constructed no calendar object of its own.
- `features/test/progress/review_history_list_test.dart` (widget) — rows come from a seeded `review_log` fake (mixed self/teacher, one Again lapse): asserts date · term-set grade verb · source render per row, newest first, capped; `r_predicted`/`s_before`/`d_after` values never appear; the lapse row carries no `color.semantic.error`/alarm styling; the fake's read-only DAO records no update/delete call.
- `features/test/progress/detail_sheet_banned_phrase_test.dart` (unit) — the never-ship banned-phrase lint over every ARB value this task adds in fa/ckb/ar (guilt/fear/loss, "safe to drop"/"mastered"/"done"/"finished", mandate words, `!`, emoji) and pins that no key formats a single-value retention percent.
- `features/test/progress/page_detail_sheet_golden_test.dart` (golden) — per-locale (fa/ckb/ar) goldens of the cold-start-basis variant, the self-rating-basis variant, and the history list, on real bundled fonts under `Directionality.rtl`; these goldens are the seed E15-T10 consolidates into the Progress suite.
- Offline guard: the suite runs under an `HttpOverrides` that fails any socket open (eng-write-dart-test) — the sheet renders streamed state and never touches the network.
