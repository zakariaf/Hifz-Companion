# E15-T04 — Green-receding ramp + redundant colour+number+label cells + VSUP uncertainty muting

| | |
|---|---|
| **Epic** | [E15 — Progress & Heat-map](EPIC.md) |
| **Size** | M (≈1-2 days) |
| **Depends on** | E15-T03, E10 |

## Goal

Every page cell in the E15-T03 grid gets its honest appearance. Three encodings are applied to E10's heat-map cell leaf, driven entirely by the E15-T01 read model: (1) the **single-hue green-receding ramp by token name** — `color.heatmap.strong → good → fair → weak → faded`, monotonic in luminance, the decay end a muted neutral — never alarm-red, never a rainbow/traffic-light; (2) **redundant non-colour channels** — every cell carries a plain localized **band label** (the "strong" / "softening" / "ready for revision" register) plus a **coarse locale-numeral value** via `numberFormatFor(locale)`, FSI/PDI-isolated, with an optional decay texture on the weak end, so a greyscale, deuteranope, or screen-reader user reads the same map; (3) **VSUP-style uncertainty muting** — a never-recited cold-start-prior page or a self-rating-only page renders visibly muted from the read model's confidence flag and **cannot reach the most-saturated tier on one self-rating** (PRD §8.1). One reconciliation is handled explicitly: the crisp retrievability figure and its basis belong to E15-T06's detail sheet; the cell's number is coarse reinforcement of the label, never a retention-percentage promise (C-025).

## Implementation notes

This task is presentation-only: no engine call, no `review_log` write, no `DateTime.now()`, no recomputation of `R`/confidence/band. It maps the E15-T01 read model onto E10's cell leaf. The band labels are copy correctness-critical for adab (a wrong word turns the map into a scoreboard) → the label set and the no-alarm/no-cap invariants are pinned test-first.

1. **Files** (in the `features` umbrella package, `lib/src/progress/`, per the E15-T02 module anatomy):
   - `widgets/heat_cell_encoding.dart` — a **pure, deterministic presentation mapping**: an exhaustive `switch` over the read model's band enum → one `color.heatmap.*` ramp step + one band-label ARB key + the coarse display value; plus the muting pass-through (read model flag → leaf `muted` state). No widget, no I/O, unit-testable in isolation.
   - `widgets/page_heat_cell.dart` — the dumb per-page cell: composes E10's heat-map cell leaf with the encoding's output and the `Semantics` value+label. No state, no clock, no engine.
   - Slot `PageHeatCell` into E15-T03's grid cell position; touch nothing else in the grid.
2. **Ramp by token name, exhaustively, and nothing else is reachable.** One band → one ramp step, covering every band the read model can emit (an exhaustive `switch`, so a new band is a compile error, not a silent grey). The encoding may emit **only** `color.heatmap.*` tokens — never `color.semantic.warning`, never a success/accent flash, never an inline hex (a raw hex is a lint failure; 03 §6; token discipline). Monotonic luminance and the per-appearance values are 03 §5's property — consumed, not re-implemented.
3. **The reconciliation — label first, number coarse (C-025).** 08 §5 wants a number in the cell, but C-025 forbids a retention-percentage promise and E15-T06 owns the honest range-in-words + basis. So: the cell's **primary** non-colour channel is the plain band **label**; the numeric channel is the read model's **coarse** display value rendered as quiet reinforcement (small, `type.caption`-scale via the leaf's slot) — never headlined, never phrased as a guarantee, never a crisp "87%" promise. Display rounding is formatting inside the pure encoding, not health math; the crisp figure + basis stay behind the tap in T06.
4. **VSUP muting: this task decides *when*, E10 owns *how*.** Set the leaf's muted state from the read model's confidence flag: a never-recited cold-start-prior page renders at the faded/muted treatment regardless of its optimistic prior; a self-rating-only page reads less vivid than a teacher-confirmed one. The visual mechanics of muting (desaturation treatment, texture) are the E10 leaf's — do not hand-roll an opacity hack here.
5. **The top-tier cap.** When the muting flag is set, the encoding **clamps the ramp step below `color.heatmap.strong`** — an uncertain page cannot render the most-saturated tier no matter what its band says. This is the visual mirror of PRD §8.1 ("self-rating alone cannot push a page to the top retention tier"); the flag comes from T01, the clamp is pinned by a widget test.
6. **Numerals: one path, isolated.** Every cell value flows through `numberFormatFor(locale)` (ui-numerals-calendar-text) — Extended Arabic-Indic for fa/ckb, Arabic-Indic for ar, never raw ASCII, never `n.toString()` spliced into a label. The numeral run is FSI/PDI-isolated inside the RTL label run as a formatted ARB placeholder (12 §3, §4); verify digits per surface (the known `intl` caveat).
7. **Band labels via the ARB pipeline** (eng-add-localized-string): one key per band (e.g. `heatBandStrong` … `heatBandReadyForRevision`) plus the muted cell's estimate qualifier (e.g. `heatCellEstimated`), in `app_ar.arb` (template) + transcreated `fa`/`ckb` (ckb flagged pending native review). Register per 08 §3/§5: "strong," "softening," "ready for revision" — maintenance words; never "decaying/rotting/lost/failing/overdue," never "mastered/safe," no `!`. Final wording passes the adab/banned-phrase gate before ship.
8. **Optional decay texture = the third channel.** Enable the leaf's decay texture for the weak/faded bands so healthy-vs-decaying survives even with colour *and* lightness gone (08 §5) — it comes from the E10 leaf's state matrix, not custom paint here.
9. **Semantics.** Each cell announces its band label + coarse value in the active locale (09 §7 conventions via the leaf's `Semantics` slot); a muted cell appends the localized estimate qualifier so uncertainty is audible, not only visual. Colour is announced never — it is reinforcement, not the message.
10. **Pitfalls to avoid:** re-deriving `R`/confidence/band in the widget (T01 owns them); inlining a hex or restating the 03 §7 audit; mapping any band to a token outside `color.heatmap.*`; letting a muted page hit `color.heatmap.strong`; headlining the number or phrasing it as a promise (C-025 — the range + basis is T06's); ASCII digits or an un-isolated numeral run; a hardcoded label string; styling the juz tile (T05) or the sheet (T06); changing grid geometry (T03); any celebratory treatment of a fully-strong cell (no glow, no badge, no animation).

## Acceptance criteria

- [ ] `progress/widgets/heat_cell_encoding.dart` and `page_heat_cell.dart` exist; the encoding is a pure exhaustive mapping (band → ramp token + ARB label key + coarse value; flag → muted) with no widget/I/O imports; the cell is a dumb stateless widget with no engine call and no `DateTime.now()` (verifiable by grep).
- [ ] Every band renders one `color.heatmap.*` step **by token name**; no inline hex anywhere in the task's files; no token outside `color.heatmap.*` is reachable from the encoding — no `color.semantic.*`, no red, no rainbow.
- [ ] Every cell carries all three channels: ramp colour + a plain localized band label + a coarse locale-numeral value (weak/faded cells additionally the decay texture); no cell state is conveyed by colour alone (SC 1.4.1; PRD §18).
- [ ] The cell's number is coarse reinforcement — visually subordinate to the label, never a headlined percent, never promise-phrased; the crisp figure + basis appear only in E15-T06's sheet (C-025).
- [ ] A never-recited (cold-start-prior) page renders the muted/faded treatment regardless of its prior; a self-rating-only page renders muted; a muted page **never** renders `color.heatmap.strong` — one self-rating cannot reach the most-saturated tier (PRD §7.10, §8.1; 08 §4).
- [ ] The muting decision comes only from the E15-T01 read model's flag; nothing in this task recomputes `R`, `sourceConfidence`, the band, or any aggregate.
- [ ] Every value renders via `numberFormatFor(locale)` in the locale digit set (۰۱۲ fa/ckb, ٠١٢ ar), FSI/PDI-isolated as an ARB placeholder; no raw ASCII digit and no spliced substring in any localized string.
- [ ] Every label is an `l10n.*` ARB key present in fa/ckb/ar (ar template; ckb flagged pending native review), transcreated; the label set passes the adab/banned-phrase gate (no loss/alarm/shame word, no "mastered"/"safe to drop", no `!`).
- [ ] Each cell exposes one `Semantics` announcement: band label + coarse value in the active locale, plus the estimate qualifier when muted.

## Tests

All deterministic, offline by construction, real bundled fonts, seeded read-model fixtures (never a live engine or clock). Test-first on the label set and the cap/no-alarm invariants.

- `features/test/progress/heat_cell_encoding_test.dart` (unit) — **written first**: the band→token mapping is exhaustive and emits only `color.heatmap.*` (asserted over every band value); the muting flag clamps the step below `strong`; the coarse value is deterministic for a fixed input; no non-heatmap token is reachable.
- `features/test/progress/page_heat_cell_test.dart` (widget) — a strong, a decaying, and a muted-uncertain fixture cell each expose **colour + number + label** (finders assert the label text, the locale-numeral value, and the leaf's band state); the decaying cell shows the texture channel; a page with exactly one self-rating renders muted and **not** the top tier; `Semantics` announces label + value (+ estimate qualifier when muted).
- `features/test/progress/heat_cell_greyscale_order_test.dart` (widget) — renders the five band cells side by side, converts the captured image to greyscale/deuteranope simulation, and asserts magnitude order still reads (mean luminance strictly monotonic across bands per appearance) and the muted cell is distinguishable from a confident one — colour is provably not the sole channel.
- `features/test/progress/heat_band_labels_adab_test.dart` (unit) — runs the banned-phrase lint over every ARB value this task adds in fa/ckb/ar (loss/fear/alarm words, "overdue"/"failing"/"lost", "mastered"/"safe"/"done", mandate words, `!`, emoji) and pins that every band key exists in all three locales.
- `features/test/progress/page_heat_cell_golden_test.dart` (golden) — per-locale (fa/ckb/ar) goldens of the strong / softening / ready-for-revision / muted-uncertain cells on real bundled fonts, locale numerals visible and isolated; these goldens are the cell inputs E15-T10 consolidates.
- Offline guard: the suite runs under an `HttpOverrides` that fails any socket open — the cell renders streamed state only. (The full-surface per-locale RTL/CVD/offline consolidation is E15-T10, not re-run here.)

## Definition of Done

- [ ] All acceptance criteria met; the encoding unit test and adab lint were written first and are green; the per-locale cell goldens run in CI on the real bundled fonts.
- [ ] **Offline / no-network**: the cell renders read-model state only — never fetches, records, or opens a socket; the `HttpOverrides` guard passes (PRD C1).
- [ ] **No AI / no microphone**: nothing here infers, records, or transcribes; the muting flag is deterministic engine output read from T01, not a model (PRD C2, §8.3).
- [ ] **Quran text fidelity (R1)**: the visualization layer renders and tints **no Quran glyph** — cells are UI chrome about pages, never sacred text; no decoration touches the muṣḥaf layer.
- [ ] **Never "safe to drop" (§7.12)**: no band label or qualifier says or implies "safe," "mastered," "done," or "finished"; the faded end is framed as un-reviewed/ready-for-revision — quiet, never "lost"; the strong end is a state, never a trophy.
- [ ] **No gamification / no shame (R3, C6)**: no alarm-red is reachable from the encoding; no streak/score/badge/celebration on or in any cell; a fully-strong cell gets no glow or flash; decay reads as calm recession, never a failing scoreboard (08 §3, §8; 03 §6).
- [ ] **Honest about prediction**: uncertain pages render muted (VSUP) and are capped below the most-saturated tier on one self-rating; the cell makes no retention-percentage promise — coarse number as reinforcement, the range-in-words + basis deferred to T06 (08 §4; PRD §7.10, §8.1; C-025).
- [ ] **The widget is dumb**: band, value, and confidence come from the E15-T01 read model; this task never recomputes `R`/`due_at`/confidence/aggregate and never reads `DateTime.now()`.
- [ ] **RTL + fa/ckb/ar localization**: every label ships through the ARB pipeline (ar template + fa/ckb, transcreated, ckb flagged pending native review); every numeral is locale-set via `numberFormatFor(locale)` and FSI/PDI-isolated; layout stays logical (the leaf under T03's `Directionality.rtl` grid); no hardcoded user-facing string.
- [ ] **Accessibility (WCAG 2.2 AA)**: colour is never the sole channel (SC 1.4.1) — label + number (+ texture) on every cell; the 3:1 strong-anchor posture is inherited from the 03 §7 audit (not restated); the greyscale/deuteranope test proves magnitude order survives; `Semantics` announces value + label per locale.
- [ ] **Sect-neutral adab**: the band-label set cleared the adab conscience pass and the banned-phrase lint in all three locales — maintenance words only, no fiqh ruling, no guilt/fear/loss framing.
- [ ] **Deterministic tests**: all tests run on seeded fixtures with no hidden clock and no network; goldens are byte-stable on the pinned fonts; all gates stay green.
