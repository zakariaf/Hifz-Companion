## Goal

The tests **are** the deliverable: the consolidated golden + accessibility + offline harness that hardens the whole Progress surface before it becomes the app's central emotional screen. Three legs, one seeded fixture: (1) **per-locale (fa/ckb/ar) RTL goldens** of the five surfaces — the 604-page cluster grid, a min-leaning juz tile with its weakest-page badge, a muted (uncertain) cell beside a confident weak one, the page-detail sheet, and the upcoming-load forecast — pumped under the locale's `Directionality.rtl` on the **real bundled UI fonts** (never Ahem), `@Tags(['golden'])`, run only on the pinned Linux golden lane; (2) a **greyscale/deuteranope check** proving the ramp's magnitude order still reads with hue removed — colour is never the sole channel; (3) a **throwing `HttpOverrides` offline guard** proving the entire surface, driven end-to-end, opens no socket. Plus the automated contrast checks (the `color.heatmap.strong` anchor clears 3:1) and the visual **no-glyph / no-scoreboard** invariants asserted over every master. This task builds no surface and re-implements nothing — it captures what T03–T09 built and feeds the release-gate suite (E20; PRD §20 gates 5 & 6).

## Implementation notes

This task writes tests only: no production widget, provider, string, or token changes. Everything is driven from one deterministic fixture through the T01 provider override — the harness never calls the engine, never reads `DateTime.now()`, never touches a real database.

1. **Files** (in the `features` package): `features/test/progress/golden/progress_surface_golden_test.dart` (+ committed masters under `features/test/progress/golden/goldens/progress/`), `progress_cvd_golden_test.dart`, and untagged `features/test/progress/progress_cvd_magnitude_test.dart`, `progress_offline_guard_test.dart`, `progress_a11y_contrast_test.dart`, `progress_no_scoreboard_no_glyph_test.dart`, plus a shared `progress_golden_fixture.dart` harness.
2. **One frozen fixture, injected — never computed.** Build a `ProgressReadModel` value covering: all five bands (`strong → faded`), a VSUP-muted never-recited page **and** a muted self-rating-only page next to a confident weak cell, one mostly-strong juz whose min-leaning tile is failed/badged by a single decaying page, a detail-sheet page with range-in-words + basis + next-due + a short history, and a multi-day forecast with counts that exercise ar's plural categories. Override `progressHeatmapProvider` with it; fix the injected `Clock`/`CalendarDate`. No retrievability arithmetic in this file — frozen literals only (the math is pinned in E04/T01).
3. **Golden harness discipline** (eng 11 §5): `setUpAll` loads the real bundled fa/ckb/ar UI fonts via `FontLoader`; fixed `tester.view.devicePixelRatio = 2.0` and `physicalSize`; Light theme; no animations; `@Tags(['golden'])` at the top of both golden files so only the pinned lane (`--tags=golden`) renders them. Master naming: `goldens/progress/<surface>_<locale>.png` — 5 surfaces × 3 locales = 15 masters, plus the CVD-filtered captures.
4. **Per-locale pump**: a `MaterialApp` with the target `locale`, the app's localization delegates, and the screen under `Directionality.rtl` (all three locales are RTL — asserted by construction, not by mirroring flags). Masters must visibly show Extended Arabic-Indic numerals (۰۱۲) for fa/ckb and Arabic-Indic (٠١٢) for ar in cell values, page numbers, and forecast counts, and the localized band labels; ckb (typically the longest transcreation) is the binding reflow case — no truncated label in its masters.
5. **Greyscale/deuteranope, two ways.** (a) *Golden:* wrap the pumped grid in a `ColorFiltered` greyscale (luminance) matrix and a deuteranopia-simulation matrix and capture masters — a human reviews that band order still reads. (b) *Programmatic (fast lane):* read the five `color.heatmap.*` values from the theme, apply the same two matrices, and assert relative luminance stays **strictly monotonic** strong → good → fair → weak → faded under both — pinning 03-color §7's "magnitude order survives greyscale and CVD" against future token drift. Redundancy makes this honest: the same masters show number + label per cell, and the weakest-pages list (T07) remains the fully non-visual equivalent (09-a11y §4, A3).
6. **Offline guard as an interaction journey, not a smoke test**: install the throwing `HttpOverrides` (reuse `useOfflineTestPolicy()`), then pump the full Progress surface and drive it — grid renders, tap a cell → detail sheet opens, open the forecast — asserting normal completion. Any socket attempt anywhere in the tree throws `StateError` and fails loudly (eng 11 §7).
7. **Contrast checks**: run `meetsGuideline(textContrastGuideline)` over the pumped Progress screen (A1), and compute the WCAG relative-luminance ratio of `color.heatmap.strong` against `color.bg.primary` **from the resolved theme tokens** in Light and Dark, asserting ≥ 3.0 (A2, SC 1.4.11). Do **not** assert 3:1 on `good/fair/weak/faded` — they are below the floor by design inside labelled cells; a test that "fixes" them contradicts the audit.
8. **No-glyph / no-scoreboard assertions** over the same pumped trees: no widget renders with a KFGQPC page-font family and no muṣḥaf page widget is present (the visualization layer is glyph-free; PRD R1 lives in E13's reader); no streak/score/points/badge/leaderboard widget or string anywhere; T09's continuity indicator absent in the default (opted-out) state; no `!`/celebration chrome in any master (C-041, C-044).
9. **Lane placement**: only the two golden files carry `@Tags(['golden'])`; the CVD-magnitude, offline, contrast, and invariant tests are untagged so the fast job runs them on every push. Touch no `.github/workflows/*` — E01's lanes already run both tags.
10. **Pitfalls to avoid**: forgetting `FontLoader` (Ahem squares silently pass numeral goldens); `pumpAndSettle()` anywhere an indicator could animate — pump explicit durations; regenerating masters in CI or on macOS (pinned-Linux-only, regenerated locally + reviewed); hardcoding a hex/px in an assertion instead of reading the theme token; recomputing `R`/bands in the fixture; a fixture so uniformly green the min-leaning tile, muted cell, and badge are invisible in the masters; asserting the whole 604-cell grid pixel-by-pixel at a size where cells are sub-pixel — size the surface so one juz block is legible.

## Acceptance criteria

- [ ] 15 per-locale masters (grid, min-leaning juz tile + badge, muted cell beside a confident weak cell, detail sheet, forecast × fa/ckb/ar) are committed under `features/test/progress/golden/goldens/progress/` — captured on the real bundled UI fonts, fixed DPR/surface, each under its locale's `Directionality.rtl` — and green on the pinned golden lane.
- [ ] Every master visibly carries the redundant channels: ramp colour + locale-numeral value (۰۱۲ fa/ckb, ٠١٢ ar) + localized band label per cell; the detail-sheet master shows a range **in words** with its basis and a next-due date — no bare single percent, no raw `R`/D/S (C-025).
- [ ] The juz-tile master shows a mostly-strong juz honestly failed/badged by one weak page (badge at the logical start); the muted-cell master is visually distinguishable from the confident weak cell.
- [ ] Greyscale **and** deuteranopia captures of the grid are committed, and the programmatic check asserts strict luminance monotonicity of the five ramp tokens under both matrices — magnitude order reads without hue.
- [ ] The offline guard drives grid → cell tap → detail sheet → forecast under the throwing `HttpOverrides` and passes; any socket open anywhere fails the suite by construction.
- [ ] `meetsGuideline(textContrastGuideline)` passes on the pumped Progress screen, and `color.heatmap.strong` vs `color.bg.primary` ≥ 3:1 in Light and Dark, computed from theme tokens.
- [ ] The no-glyph and no-scoreboard assertions pass: no KFGQPC-family text or muṣḥaf page widget in any pumped tree; no streak/score/badge/leaderboard widget or string; the T09 indicator absent by default in every master.
- [ ] Only the golden files carry `@Tags(['golden'])`; all other tests run in the fast lane; no CI workflow file was touched; ckb masters show no truncated label.
- [ ] All six test files consume the one shared fixture harness; no test file computes retrievability, calls the engine, or reads `DateTime.now()` (grep-verifiable); the forecast fixture counts exercise ar's plural categories.

## Tests

All deterministic and offline by construction: one frozen fixture through the T01 provider override, the injected `Clock`/`CalendarDate`, real bundled fonts, pinned lane for pixels. The tests are this task's entire output.

- `features/test/progress/golden/progress_surface_golden_test.dart` (`@Tags(['golden'])`) — the 15 per-locale RTL masters of the five surfaces; pins locale numerals, localized band labels, badge-at-logical-start, range-in-words in the sheet, plural-correct forecast counts, and ckb reflow.
- `features/test/progress/golden/progress_cvd_golden_test.dart` (`@Tags(['golden'])`) — greyscale- and deuteranopia-filtered captures of the grid for human review of band-order legibility (A3).
- `features/test/progress/progress_cvd_magnitude_test.dart` (unit/widget, fast lane) — strict monotonic relative luminance of `color.heatmap.strong → faded` under the greyscale and deuteranopia matrices, read from the theme — pins the ramp's CVD survivability against token drift.
- `features/test/progress/progress_offline_guard_test.dart` (widget) — the full grid → sheet → forecast journey under the throwing `HttpOverrides`; completes with zero socket attempts (PRD §20 gate 6).
- `features/test/progress/progress_a11y_contrast_test.dart` (widget) — `meetsGuideline(textContrastGuideline)` on the Progress screen + the ≥ 3:1 strong-anchor assertion in Light and Dark (A1/A2); deliberately does **not** assert 3:1 on the atmosphere steps.
- `features/test/progress/progress_no_scoreboard_no_glyph_test.dart` (widget) — no KFGQPC font family / muṣḥaf widget in the tree; no streak/score/points/badge/leaderboard widget or string; the continuity indicator absent in the default state (C-041, C-044).
- `features/test/progress/progress_golden_fixture.dart` (shared harness, not a test) — the frozen read model, the provider/`Clock` overrides, and the real-font loader reused by all six files; contains no assertion and no retrievability arithmetic.
