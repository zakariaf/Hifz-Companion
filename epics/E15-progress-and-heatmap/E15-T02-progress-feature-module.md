## Goal

The Progress tab stops being inert. This task builds **only the skeleton** the rest of E15 mounts into: the `packages/features/lib/src/progress/` module in the canonical anatomy — a dumb `ProgressScreen` `ConsumerWidget` View, a 1:1 `ProgressViewModel`, a `widgets/` directory, and a **feature-scoped** `progress_providers.dart` — replacing E07-T04's inert Progress placeholder behind the existing `/progress` `GoRoute` in the `ShellRoute` bottom nav (RTL order **Today · Muṣḥaf · Mutashābihāt · Progress · Settings** preserved, untouched). The ViewModel reads the E15-T01 streamed read model (`progressHeatmapProvider`) and exposes it as a sealed UI state with **loading / populated / empty** variants; the View renders those variants into named structural slots — the grid host (T03), the forecast host (T08), and the empty/first-run host (T09). No visualization, no health copy, no number is built here: T02 ships structure, provider wiring, and the tab swap, and nothing else.

## Implementation notes

This task is wiring and structure only: no engine call, no repository write, no `DateTime.now()`, no visualization, no user-facing number, no new factual claim. Every health value on this screen will arrive pre-computed from E15-T01's stream.

1. **Files** (in `packages/features/lib/src/progress/`, per eng-add-feature-module):
   - `progress_screen.dart` — the dumb `ConsumerWidget` entry View. It reads exactly one controller (`ProgressViewModel` via the scoped provider), `switch`es over the sealed state, and lays out the named slots. It replaces E07-T04's inert placeholder **in the same file**, so the existing `/progress` route resolves to it with zero router changes; the `screen.progress` accessibility identifier is retained.
   - `progress_view_model.dart` — the 1:1 ViewModel: a `Notifier`/`AsyncNotifier` that watches `progressHeatmapProvider` (T01) keyed by the active `ProfileId` and maps its emissions onto an immutable sealed `ProgressState`: `loading` (stream not yet emitted), `populated` (a non-empty page set with its juz roll-up), `empty` (no memorized pages / first run). No commands yet — this surface is read-only; the module adds **no write path**.
   - `widgets/` — structural slot leaves only (e.g. a token-styled `progress_section_slot.dart` host), one primary type per file. No cell, tile, sheet, list, or forecast widget lives here — those are T03–T08.
   - `progress_providers.dart` — the screen's Riverpod providers, **scoped to the feature**: the `ProgressViewModel` provider, `family`-keyed by `ProfileId` and `autoDispose`d on unmount. Nothing from this file is declared or re-exported globally; `app/composition/providers.dart` is not touched.
2. **The ViewModel consumes, never computes.** It holds zero scheduling logic: no `retrievability`, no `due_at`, no aggregate, no band derivation, no clock read (`DateTime.now()` and `clockProvider` are both absent — T01 already applied the injected `Clock`). It is a pure mapping from the streamed read model to the sealed UI state; a new stream emission (e.g. a review committed on Today) rebuilds the state automatically (04 §3).
3. **Dependencies point down only.** The module imports `data` (the T01 provider surface), `l10n`, `flutter_riverpod`, and `go_router` — and needs no direct `engine`/`quran` import at all, since health arrives pre-computed and the visualization layer is glyph-free. No `http`/`dio`, no `drift`/DAO symbol, no other feature's `src/` (eng-add-feature-module §4; 02 §5).
4. **Variant rendering stays calm and structural.** `loading` is a quiet token-styled placeholder (no spinner-of-shame, no progress percentage); `populated` renders the slot column — grid host first (overview-first, PRD §12.5), then forecast host, then the future list/detail entry points — each an empty named container T03/T07/T08 fill; `empty` renders a single structural placeholder region whose real welcoming copy is T09's. Any error from the stream surfaces as the standard calm retry, never a guilt message.
5. **Strings.** Reuse the existing E07-T04 ARB keys for the nav label and screen title. Any new structural string this task genuinely needs (e.g. a loading `Semantics` label) is an ARB key in `app_ar.arb` (template) + transcreated `fa`/`ckb` (ckb flagged pending native+scholar review) — no hardcoded literal, no number, no band label, no health/methodology copy (those belong to T04/T06/T09 with their own CLAIMS tracing).
6. **RTL + tokens + a11y by construction.** Logical insets only (`EdgeInsetsDirectional`/`AlignmentDirectional`); layout from `space.*`, text via `type.*`, surfaces via `color.*` — by name, no raw hex/pt/ms; the screen root keeps a stable identifier and a `Semantics` label per locale; targets that exist (none interactive yet beyond nav chrome) stay ≥48dp.
7. **The slot contract is the hand-off to the siblings.** Each structural slot carries a stable identifier (e.g. `progress.slot.grid`, `progress.slot.forecast`, `progress.slot.empty`) documented in the slot leaf's `///` doc, so T03/T08/T09 mount by filling a slot — never by editing the ViewModel or the sealed state. Do **not** pre-declare a detail-sheet route or a "weakest pages" section here: T06 owns its own presentation entry and T07 its list; adding their scaffolding early would put two writers on one widget.
8. **The tab swap is surgical.** Do not edit the route table, the redirect guard, `HomeShell`, or the nav order; do not add a route parameter; do not navigate from the ViewModel. The only shell-visible change is that `/progress` now renders the scaffold instead of the inert placeholder — and E07-T04's `placeholders_test.dart` is updated to drop Progress from the inert set (it is no longer required to be interaction-free once T03+ mount).
9. **Pitfalls to avoid:** computing `R`/`due_at`/the roll-up (or reading a clock) anywhere in this module; declaring a provider globally "for convenience"; an un-keyed current-profile read (must be `family` by `ProfileId` + `autoDispose`); building a grid cell, juz tile, forecast row, or empty-state copy that belongs to T03–T09; touching `app/composition/router.dart` beyond nothing; `Navigator.push`; breaking the shell nav test's existing notification-scheduler fake wiring; leaving the stale "Progress is inert" assertions green.

## Tests

All deterministic and offline by construction; ViewModel tests use `ProviderContainer.test()` + `overrideWith` faking the T01 provider — never mocking the `Notifier` (04 §7).

- `features/test/shell/home_shell_test.dart` (**extended**, not rewritten) — tapping the Progress nav item routes to `/progress` and the resolved subtree is the new `ProgressScreen` scaffold, **not** the inert placeholder (asserted by the scaffold's slot identifiers and the absence of the placeholder body); the five-destination RTL order assertions and the existing notification-scheduler fake wiring stay green under fa/ckb/ar.
- `features/test/shell/placeholders_test.dart` (**updated**) — Progress is removed from the inert-placeholder assertion set; the remaining placeholders (if any) still pass.
- `features/test/progress/progress_view_model_test.dart` (unit) — with `progressHeatmapProvider` overridden by a controllable fake stream: pins `loading` before first emission; a non-empty read model → `populated` carrying the streamed value **unchanged** (same instance/equality — proving no recompute); an empty card-set emission → `empty`; a second emission rebuilds the state (the listener records the transition); a recording fake repository asserts **zero writes** and a throwing fake clock asserts **zero clock reads** from this module.
- `features/test/progress/progress_screen_test.dart` (widget) — pumps `ProgressScreen` with the ViewModel provider overridden per variant: `loading` renders the calm structural placeholder (no spinner-of-shame, no percentage); `populated` renders the named grid-host and forecast-host slots in order (grid first); `empty` renders the structural empty region; no streak/score/badge widget exists in any variant; run under `Locale('fa')`, `Locale('ckb')`, `Locale('ar')` with logical-inset assertions.
- Offline guard: the suite installs a throwing `HttpOverrides` (eng-write-dart-test) — the scaffold, its providers, and the tab swap open no socket. (The consolidated per-locale RTL/greyscale/deuteranope golden suite for the full Progress surface is E15-T10, not here.)
