What the "built-blind" epics kept, and where they drifted from their own specs

E15–E19 were built before their per-task files existed. On 2026-07-10 the 61 missing task files were retro-authored from the design docs, then the build was audited against them — one comparison auditor per epic, then an adversarial adjudicator who re-verified every claimed gap. E20 was never built.

Built blind, the epics consistently got the non-negotiables right — engine-honest data, min-leaning aggregates, persist-before-republish, append-only logs, calm adab copy, offline — and consistently fell short on breadth: secondary surfaces, cross-feature handoffs, and above all tests. Most architectural divergences are defensible simplifications to amend into the specs, not rebuild. Two built details violate the project's own honesty posture and must be removed.

Remove from code — two honesty violations

  1. E19 (blocker): the C-048 grade coercion. The build coerces the register's deliberate [TRAD-equivalent project rule] grade into [TRAD] in both the register and the drift gate (whose own test pins the coercion) — so the science screen labels the app's own design rule as "traditional scholarship," on the very surface built to earn scholars' trust. Remove it; raise the CLAIMS.md amendment instead.
  2. E15 (major): the crisp per-page percentage (e.g. ۸۷٪) on zoom-sheet cells — more precise than the detail sheet's own range-in-words, exactly what C-025 forbids.

E17 Backup & Restore

1 met7 partial1 divergent

The format core is high-fidelity (container byte-for-byte per spec, canonical payload, true set-union merge, 44 tests green under the TZ matrix). The shell layer falls short: no backup controller/status line/stale nudge, Argon2id on the UI isolate, a full-history temp .hifzbackup survives "Erase everything," and double-tap erase instead of the specced hold-to-confirm. The safety-critical divergence: import coerces hostile Argon2 params into range and derives anyway (spec demands validate-and-refuse, zero KDF calls); and an unspecced honesty defect — encryption-ON with an empty passphrase silently exports plaintext.

Key adjustments (15)

  • addvalidate-and-refuse hostile Argon2 params (zero derivations); map unknown KDF id to newerFormat
  • addrequire a passphrase when encryption is on — never silently downgrade to plaintext
  • addoff-isolate export/import; backup controller + dated status line; temp-file sweep; hold-to-confirm erase
  • amendthe merge-weight rule to the built idempotence-preserving max (not summed)
